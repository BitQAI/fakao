## 1. 用户口径（本次落地）

1. 看背题卡与条目卡**严格一致**：点卡片翻面 + 三档自评，不再"点选项判分"。
2. 手机端两处大文件必须拆（`FlashcardView` 603 行 → 293 行）。
3. 题卡标记要做（复用 `marks`）。
4. 统计计入题卡（今日累计 / 累计已听走同一套 `reviews`）。
5. **不新建表**：题卡按条目模型重建，复用 entries/reviews/marks/tts。
6. 卡片 ID 按科目分类；priority 统一"普通"，**不强制混排**。
7. **判断题不进看背 / 听学**（卡片只做客观题）。
8. 自定义范围要能选到新增的题卡。

## 2. 实现要点

| 层 | 改动 |
|---|---|
| 数据 | `entries` 加 `kind` / `options` / `article_text`；`v_entries` 视图隔离「条目空间」（43 处 SQL 逐处归属） |
| 卡片生成 | `app/card_entries.py` + `scripts/sync_card_entries.py`：客观题（`origin='bank'`）→ 卡片条目 `XF-Q000162`，幂等；文本漂移更新并作废旧音频；题库下架转 draft；判断题卡片自动清理 |
| 看背 | `FlashcardView` 只留编排（293 行）；`study/StudyCardShell` + `EntryFace` / `CardFace` 共用外壳；`useReadPlan` / `useStudyMarks` / `ReadFinishCard` / `EditEntryDialog` 抽出；`/api/plans/today` 去掉 `statute_cards`（题卡本就在 `items` 里） |
| 听学 | `listen/ListenSegment` 一段组件覆盖两种内容；题卡音频走 `/api/audio/{卡片ID}`；`/api/listen` 去掉 `statute_cards`；删除 `ListenCardView`、`/api/cards/statute|stats`、`/api/audio/card/*` |
| 自定义范围 | 新增「内容」开关（全部 / 正式条目 / 法条题卡）与「按法条题卡选择」；后端 `GET /api/coverage/cards` + `custom_entries(kinds, laws)` |
