# 核心考点覆盖扩容与指导性案例挂接 — Spec（2026-08-29）

## 问题背景

用户目标为法考客观题 180 分（总分 300，60% 过线），策略是"抓大放小"：优先掌握高权重科目的常考/易错/新增必考点，不追求低频考点全覆盖。

现状盘点（2026-08-29 实测）：

- 条目库 1922 条，全部唯一考点，组织为 科目(7) → 子科目(791) → 考点；优先级分布：高频 59.8%、易错 22.7%、新增 8.8%、普通 8.7%。
- 科目资料 19 份，按标题切出 888 个章节块；按条目 sources.loc 定位，780 块有条目引用，108 块无引用；剔除"复习建议/口诀/速记"等元信息节后，疑似真缺口 66 块（商经知 23、三国法 17、理论法 10、民法 6、刑法 5、民诉 3、刑诉 2）。
- 对照司法部公告的客观题科目构成，**行政法与行政诉讼法整科缺失**（客观约 25-26 分），**环境资源法缺失**（约 3-5 分）。
- 案例库统一已有 278 条"最高法指导性案例"（多为旧批次经典），但 1922 条目中仅 12 处引用；`data/案例素材/最高法指导性案例-精选汇编.md` 收录 30 个指导性案例（含 2023-2026 新批次 23 个），其中新批次未入统一案例库。
- 官方大纲约 1100+ 考点 / 3000+ 细分知识点；历年真题累计实际考过约 956 个考点，每年约 400 个。对 180 分目标，关键是高优覆盖而非全量覆盖。

## 方案概要

1. **补行政法**：基于仓库 `data/法条库/` 中行政法相关法律原文，编写科目资料（高频考点 / 易错点 / 背诵版讲义），接入科目循环并生成条目、导入、合成音频。
2. **定向补缺**：对 66 个疑似真缺口章节，只把这些块喂给 DeepSeek 生成条目（不重跑全科），补后复测章节覆盖。
3. **指导性案例挂接**：把精选汇编中 2023-2026 新批次指导性案例并入统一案例库（jsonl + index + cases 表），扩展匹配脚本支持"对已有案例的条目追加指导性案例"，全量挂接并去重、限条数。

## 数据模型

- `entries`：无结构变更；新增 `subject=行政法` 条目，ID 前缀 `XZ`。
- `cases`：无结构变更；`source=最高法指导性案例` 增加新批次记录。
- `data/案例库统一/index.csv` 与 `documents/最高法指导性案例.jsonl`：追加新批次记录（幂等去重）。
- 科目顺序（scheduler `SUBJECT_ORDER`、generator 续批循环）：加入 行政法。

## API 设计

无对外 API 变更。`/api/coverage`、`/api/listen`、`/api/audio` 自动包含新科目。

## 验证标准

- 全量 pytest 通过（含新增用例）。
- 行政法条目 ≥150，音频齐全；全科章节引用覆盖率较 780/888 提升，行政法章节覆盖率 ≥80%。
- 指导性案例挂接：引用"最高法指导性案例"的条目数显著提升（目标 ≥200 条），每条去重且不超过上限；精选汇编新批次（如 225-229 号）出现在库中且被匹配。
- 定向补缺后 66 个疑似缺口章节中无条目引用数降至 ≤15。

## 范围边界

- 不做：环境资源法补全（仅记录缺口）、真题频次校正优先级、主观题。
- 优先级标注仍由生成 LLM 给出，本次不引入真题频次统计。
