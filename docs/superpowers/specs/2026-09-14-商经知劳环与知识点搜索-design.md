# 知识点搜索与「商经知劳环」科目扩容 — Spec（2026-09-14）

## 问题背景

用户提出两条需求：

1. **知识点可搜索**：自定义学习范围（按知识点勾选）与覆盖页（覆盖树）当前只能逐级展开浏览，考点数量已达 2304 条（子模块 800+），靠肉眼找某个考点成本高。
2. **科目口径修正 + 内容扩容**：客观题卷二「商经知」实际包含劳动法与社会保障法、环境资源法，仓库当前 `subject=商经知` 仅覆盖公司法/合伙企业法/破产法/票据法/保险法/证券法/竞争法/消费者法/知识产权法/劳动法（仅 35 条），**环境保护法完全缺失**（0 条，约 3-5 分）。用户要求科目改名为 `商经知劳环`，并补充劳动法、环境保护法的内容与题目。

现状盘点（2026-09-14 实测）：

- 条目库 2304 条 final（刑法 162 / 民法 180 / 刑诉 260 / 民诉 228 / 商经知 553 / 理论法 371 / 三国法 374 / 行政法 176）。
- 商经知 553 条中，劳动法相关子模块（`劳动法-*` / `劳动合同法`）共 35 条，集中在「解除与经济补偿」「试用期」；环境保护法 0 条。
- `data/科目资料/商经知/` 4 份资料，`--gaps --dry-run` 仅剩 2 个未引用块，说明现有资料已被充分提炼，缺口在**新增资料**。
- 劳动法条目引用的 `劳动合同法/劳动争议调解仲裁法/劳动法/工伤保险条例` 共 43 处 `statutes` 在 `data/法条库/` 无对应文件，前端「法条」chip 点击返回 404。
- 知识点浏览入口：覆盖页 `CoverageTree.tsx`（只读树）、`CustomRangePicker.tsx`（勾选树，看背/听学/组卷共用），均无搜索框。

## 方案概要

### A. 知识点搜索（前端，两处复用同一套匹配逻辑）

1. 新增共享匹配工具 `frontend/src/lib/pointSearch.ts`：输入覆盖树 + 关键词，返回命中考点集合、命中科目/子模块集合（供自动展开）、命中总数。
   - 命中规则：关键词命中「考点名」→ 命中该考点；命中「子模块名/科目名」→ 该范围下所有考点视为命中。
   - 空关键词 → 不启用搜索（沿用原折叠行为）。
2. 新增共享搜索框组件 `frontend/src/components/KeywordSearch.tsx`（输入 + 清空 + 命中数）。
3. 覆盖页 `CoverageTree.tsx`：顶部搜索框，命中时只渲染命中分支并全展开，显示「命中 N 个考点」。
4. 自定义范围 `CustomRangePicker.tsx`：
   - 按科目模式：按科目名过滤列表。
   - 按知识点模式（主要场景）：命中分支自动展开、只显示命中考点；提供「全选命中结果」；筛选期间**不改变已勾选集合**（清空关键词后原勾选保持）。

### B. 科目改名与扩容（数据 + 后端 + 文档）

1. 科目 `商经知` → `商经知劳环`，落点：
   - `backend/app/scheduler.py`、`backend/app/generator.py` 的 `SUBJECT_ORDER`；`backend/scripts/generate_entries.py` 的 `SUBJECT_PREFIX`（前缀保持 `SJ`，避免改 importer 的 ID 正则与历史 ID）。
   - `backend/scripts/match_cases.py` 的领域门槛集合。
   - 资料目录 `data/科目资料/商经知/` → `商经知劳环/`；条目文件 `data/entries/商经知.json` → `商经知劳环.json`（含 `subject` 字段与 `source_md`）。
   - DB：`UPDATE entries SET subject='商经知劳环' WHERE subject='商经知'`。
   - `AGENTS.md`、README 等文档口径同步。
2. 新增资料：
   - `data/科目资料/商经知劳环/劳动法-高频考点.md`：服务期与违约金、竞业限制、集体合同、非全日制用工、劳务派遣三性/10%、工伤认定与待遇、年休假、工时与加班、社会保险、失业保险金等新增块（避开已覆盖的解除/经济补偿/试用期重复）。
   - `data/科目资料/商经知劳环/环境保护法-高频考点.md`：原则与责任主体、环评制度、排污许可、总量控制、监测与信息公开、按日连续处罚、查封扣押、行政拘留、生态红线与补偿、环境侵权责任（民法典 1229-1235）、环境公益诉讼、水污染防治（饮用水水源保护区）。
3. 条目与题目：用既有流水线 `generate_entries.py --subject 商经知劳环 --gaps` 生成新条目（draft）→ 导入 → 提升 final → `synthesize_audio.py` 合成音频。自测题仍走 `quiz_service` 按条目即时生成，新条目自动产出新题目。
4. 法条库（可选增强）：环保法条文已在 `data/法条库/中华人民共和国环境保护法.md`；劳动法相关法条库文件缺失，需外部权威文本，本次**不改动**，作为遗留项记录。

## 数据模型

无表结构变更。`entries.subject` 取值由 `商经知` 改为 `商经知劳环`（同库 553 行原位更新，`id` 前缀 `SJ-###` 不变，`reviews/quiz_answers/cases` 外键不受影响）。

## API 设计

无新增接口。`/api/coverage`（搜索数据源）、`/api/plans/custom`、`/api/listen/custom`、`/api/quiz/custom` 自动适配新科目名。

## 验证标准

- 前端：覆盖页与自定义范围（看背/听学/组卷入口）均能输入关键词命中考点，命中分支自动展开，清空后恢复原状；自定义范围筛选不影响已勾选集合。
- 后端：`pytest` 全绿（含改名后的用例断言）。
- 数据：`商经知劳环` 条目数 ≥ 600，其中环境保护法子模块 ≥ 20 条、劳动法相关子模块 ≥ 60 条；新条目 `status=final` 且有音频文件。
- 覆盖树 `/api/coverage` 中 `商经知劳环` 下出现环境保护法子模块。

## 范围边界

- 不做：劳动法/环保法法条库文件补全（需权威来源）、真题频次校正、主观题。
- 不改：条目 ID 规则、`entries` 表结构、现有 8 科之外的科目划分。
- 已勾选但被关键词过滤隐藏的考点：保留勾选状态，不做自动取消。

## 执行中新增发现（2026-09-14）

1. **自测题与考点脱钩（既有缺陷，已修）**：`ai.generate_quiz` 的 prompt 只写"根据该条目出题"，
   却从未把条目内容拼进 user 消息，模型只能凭空编题。实测 `SJ-593`（劳动法·年休假天数）
   出的是刑法题。修复：新增 `_quiz_brief(entry)` 拼入科目/子模块/考点/场景/结论/易错提示/法条，
   并加回归测试 `test_generate_quiz_prompt_carries_entry`。修复后同一考点出的题目与条目一致。
2. **新条目法条引用人工复核**：逐条核对新增 123 条（环保法 57 + 劳动法相关 66）的结论与条号，
   修正 5 条（`SJ-643` 第42条误含公开义务、`SJ-653` 环保税法条号、`SJ-663` 按日计罚表述、
   `SJ-608` 社保法第60条应为第62条、`SJ-619` 未成年工禁忌劳动应为第64条），删除 1 条无法条依据的
   `SJ-646`（生态红线调整程序），最终新增 122 条。
