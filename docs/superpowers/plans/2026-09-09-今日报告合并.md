### Task 2: 报告复盘段重组

**Files:**

- [ ] **Step 1: 类型对齐**

在 `frontend/src/lib/types.ts` 中把 `TodayPayload` 改为：

```typescript
export interface TodayPayload {
  date: string;
  days_left: number | null;
  plan: Plan;
  stats: Stats;
  streak: { current: number; longest: number };
}
```

（删除 `morning_report: Report | null;` 一行；`Report` 接口保留，晚报仍用。）

- [ ] **Step 2: 复盘段重组**

在 `frontend/src/app/report/page.tsx` 中：

1. 顶部数据取值改为：
   ```tsx
   const stats: Stats | null = today?.stats ?? null;
   const plan = today?.plan ?? null;
   const daysLeft = today?.days_left ?? null;
   const streak = today?.streak ?? null;
   ```
2. `{view === "review" && (...)}` 整块替换为三段纵排：
   - hero 卡（复用今日页样式类 `today-hero`/`progress-ring` 等；`ring` 变量计算保留）：
     进度环 + 倒计时徽标（`daysLeft <= 17` 标红逻辑照搬今日页）+
     打卡（`streak.current > 0` 才显示）+ 新学/复习/错题三数（`plan.counts`）+
     今日数据一行（看背+自测 done/quota、听学分钟、薄弱）。
   - 计划 rationale 小灰字：`plan.rationale` 经 `mdToHtml` 渲染，
     包在 `<div className="report-content muted">`。
   - 今日复盘卡（原晚报卡，标题改 `今日复盘`）：
     未生成时显示 `<p className="muted">学完后来生成今日复盘。</p>` +
     `[生成今日复盘]` 主按钮；已生成显示内容 + `[重新生成]`。
3. `regenerate` 函数加确认：
   ```tsx
   async function regenerate() {
     if (evening && !confirm("重新生成将覆盖今日复盘并消耗 token，确定？")) return;
     const r = await postJson<Report>("/api/reports/generate/evening");
     setEvening(r);
   }
   ```
   （首次生成不弹 confirm，只对覆盖式重生成确认。）
4. 删除原「今日数据」卡与原早报段（`today?.morning_report` 整块）。
5. 后端 `kind=evening` 不变：`latest?kind=evening` 与 `generate/evening` 调用保持原样。
