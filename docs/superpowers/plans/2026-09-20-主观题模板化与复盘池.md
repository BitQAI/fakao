## 问题诊断

原来的 13 道题，采分点**清一色是结论句**，用户只要说出结论就得分。而真实主观题
按「结论＋依据＋涵摄」给分，只写结论基本不得分——**模块在奖励错误的答题习惯**。

## 实现的三层

### 第 1 层：采分点结构化

文件：`backend/app/subjective_templates.py`（新增）、`backend/scripts/build_case_questions.py`

- 新增 6 个采分点维度：`结论 / 依据 / 涵摄 / 抗辩 / 程序 / 救济`
- 生成 prompt 按科目给出维度侧重，并要求 **5–7 个采分点覆盖多个维度**
- 校验规则同步调整：点数放宽到 4–8；**只有「依据」类必须带可解析法条**（结论、涵摄本来就没有法条）
- 判分从「命中 N/M」升级为**按维度给分**（`case_quiz.kind_breakdown`），能直接看出「结论对、依据缺」

### 第 2 层：作答骨架

- `subjective_templates.SKELETONS`：6 科各自的作答骨架（刑法七步、民法请求权基础、刑诉阶段-主体-权限、民诉路线图、行政法六步法、商法内外部关系）
- 前端以**可折叠的 `<details>` 呈现，不自动填充作答区**（自动填会退化成填空题，有测试守护）

### 第 3 层：复盘池

- `case_quiz.misses()`：按**采分点文本聚合**（同一采分点跨题反复未命中才是真薄弱），返回未命中次数 / 出现次数 / 最近时间 / 法条链接 / 来源题
- `GET /api/cases/misses?subject=`
- 前端新增 `CaseReview.tsx`，案例模块改为「今日案例 / 复盘池」两个子页签（`CasePanel.tsx`）

### 新增：卷面映射

- `subjective_templates.EXAM_SLOTS`：科目 → 卷面题号 + 分值 + 建议用时
- 题面顶部显示「第5题·行政法（选做） · 建议 35 分钟 / 30 分」
