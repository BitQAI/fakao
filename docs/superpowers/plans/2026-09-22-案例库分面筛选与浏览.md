# 案例库分面筛选与浏览 — 实施计划（2026-09-22）

> 依据：`docs/superpowers/specs/2026-09-22-案例库分面筛选与浏览-design.md`

## 任务清单

### Task 1 — 分面聚合 `backend/app/case_facets.py`（新增）

- [ ] `FIELD_TAGS = ("刑事","民事","行政","执行","国家赔偿")` + `UNLABELED = "未标注"`
- [ ] `case_year(date) -> str`：取前 4 位，非法返回 `""`
- [ ] `crimes_of(keywords) -> list[str]`：以「罪」结尾、剔除 `无罪/有罪/犯罪`
- [ ] `facets(conn) -> dict`：单趟扫描 source/category/keywords/date，返回 fields/crimes/years/sources/total

### Task 2 — 检索升级 `backend/app/case_index.py`

- [ ] `search(conn, q="", source=None, field=None, crime=None, year=None, sort="relevance", limit=30, offset=0) -> dict`
- [ ] 维度过滤：field 走 `keywords[0]`（含 `未标注` 分支）、crime 走 keywords 精确元素、year 走 `date` 前缀
- [ ] 排序：`relevance`（有 q）/ `newest` / `oldest`（date 归一后比较，空日期排最后）
- [ ] 分页：`total` = 筛选后全量数，`items` = `[offset:offset+limit]`
- [ ] 空 `q` 且无筛选 → 返回浏览列表（默认 newest），不再返回空

### Task 3 — 路由 `backend/app/routers/case_library.py`

- [ ] `/api/case/search` 新增 field/crime/year/sort/offset 参数与校验（未知 sort → 400）
- [ ] `/api/case/facets` 新接口

### Task 4 — 后端测试

- [ ] `tests/test_case_facets.py`（新增）
- [ ] `tests/test_case_index.py` / `tests/test_api_case_library.py` 扩展筛选、排序、分页、浏览
- [ ] `pytest tests` 全绿

### Task 5 — 前端 `/cases`

- [ ] `lib/caseLibTypes.ts`：新增 `CaseFacet`/`CaseFacets`/`CaseQuery`
- [ ] `components/CaseFacets.tsx`（新增）：部门法 chips、罪名 chips（展开全部）、年份下拉、排序段
- [ ] `app/cases/page.tsx`：筛选状态 + 分页（加载更多）+ 空态文案
- [ ] `components/CaseLibraryList.tsx`：支持「共 N 篇 + 加载更多」
- [ ] `app/components.css`：`.caselib-*` 增补（chips 换行、年份下拉、加载更多）

### Task 6 — 验证

- [ ] `pytest tests`、`tsc --noEmit`、`npm run lint`
- [ ] Playwright：部门法/罪名/年份筛选、排序、加载更多、console 无错误（截图存 `frontend/e2e/shots/`）

## 风险

- 浏览模式会扫描全部元数据行（7172 行，实测 17 ms）+ 为当前页取正文，代价可接受；量级翻十倍再考虑 FTS5/索引。
- 主部门法口径固定为 `keywords[0]`，若后续 `format_cases.py` 改标签顺序，需要同步本口径。
