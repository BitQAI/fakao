- [ ] `resolve_law_article(text) -> (law_key, no, sub) | None`：把「刑诉法91条」「中华人民共和国专利法第九条」解析成法条库定位
- [ ] `resolve_statute()` 改为复用该函数（行为不变）

## Task 2 覆盖率度量（`app/statute_coverage.py` + `scripts/audit_quiz_coverage.py`）

- [ ] `coverage(conn)`：每部法 {条文数, 被条目引用, 被题目覆盖(entries/bank/judge), 覆盖率}
- [ ] 题目 `basis` 与条目 `statutes` 两种写法都能解析
- [ ] 报告：总量 + 覆盖率分布 + 缺口 Top30 + 分类（新增法条/司法解释/国际条约/配套法规）
- [ ] 输出 Markdown + JSON；测试覆盖解析与统计口径

## Task 3 法条驱动客观题（`scripts/build_statute_quiz.py`）

- [ ] 候选 A：条目引用过但无题覆盖的条文（按引用条目数排序）
- [ ] 候选 B：按 `--per-law` 配额补未覆盖条文（数字/要件型优先）
- [ ] 出题 → 校验（结构 + 正确项与条文原文相关）→ 入 `origin='bank'`、`entry_id=NULL`
- [ ] 参数：`--per-law`、`--limit`、`--workers`、`--only-cited`、`--only-missing`、`--publish`、`--dry-run`
- [ ] 抽检 + 发布；记录覆盖率前后变化

## Task 4 组卷可用（`app/quiz_service.py` + 测试）

- [ ] `custom_quiz`：条目题不足题量时用 `quiz_bank.pick` 补齐（含法条题）
- [ ] 测试：题量满时不改变结果；不足时补入法条题且不重复
