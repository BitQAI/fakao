## T1 关系词闸门模块

**文件**：`backend/app/relation_terms.py`（新增，≈260 行）、`backend/tests/test_relation_terms.py`（新增）

**接口**

```python
@dataclass(frozen=True)
class Family:
    name: str                      # modal / form / instance / …
    terms: tuple[str, ...]         # 词表（长词在前，避免子串误判）
    swaps: dict[str, tuple[str, ...]]   # 原文词 -> 允许被偷换成的词

FAMILIES: dict[str, Family]        # 17 族，仅此一处定义

def extract(text: str) -> set[tuple[str, str]]        # {(族名, 词)}
def subject_terms(text: str) -> set[str]              # {机关/主体名}
def distinguishing(text: str) -> list[str]            # 命中的族名（按词长优先）
def swaps_for(term: str) -> tuple[str, ...]
def check(stem: str, reference: str, answer: str,
          min_ratio: float = 0.85) -> tuple[bool, str]  # (是否通过, 原因)
```

**步骤**

- [ ] 定义 17 族词表 + 定向互换白名单（Spec §4.1）
- [ ] `extract`：长词优先扫描，返回 `(族, 词)` 集合
- [ ] `check`：对题禁新增关系词；错题要求「恰好 1 处偷换 + 落在白名单 + 原文恰好少 1 词」
- [ ] 主体一致性校验（`subject_terms` 双向命中或同体系放行）
- [ ] 题干相似度闸门（≥0.85 视为抄原文，丢弃）
- [ ] 单测 ≥15 例：对题新增即拒 / 错题白名单内通过 / 错题改两处即拒 / 白名单外即拒 /
      主体不一致即拒 / 长词优先（发回重审、驳回诉讼请求、上一级）

**验证**：`backend/.venv/bin/python -m pytest tests/test_relation_terms.py -q`
