# 第一篇 国际公法

## 一、国际法导论与主体

### 必背考点清单

1. **国际法渊源**（《国际法院规约》第38条）：①国际条约（最主要渊源）；②国际习惯（须具备"物质要素+心理要素"：普遍实践+法律确信）；③一般法律原则。判例与学说仅为"辅助资料"，不是直接渊源。
2. **国际法主体**：国家（基本主体）、国际组织（派生主体）、争取独立的民族解放组织（准主体）。**自然人、法人不是国际法主体**。
3. **国家主权豁免**：国家的行为及财产不受他国管辖。
   - 绝对豁免主义 → 限制豁免主义（管理行为/商业行为不豁免，主权行为豁免）；
   - 豁免**放弃**：须明示（国家或其代表的声明），且为对具体诉讼的放弃；豁免放弃**只能由管辖豁免放弃延伸至执行豁免，但执行豁免放弃须单独明示**；
   - ⚠️ **2024年《外国国家豁免法》**（2024年1月1日施行）：我国采**限制豁免**立场，商业活动例外、仲裁例外、国有企业单独责任等已立法化（2025/2026年大纲重点）。
4. **国家承认与继承**：承认方式（法律承认=建交/条约等明示行为；事实承认）；政府继承仅限革命或政变导致的非宪法方式更迭；债务继承：**恶债不继承**（如湖广铁路债券案）。
5. **引渡**（考点集中）：
   - 原则：**双重犯罪原则**、**政治犯不引渡**（口诀：**种劫外战**——种族灭绝罪、劫机等国际罪行、侵害外交代表、战争罪**不视为政治犯**）；**罪行特定原则**（只就引渡罪名审判，不得转引渡）；
   - 本国国民**可以**不予引渡（"或引渡或起诉"）；
   - 我国《引渡法》：**应当拒绝**（本国国民、政治犯、军事犯罪、已获赦免、时效已过、双重审判风险、酷刑风险）；**可以拒绝**（本国已就同罪提起公诉、人道主义考虑等）。
   - 【口诀】应当拒绝八情形："本国政军免过期，已判酷刑双重险"。
6. **外交保护**：条件——①受侵害人具有本国国籍且**持续国籍原则**（受害时至求偿结束时）；②**用尽当地救济**；③国家行使外交保护是**权利而非义务**。

## 二、海洋法（各海域宽度与制度对比表）★★★

### 必背考点清单

1. 领海基线：**正常基线法**（低潮线）与**直线基线法**（我国采用直线基线法）。
2. 海湾：曲入陆地面积≥以湾口宽度为直径的半圆面积；**历史性海湾**不受此限（我国渤海、琼州海峡为内水）。

### 海域制度对比表（核心背诵）

| 海域 | 宽度（自基线量起） | 法律地位与沿海国权利 | 外国船舶航行制度 |
|---|---|---|---|
| **内水** | 基线向陆一侧 | 完全主权；非经许可不得进入 | 无通过权 |
| **领海** | **≤12海里** | 主权（上空、水域、底土） | **无害通过**（须连续不停；潜水艇须浮出水面并展示旗帜） |
| **毗连区** | **≤24海里** | 仅为管制权，非主权 | 沿海国可管制：**海关（走私）、财政（逃税）、移民（偷渡）、卫生（检疫）**（我国另加"国家安全"）【口诀】**安移卫关财** |
| **专属经济区** | **≤200海里** | 经济性主权权利（勘探开发自然资源）；他国有航行、飞越、铺设电缆管道自由 | 无害通过等 |
| **大陆架** | **200海里；宽大陆架最多350海里**（或2500米等深线外100海里） | 沿海国开发自然资源的主权权利（**无需占领**）；他国可铺设电缆管道 | 上覆水域非领海 |
| **群岛水域** | 群岛基线最长**125海里** | 群岛国主权 | **群岛海道通过权** |
| **用于国际航行的海峡** | —— | 沿岸国主权但受限 | **过境通行制**（马六甲海峡等） |
| **公海** | 专属经济区以外 | 不属于任何国家 | **六大自由**【口诀】**航飞铺、科建捕**：航行、飞越、铺设电缆管道、捕鱼、建造人工岛屿、科学研究 |
| **国际海底区域** | 国家管辖范围以外海床洋底 | **人类共同继承财产**；开发采**平行开发制**（海底管理局企业部＋缔约国/实体） | —— |

### 必背考点清单（续）

3. **紧追权**：必须①连续不断；②从管辖海域开始，可追至公海；③只能由**军舰、军用船舶或政府船舶/飞机**行使；④**被追船舶进入其本国或第三国领海必须立即停止**。⚠️**民用商船无紧追权**。
4. **登临权**（临检权）：军舰在公海上对**外国船舶**的嫌疑船（海盗船、贩奴船、非法广播船、无国籍船等）可登临检查；错误登临应赔偿。⚠️对象：外国船，**不适用于本国船与军舰**。
5. **海盗、贩奴、贩毒、非法广播**：各国均可行使**普遍管辖权**【口诀】**海盗贩奴和贩毒是非法的**。
6. 船舶碰撞刑事管辖：公海碰撞仅由**船旗国或船员所属国**行使刑事管辖。

## 三、外交关系法与领事关系法 ★★★

### 必背考点清单（使馆与人员）

1. 主要公约：《维也纳外交关系公约》（**1961年**）、《维也纳领事关系公约》（**1963年**）。
2. 使馆职务：代表、保护、谈判、调查、促进。
3. **使馆馆长等级**：大使、公使、代办（**代办≠临时代办**，代办是馆长级别，派遣无须征得接受国同意——错，馆长均须征得同意）。
4. **派遣须征得接受国同意**：使馆馆长、**武官**（其余人员如参赞、秘书、随员无须征得同意）。
5. 使馆人员构成：外交人员（馆长、参赞、武官、秘书、随员）＋行政技术人员＋服务人员＋私人仆役。

### 外交特权与豁免与领事特权与豁免对比表（高频对比题）

| 项目 | 外交人员（使馆） | 领事官员 |
|---|---|---|
| **人身不可侵犯** | 完全不可侵犯（不得逮捕拘禁） | 不可侵犯；**犯重罪且经司法机关裁判可逮捕** |
| **馆舍不可侵犯** | 完全；未经馆长同意不得进入；不得搜查扣押 | 馆舍中执行领事职务区域不可侵犯；**火灾等紧急情况可推定同意进入** |
| **管辖豁免** | 刑事：**完全豁免**；民事：豁免但**3个例外**（私人不动产诉讼、继承诉讼、公务范围外的商业活动）；行政：豁免 | 仅限**执行领事职务的行为**（职务豁免） |
| **作证义务** | **完全免除** | 职务相关事实免除，可拒绝作证（职务行为） |
| **免税** | 关税、直接税免除 | 领事物品关税免除（有限额） |
| **豁免开始** | 进入接受国境时（已在境内者自就任通知时） | 同左 |
| **豁免终止** | 职务终止后，至其**离境或合理期间届满**时止 | 同左 |

> 【口诀】外交刑事全豁免，民事三例外：**私房遗产做生意**；领事只免职务事。

6. **外交人员豁免的放弃**：只能由**派遣国**明示放弃（不得由外交人员本人放弃）；放弃管辖豁免须个案明示。
7. 使馆人员对接受国义务：尊重法律、不干涉内政、馆舍不得用于职务以外用途。
8. **外交特权与豁免的依据**：职务需要说＋代表说（维也纳公约采职务需要说为主）。

## 四、条约法 ★★★

### 必背考点清单

1. 依据：《维也纳条约法公约》（**1969年**）。
2. **条约成立实质要件**：①缔约能力和缔约权；②自由同意（**错误、诈欺、贿赂、强迫**均使同意无效）；③**符合强行法**（与强行法抵触的条约无效，强行法优先）。
3. **缔约程序**：谈判议定约文（**认证**：草签、暂签、签署）→签署→**批准**（表示同意受拘束）→交换/交存批准书→生效。
4. **无须出示全权证书的人员**（法定当然代表）：**国家元首、政府首脑、外交部长、使馆馆长（议定接受国条约）、国际组织代表**。【口诀】**元首首脑外长，馆长代表免证**。
5. **条约保留**：
   - 含义：单方面声明排除或改变条约条款对其效力；
   - 不得保留：①条约禁止保留；②条约仅准许特定保留；③保留与条约目的宗旨不符；
   - 效果：保留经接受后，**在保留国与其他当事国间按保留后的条约执行**；反对保留国不反对条约生效时，**保留所涉条款在两国间不适用**；
   - 保留可在**签署、批准、接受、赞同或加入时**提出。
6. **条约的生效与适用**：生效≠签署；多边条约交存批准书后生效；条约对第三国无损益（**"条约不约束第三国"**；但"最惠国待遇"等约定可为第三国创设权利需第三国同意）。
7. **条约解释规则**：善意解释；按**通常含义**、上下文、**目的宗旨**解释；补充资料（谈判准备文件）为辅助。中国参加并批准的条约与国内法冲突时，**除保留条款外，国际条约优先**；我国声明保留的条款不适用。
8. **条约的无效**：违反强行法、强迫（包括对代表施压）、诈欺、贿赂、错误（以错误为基础方可）。
9. **条约的终止**：期满、履行完毕、**退约**（须按条约规定）、**违约**（重大违约他方可终止或暂停）、**情势变迁**（"根本情势变迁"可作为终止理由——注意：**条约法公约限制严格**，仅限缔约时情况发生根本变化且构成基础）、战争、新强行法产生。
   - 【口诀】条约终止："期满履毕退违约，情变强法战争间"。

## 五、国家责任与国际不法行为

### 必背考点清单

1. **构成要件**：①行为**可归因于国家**（国家机关行为、行使政府权力者、国家指挥控制的行为、事后承认的行为等）；②行为**违背国际义务**（作为或不作为）。
2. **免责事由**（排除不法性）：**同意、自卫、反措施、不可抗力、危难、危急情况**。【口诀】**同意自卫反措施，不可抗力危难急**。
3. **国际不法行为的后果**：停止、赔偿（恢复原状、补偿、抵偿）、保证不再犯。
4. **反措施**：受害国针对责任国的措施，须①事先催告；②与所受损害相称；③不得使用武力、不违反基本人权。
5. **国家的国际罪行**（如侵略、灭绝种族）：适用特殊责任规则。

## 六、国际争端的和平解决 ★★

### 必背考点清单

1. **政治方法**（无拘束力）：**谈判与协商**（必须首先使用）、斡旋与调停（第三方介入）、调查（查明事实）、和解（调解，出具报告无拘束力）。
   - 【口诀】政治五法："谈斡调查明，调和和解清"——谈判、斡旋、调停、调查、和解。
2. **法律方法**（有拘束力）：
   - **国际仲裁**：当事国同意→仲裁庭裁决**终局且拘束力**；
   - **国际法院（ICJ）**：
     - 诉讼管辖权：**自愿管辖**（协议提交）、**协定管辖**（条约约定）、**任择强制管辖**（声明接受，可附保留）；
     - 咨询管辖权：应**联合国大会、安理会**等机构请求发表咨询意见，**无拘束力**；
     - 判决：终审，**无上诉**；拒不执行由安理会采取措施。
3. **安理会**：维持和平主要责任机关；表决——常任理事国**五大国一致原则**（实质性事项否决权）；**弃权不构成否决**。实质事项：采取行动、接纳会员、推荐秘书长、中止或开除会员。【口诀】**新老秘书长要采取行动**。
4. 我国对任择强制管辖声明**曾作保留**（不接受ICJ任择强制管辖）。

## 七、战争与武装冲突法 ★★

### 必背考点清单

1. **战争开始的后果**：外交关系断绝、条约关系变化（政治性条约终止，人道条约与边界条约继续有效）、敌国财产处理（公产可没收，**私产不得没收**）。
2. **作战手段限制（海牙体系）**：禁止使用**极度残酷武器**（达姆弹、窒息性毒气、化学/生物武器）；禁止不分皂白攻击；禁止攻击不设防城镇、医院、文化财产（战时不得攻击，**文化财产标识**三顶蓝盾）。
3. **保护对象（日内瓦体系）**：1949年日内瓦四公约（战地伤病员、海上伤病员、**战俘**、**平民**）＋1977年两个附加议定书。
   - **战俘待遇**：不得杀害虐待；审讯仅可要求陈述姓名、军衔、编号、出生日期；**战争结束后应立即释放遣返**；红十字会探视权。
   - **平民保护**：禁止攻击平民及民用物体；占领国不得强迫平民提供情报、劳动。
4. **战时中立**：中立国领土不可侵犯；交战国不得在中立国领土作战（违反即中立国可采取行动）。
5. **战犯责任**：个人责任（纽伦堡/东京审判原则）；指挥官责任；**战争罪、反人类罪、灭绝种族罪不适用政治犯不引渡，时效不适用**；国际刑事法院（罗马规约1998，**中国未加入**，美国未加入）。

# 第二篇 国际私法

## 一、冲突规范与基本制度

### 必背考点清单

1. **冲突规范结构**：范围＋系属（连结点＋准据法表述公式）。
2. **类型**：
   - 单边冲突规范（直接规定适用内国或外国法，如三类涉外投资合同适用中国法）；
   - 双边冲突规范（如"不动产物权适用不动产所在地法"）；
   - **重叠适用**（收养条件和手续适用收养人与被收养人经常居所地法）；
   - **选择适用**：无条件（结婚手续，符合缔结地/一方经常居所地/国籍国法任一即有效）vs 有条件（结婚条件按次序）。
3. **准据法**：经冲突规范指引的**实体法**（不包括冲突规范本身）。
4. **五大基本制度**：
   - **识别**：依法院地法；
   - **反致**：我国**不接受反致与转致**（《法律适用法》第9条：涉外民事关系适用的外国法律，不包括该国的法律适用法）；
   - **公共秩序保留**：外国法适用结果损害我国社会公共利益→排除适用，**适用中国法**；
   - **法律规避**：当事人故意制造连结点规避**我国强制性规定**→不发生适用外国法的效力；
   - **外国法查明**：查明主体——法院依职权（当事人可选择）→提供途径：**当事人提供、中外法律专家、我国驻该国使领馆、该国驻华使领馆、司法协助中央机关**；无法查明→**适用中国法**；对外国法内容有异议由**人民法院认定**。
   - 【口诀】查明五途径："当事人专家，双边使馆加中央"。

---

## 二、"经常居所地"认定规则 ★★★

1. **自然人**：在涉外民事关系产生、变更、终止时**已经连续居住一年以上**且作为**生活中心**的地方。
2. **除外情形**：**就医、劳务派遣、公务**等情形不构成经常居所地。【口诀】**医派公不居**。
3. 法人：**主要营业地**；当事人可以协议选择或变更适用法律（**一审法庭辩论终结前**均可行，但不得规避强制性规定）。
4. ⚠️涉港澳台地区参照适用经常居所地规则（港澳居民居内地参照外国人）。

---

## 三、《涉外民事关系法律适用法》重点法条背诵表 ★★★★

> 原则：**有约定从约定（意思自治），无约定按最密切联系/经常居所地/物之所在地**。

### 1. 民事主体（第11-20条）

| 事项 | 准据法 |
|---|---|
| 自然人民事**权利能力** | **经常居所地法** |
| 自然人**行为能力** | **经常居所地法**；若行为地法认为有行为能力而经常居所地法认为无，**适用行为地法**（保护交易安全） |
| 宣告失踪、死亡 | 自然人**经常居所地法** |
| 法人（权利能力、行为能力、组织、股东权利义务） | **登记地法**（主营业地与登记地不一致的，可适用主营业地法） |
| 人格权（姓名权、名誉权、肖像权、隐私权等，含网络侵权） | **被侵权人经常居所地法**（第15条、46条） |

### 2. 物权（第31-40条）

| 事项 | 准据法 |
|---|---|
| **不动产物权** | **不动产所在地法**（第36条） |
| **动产物权**（取得、变更、消灭） | 当事人**协议选择**；无选择→适用**法律事实发生时动产所在地法**（第37、38条） |
| **运输中动产** | **目的地法**；当事人可协议选择 |
| 船舶物权 | **船旗国法**；船舶抵押权适用**船旗国法**（光船租赁前设立的适用**原登记国法**）；船舶优先权适用**法院地法** |
| 航空器物权 | **国籍登记国法** |
| 有价证券 | **权利实现地法或其他最密切联系地法**（第39条） |
| 权利质权 | **质权设立地法**（第40条） |

### 3. 债权——合同（第41-49条）

1. 当事人可**协议选择**合同适用法律（第41条），无选择→适用**履行义务最能体现合同特征的一方经常居所地法**或**最密切联系地法**。
2. **三类合同强制适用中国法**（单边规范）：在中国境内履行的**中外合资经营企业合同、中外合作经营企业合同、中外合作勘探开发自然资源合同**。【口诀】**合资合作勘探，三合同用中国法**。
3. 消费者合同：消费者经常居所地法优先，但消费者可选择商品/服务提供地法（保护弱者）。
4. 劳动合同：**劳动者工作地法**；难以确定→用人单位主营业地法（劳务派遣除外）。

### 4. 债权——侵权（第44-50条）

| 情形 | 准据法 |
|---|---|
| **一般侵权** | **侵权行为地法**；双方**共同经常居所地**→适用该共同经常居所地法；**侵权发生后**当事人可协议选择**法院地法**（第44条） |
| **产品责任** | **被侵权人经常居所地法**为主；被侵权人可选择**侵权人主营业地法或损害发生地法**（第45条） |
| **网络侵权（名誉权等）** | **被侵权人经常居所地法**（第46条） |
| **不当得利、无因管理** | 当事人**协议选择**→无选择：**共同经常居所地法**→无：**发生地法**（第47条） |
| **知识产权侵权** | **被请求保护地法**；侵权发生后可协议选择**法院地法**（第50条） |

### 5. 婚姻家庭（第21-30条）★★★

| 事项 | 准据法 |
|---|---|
| **结婚条件** | 共同经常居所地法→无：**共同国籍国法**→无（在一方经常居所地或国籍国缔结）：**婚姻缔结地法**（第21条，有条件选择） |
| **结婚手续** | 符合**缔结地法、一方经常居所地法或国籍国法**之一即有效（第22条，无条件选择） |
| **协议离婚** | 可协议选择**一方经常居所地或国籍国法**；未选择→**共同经常居所地法**→共同国籍国法（第26条） |
| **诉讼离婚** | **法院地法**（第27条） |
| **夫妻人身关系** | 共同经常居所地法→共同国籍国法（第23条） |
| **夫妻财产关系** | 可协议选择（一方经常居所地/国籍国/主要财产所在地法）→无选择：共同经常居所地→共同国籍国（第24条） |
| **父母子女关系** | 共同经常居所地法→一方经常居所地或国籍国法中**有利于保护弱者**（第25条） |
| **收养** | 条件和手续：**重叠适用**收养人、被收养人经常居所地法；效力：收养人经常居所地法；解除：收养时收养人经常居所地法或法院地法（第28条） |
| **扶养** | 一方经常居所地、国籍国或主要财产所在地法中**有利于被扶养人**（第29条） |
| **监护** | 一方经常居所地或国籍国法中**有利于被监护人**（第30条） |

> 【口诀】结婚"三递进"：**同居→同籍→缔结地**；弱者保护五大类：**扶养、监护、父母子女、消费者、劳动者**。

### 6. 继承（第31-35条）★★

| 事项 | 准据法 |
|---|---|
| **法定继承** | **被继承人死亡时经常居所地法**；但**不动产适用不动产所在地法**（第31条，"动随人、不随物"） |
| **遗嘱方式** | 符合遗嘱人**立遗嘱时或死亡时**经常居所地、国籍国法，或**遗嘱行为地法**任一→有效（第32条） |
| **遗嘱效力** | 遗嘱人**立遗嘱时或死亡时经常居所地法或国籍国法** |
| **遗产管理、无人继承遗产** | 适用**遗产所在地法**（第34、35条） |

### 7. 其他总则性规定

1. **诉讼时效**：适用相关涉外民事关系**应当适用的法律**（第7条）。
2. **意思自治**：必须**明示**选择；一审法庭辩论终结前可变更。
3. 涉外民事关系涉及的领域：凡依本法规定为**中华人民共和国法律强制性规定**的，直接适用（直接适用法）。

## 四、涉外民事诉讼程序 ★★

### 必背考点清单

1. **管辖权**：
   - 一般地域管辖：被告住所地；涉外合同或其他财产权益纠纷，被告在中国无住所的，可由**合同签订地、履行地、诉讼标的物所在地、可供扣押财产所在地、侵权行为地或代表机构住所地**法院管辖（《民诉法》第272条）；
   - **协议管辖**：书面明示选择，与争议有实际联系的地点的法院；
   - **应诉管辖**：被告应诉答辩且未提管辖异议→视为接受管辖；
   - **专属管辖**：因在中国履行**中外合资/合作经营企业合同、中外合作勘探开发自然资源合同**发生纠纷提起的诉讼，由**中国法院专属管辖**（不能协议排除）。
2. **送达**：中国法院可依公约（海牙送达公约）、外交途径、使领馆（对本国国民）、传真电子邮件（受送达人同意）等送达；**邮寄送达须受送达国允许**。
3. **外国法判决的承认与执行**：依条约或互惠原则，由**中级人民法院**审查；裁定承认后同判决效力。
4. **外国仲裁裁决的承认与执行**：适用《纽约公约》（**1958年**，中国1987年加入，**互惠保留＋商事保留**）；拒绝事由以公约第5条为限：**①当事人无行为能力或协议无效；②程序不当（未获指定仲裁员或通知）；③超裁；④仲裁庭组成或程序不符；⑤裁决未生效或已撤销；⑥争议事项依法院地法不可仲裁；⑦违反公共政策**。⭐第5条事由穷尽，法院不得主动依职权审查第1款事项（第2款可依职权审查）。
5. **涉外仲裁**（中国国际经济贸易仲裁委员会等）：**仲裁协议有效**（书面）；**裁决终身性**；当事人不能就涉外仲裁裁决向法院起诉或上诉。
6. **国际司法协助**：请求协助事项**有损我国主权、安全、社会公共利益**的，不予执行（公共秩序保留）。

## 一、国际贸易术语（Incoterms 2020）★★★★

### 必背考点清单

1. 2020通则共**11个术语**，按运输方式分两组：
   - **任何运输方式（7个）**：EXW、FCA、CPT、CIP、DAP、DPU、DDP；
   - **仅海运及内河运输（4个）**：FAS、FOB、CFR、CIF。
   - 【口诀】"E F C D"四组：**工厂家里等（EXW），F说船前事（FCA/FAS/FOB），C管运费险（CFR/CIF/CPT/CIP），D到门口完（DAP/DPU/DDP）**。
2. **2020版主要变化**：①**DAT改为DPU**（卸货地交货，唯一要求卖方卸货的术语）；②**FCA可结合已装船提单**（买方指示承运人签发提单）；③**CIP默认投保级别高于CIF**（CIP须投ICC(A)一切险级，CIF仅须ICC(C)最低险级）。

4. **清关义务**：出口清关——除EXW外均由**卖方**办理；进口清关——除DDP外均由**买方**办理。

## 二、《联合国国际货物销售合同公约》（CISG）★★★

### 必背考点清单

1. **适用范围**：①**营业地**在不同缔约国（不看国籍）；②国际私法规则导致适用缔约国法（中国保留）；③**排除适用**：**消费品买卖、拍卖、公债股票、船舶飞机、电力、供货方的义务主要在于提供劳务**；合同效力、所有权转移、产品责任**不适用公约**。
2. **中国保留**：①**书面形式保留已撤销**（公约允许任何形式）；②扩大适用保留未撤销。
3. **合同订立**：要约（**到达生效、可撤回**；不可撤销：写明期限或受约人合理信赖）；承诺（到达生效；**逾期承诺**：立即通知接受则有效；对要约的实质性变更=**反要约**：标的、数量、价格、付款、交货、责任范围、争议解决等为实质内容）。
4. **卖方义务**：交付货物、移交单据、**质量担保**（符合合同与通常用途）与**权利担保**（所有权无瑕疵、无第三方权利或请求）。
5. **买方义务**：付款＋收取货物。
6. **风险转移**：货交第一承运人时转移（CISG一般规则）；在途货物：**合同订立时**；货物特定化前风险不转移。
7. **根本违约**：构成根本违约才能**宣告合同无效**；预期违约（明显不能履行）可中止履行或解除；分批交货：一批根本违约可宣布该批无效，必要时全部无效。
8. **救济方式**：实际履行、损害赔偿（**可预见性规则**：不得超过违约方订立时预见的损失）、减价、解除合同；**免责（障碍）**：不可预见的障碍，免责期间限于障碍存续期间。
9. **通知期限**：货物不符，买方须在**发现或应当发现后合理时间内**通知，最迟不得超过**收货后2年**（除非与合同保证期不符）。
10. **公约适用特点**：任意性——当事人可约定排除或改变（中国《民法典》与公约不冲突时可并行适用，但涉外买卖合同纠纷当事人明示排除公约的除外）。

## 三、国际货物运输与保险 ★★★

### 必背考点清单（提单）

1. **提单性质**：①**货物收据**；②**运输合同证明**（不是合同本身）；③**物权凭证**（凭单放货）。
2. **提单种类**：已装船提单/收货待运提单；清洁/不清洁提单；**记名提单**（不可转让）、**指示提单**（背书转让）、不记名提单（交付转让）。
3. **无正本提单交付货物**（我国司法解释）：承运人（含实际承运人）无单放货→对**提货人**（未持单收货人）承担责任；**正本提单持有人可凭单索赔**；赔偿额=**货物CIF价**（成本＋保险费＋运费）；**提货人凭伪造提单提货**承运人免责情形严格限定；正本提单持有人索赔时效**1年**。
4. **三大提单公约对比（高频考点）**：

| 项目 | 《海牙规则》1924 | 《维斯比规则》1968 | 《汉堡规则》1978 |
|---|---|---|---|
| 责任基础 | **不完全过失责任制**（航行过失、管船过失免责） | 同海牙规则 | **完全过失/推定过失**（过失倒置） |
| 责任期间 | **钩至钩**（装到卸） | 同左 | **收至交**（全程） |
| 诉讼时效 | **1年** | 1年，可协议延长（索赔人可再诉**3个月**） | **2年** |
| 适用范围 | 缔约国签发的提单 | 同左＋卸货港在缔约国 | 装货港/卸货港/营业地在缔约国 |
| 火灾 | 免责 | 免责 | 承运人举证 |
| 延迟交货 | 无规定 | 无规定 | 有规定（赔偿额限运费） |

> 【口诀】**海牙"不完全过失"，汉堡"推定过失"**；**海牙钩到钩1年，汉堡收到交2年**。

5. **我国《海商法》**：采**不完全过失责任制**（航行/管船过失免责）；时效1年（海上货物运输）；承运人最低义务：**适航、管货、不绕航**。

### 必背考点清单（海上保险）

1. 三大险别：**平安险、水渍险、一切险**。
   - 平安险：全损＋部分损失中**共同海损**赔偿，**单独海损不赔**（自然灾害所致）；
   - 水渍险＝平安险＋**单独海损**赔偿；
   - 一切险＝水渍险＋**11种一般附加险**（偷窃、淡水雨淋、短量、混杂玷污、渗漏、碰损破碎、串味、受潮受热、钩损、包装破裂、锈损）。【口诀】一切险＝水渍险＋"偷淡水短混渗，碰串潮钩包锈"。
2. **除外责任**：被保险人故意或过失、发货人责任、**自然损耗、市价跌落、运输延迟**、战争险与罢工险（须另行加保）。
3. **共同海损**：为共同安全主动合理牺牲，**由受益方按价值比例分摊**；单独海损由受损方自负。

## 四、信用证（UCP600）★★★★

### 必背考点清单

1. **三大原则**：
   - **独立抽象原则**：信用证独立于基础合同，银行不审查货物/合同；
   - **单据交易原则**：银行只凭单据行事（凭单付款）；
   - **严格相符原则**：**单证相符、单单相符**（单据必须表面与信用证条款一致，单据之间不得矛盾）。
2. **银行审单期限**：银行应**自收到单据次日起最多5个银行工作日**内审核并决定接受或拒付（UCP600第14条）。⭐**5个工作日**为高频数字。
3. **拒付通知**：拒付须**一次性**列明不符点，在5个工作日内通知，否则丧失拒付权。
4. **银行免责**：对单据的**真实性、有效性**不负责；对货物、发货人/收货人行为不负责；不可抗力免责。
5. **信用证欺诈例外**：开证申请人（买方）发现欺诈可申请**法院止付令**（止付条件：①有欺诈证据；②尚未善意付款；③申请人提供担保）。**善意第三人（议付行）已付款的，不得止付**。
6. **软条款**：信用证中隐含陷阱条件（如"货物到达后付款"），银行可拒绝执行与UCP600不符的条款。
7. **UCP600（2007年生效）**：适用于跟单信用证；**保兑行**责任等同开证行；可转让信用证只能转让**一次**；不可撤销是常态（信用证一律视为不可撤销，除明示可撤销——UCP600取消了可撤销信用证）。

## 五、"两反一保"（对外贸易救济）★★★

### 必背考点清单

| 措施 | 针对行为 | 要件 | 期限 | 措施 |
|---|---|---|---|---|
| **反倾销** | 倾销（出口价低于正常价值） | ①倾销；②产业损害；③**因果关系** | 临时措施**4个月**（特殊6个月）；反倾销税征收期限**一般5年**（日落复审可延长） | 临时措施/价格承诺/**反倾销税**（向进口商征收，税率不得高于倾销幅度） |
| **反补贴** | 专项性补贴 | ①补贴（专向性）；②损害；③因果关系 | 同上，期限**一般5年** | 临时措施/承诺/**反补贴税** |
| **保障措施** | 公平贸易下的进口激增（不针对不公平行为！） | ①进口数量**绝对或相对**增加；②对国内产业**严重损害或威胁**（程度高于"实质损害"）；③因果关系 | 实施期限**一般不超过4年**，可延长但**总期限不超过10年**；临时保障措施**不超过200天** | **配额/关税**（非歧视适用，对来自**所有国家**的进口） |

### 必背考点清单（续）

1. **反倾销与反补贴比较**：均针对**不公平竞争**行为；倾销幅度=正常价值-出口价格；损害认定标准=**实质损害**。
2. **保障措施区别要点**：①针对**公平贸易**；②损害程度更高（**严重损害**）；③**非歧视性**（不分国别）【口诀】**"反倾销补贴打低价，保障只防激增量"**。
3. **中国的复审**：**期中复审**（2年内）、**日落复审**（期满前）、情势变更复审，均由商务部依职权或应申请进行。
4. **WTO救济纪律**：保障措施须**补偿或接受报复**；反倾销/反补贴可依争端解决机制挑战。

## 六、世界贸易组织（WTO）★★★

### 必背考点清单

1. **基本原则**：
   - **最惠国待遇（MFN）**：一成员给任一成员的优惠立即无条件给予其他成员（关税及贸易）——GATT第1条；
   - **国民待遇（NT）**：进口产品与国内产品同等对待（不低于）——GATT第3条；
   - **自由贸易原则**：关税减让、取消数量限制；
   - **透明度原则**：法规公布、贸易政策审议机制（TPRM）；
   - 一般例外（GATT第20条：公共道德、人类动植物健康、保护可用竭自然资源等）与**安全例外**。
2. **WTO三大支柱协议**：GATT（货物贸易）、**GATS**（服务贸易）、**TRIPS**（知识产权）。
3. **争端解决机制（DSU）**：
   - 程序：**磋商（60天）→专家组（设立后6个月裁决）→上诉机构（60-90天）→执行**；
   - **反向一致（倒协商一致）原则**：专家组报告、上诉机构报告**除非全体一致反对，否则自动通过**（"几乎自动"）；
   - 执行：败诉方须在合理期限内执行；不执行→**授权报复**（中止减让，交叉报复：先同部门→跨部门→跨协定）。
   - 【口诀】**"磋商专家上诉裁，反一致自动过"**。
4. **与中国**：中国2001年12月11日加入；"市场经济地位"争议不影响反倾销调查。

## 七、国际投资法律制度 ★★

### 必背考点清单

1. **多边投资担保机构（MIGA，华盛顿公约1985）**：承保**政治风险**（征收和类似措施、战争内乱、汇兑限制、政府违约）；投保人须为**发展中成员国**的投资者。
2. **国际投资争端解决中心（ICSID，华盛顿公约1965）**：
   - 管辖要件：①当事人一方为**缔约国及其实体**、另一方为**另一缔约国国民**；②争议为**直接因投资产生**的法律争议；③双方**书面同意**提交（不得单方撤销）；
   - 程序：仲裁庭裁决**终局**，不得上诉；拒不执行→成员国国内法院按**普通判决**执行；
   - ⚠️中国1988年加入（商事保留：**仅接受"征收补偿款额"争议**提交ICSID——逐步开放）。
3. **双边投资保护协定（BIT）**：国民待遇＋最惠国待遇＋**公平公正待遇**；间接征收补偿标准："赫尔公式"（充分、及时、有效补偿）。
4. **外资待遇与征收**：合法征收要件：①公共利益；②非歧视；③依法律程序；④**及时、充分、有效补偿**（"适当补偿"为我国立场——补偿标准中国主张"适当/合理补偿"，拒绝"赫尔公式"）。

## 八、知识产权国际公约 ★★

### 必背考点清单

| 公约 | 年份 | 核心内容 |
|---|---|---|
| 《巴黎公约》（专利/商标） | **1883** | **国民待遇**＋**优先权**（专利/实用新型**12个月**，商标/外观设计**6个月**）＋**独立性原则**（各国分别审查） |
| 《伯尔尼公约》（著作权） | **1886** | **自动保护**（无须登记）＋国民待遇（含"起源国"）＋**最低保护期：作者有生之年＋50年**（摄影/电影25年）＋对精神权利的保护 |
| 《TRIPS协定》（WTO） | **1994** | 首次将知识产权纳入多边贸易规则；**最惠国待遇原则**引入知识产权；保护范围扩展至**集成电路布图设计、地理标志**；最低保护期：专利**20年**、商标**7年（可无限续展）** |
| 《马德里协定》 | 1891 | **商标国际注册**（"马德里注册"），中国1989年加入 |
| 《专利合作条约》（PCT） | 1970 | **专利国际申请**（一次申请多国生效），中国1994年加入 |
| 《保护录音制品公约》 | 1971 | 邻接权保护（中国1993年加入） |

### 必背考点清单（续）

1. **巴黎公约优先权**：首次申请后，在**12个月（专利/实用新型）/6个月（商标/外观设计）**内向其他成员国申请，视为首次申请日提出。
2. **伯尔尼公约"起源国"**：作品**首次出版国**；未出版作品以**作者国籍国**为起源国。
3. **TRIPS的国民待遇与最惠国待遇**：TRIPS是**首个引入最惠国待遇**的知识产权公约；保护期以TRIPS规定为底线，成员可更高保护。
4. **表演者权、录音制作者权、广播组织权（邻接权）**：保护期**50年**（表演者/录音制作者以表演或录制品完成起算；广播自首次播放起50年）。
