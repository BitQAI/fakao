# 民法《高频考点》资料（2026年法考适用）

> 依据：《中华人民共和国民法典》（2021.1.1施行）及《最高人民法院关于适用〈中华人民共和国民法典〉有关担保制度的解释》（法释〔2020〕28号，2021.1.1施行）、《最高人民法院关于适用〈中华人民共和国民法典〉合同编通则若干问题的解释》（法释〔2023〕13号，2023.12.5施行）、《最高人民法院关于适用〈中华人民共和国民法典〉婚姻家庭编的解释（二）》（法释〔2025〕1号，2025.2.1施行）、《最高人民法院关于适用〈中华人民共和国民法典〉继承编的解释（一）》（法释〔2020〕23号）。
>
> 考频标注说明：**高频**＝近十年考查10次以上或几乎每年必考；**中频**＝经常考查；**低频**＝偶尔考查。2026年大纲民法部分仅作技术合同章节结构调整，无实质考点变化；复习重心仍为物权、合同、担保、侵权责任。

## 一、总则编

### 1.1 民事法律行为的效力（无效、可撤销、效力待定）【高频】

- **核心法条**：《民法典》第143、144、146、147、148、150、151、153、154、157条；合同编通则解释第16—19条。
- **可背诵要点**：
  1. 有效要件：行为人具有相应民事行为能力＋意思表示真实＋不违反法律、行政法规的强制性规定，不违背公序良俗（第143条）。
  2. 无民事行为能力人实施的民事法律行为无效（第144条）；行为人与相对人以虚假意思表示实施的无效（第146条）。
  3. 可撤销情形（考20次以上）：①重大误解（第147条）；②欺诈（第148条）；③第三人欺诈（第149条，须相对人知道或应当知道）；④胁迫（第150条）；⑤显失公平（第151条，利用对方危困状态或缺乏判断能力）。重大误解、受欺诈（第三人欺诈、胁迫）自知道或应当知道之日起90日内行使撤销权，显失公平为1年；最长除斥期间为行为发生之日起5年（第152条）。
  4. 效力待定：限制民事行为能力人超出其年龄、智力、精神健康状况实施的民事法律行为，及无权代理（狭义），经法定代理人或本人追认后有效（第145条、第171条）。
  5. 无效/被撤销后果：自始没有法律约束力；返还财产、折价补偿、赔偿损失（第157条）。
- **命题角度**：多以案例形式辨析"无效—可撤销—效力待定"三者的界限；注意撤销权90日/1年/5年期间的区分；与无权处分（合同有效）对比考查。

### 1.2 代理制度（表见代理与狭义无权代理）【高频】

- **核心法条**：《民法典》第161—175条，重点为第170条（职务代理）、第171条（无权代理）、第172条（表见代理）。
- **可背诵要点**：
  1. 表见代理构成要件：行为人无代理权＋存在使相对人相信其有代理权的权利外观（如授权书未收回、印章保管）＋相对人善意无过失。表见代理有效，代理行为后果由本人承担（第172条）。
  2. 狭义无权代理：效力待定，本人追认有效；拒绝追认的，行为人对相对人承担责任，但相对人明知或应知的除外（第171条）。
  3. 代理权滥用：自己代理、双方代理原则上无效，但经被代理人同意或追认的除外（第168条）。
  4. 注意区分"无权处分"与"无权代理"：无权处分中合同效力不受影响（第597条），存在善意取得问题；无权代理中不存在善意取得问题。
- **命题角度**：判断是否构成表见代理的典型案型（如离职员工持盖公章的空白合同签约）；职务代理中法定代表人越权签约的效力（第504条，相对人善意则合同有效）。

### 1.3 诉讼时效【中频】

- **核心法条**：《民法典》第188—199条；《诉讼时效规定》相关条文。
- **可背诵要点**：
  1. 一般时效3年；最长权利保护期20年（自权利受损之日起算）；法律另有规定的除外（第188条）。
  2. 不适用诉讼时效的请求权：请求停止侵害、排除妨碍、消除危险；不动产物权和登记的动产物权的返还请求权；抚养费、赡养费或扶养费请求权等（第196条）。
  3. 诉讼时效中止（最后6个月内因不可抗力等障碍，中止事由消除后满6个月届满）与中断（起诉、请求、同意履行义务等，中断后重新计算）（第194、195条）。
  4. 当事人不得预先放弃或约定变更诉讼时效（约定无效）。
  5. 时效届满后，债务人同意履行或自愿履行的，不得再以时效届满抗辩。
- **命题角度**：中止与中断的区别（法定事由、时间节点）；时效届满的法律效果是债务人获得抗辩权而非债权消灭；与除斥期间（如撤销权90日、遗失物回复2年）的辨析。

## 二、物权编

### 2.1 物权变动（区分原则、公示公信）【高频】

- **核心法条**：《民法典》第208—232条，重点为第209、215、224、225、229—232条。
- **可背诵要点**：
  1. 基于法律行为的物权变动：不动产＝有效合同＋登记；动产＝有效合同＋交付。登记/交付为生效要件，但特殊情形采对抗要件（如动产抵押权自合同生效时设立，登记对抗，第403条；机动车等特殊动产所有权变动登记对抗，第225条）。
  2. 区分原则（第215条）：合同效力与物权变动相区分——未办理物权登记不影响合同效力，守约方可请求违约救济。
  3. 非基于法律行为的物权变动（第229—232条）：法院/仲裁法律文书、征收决定、继承、合法建造或拆除房屋等，自行为成就时生效；处分该物权前须先办理宣示登记（"双重登记"）。
  4. 预告登记（第221条）：防止一房二卖；债权消灭或自能办理登记之日起90日内未申请的，预告登记失效。
  5. 交付方式：现实交付、简易交付、指示交付、占有改定；占有改定不能设立质权、不能善意取得。
- **命题角度**：一房二卖/多重买卖中谁取得所有权、谁承担违约责任；预告登记期间处分不发生物权效力；继承取得后未经宣示登记处分的效力问题。

### 2.2 善意取得【高频】

- **核心法条**：《民法典》第311—313条；物权编解释（一）第14—20条。
- **可背诵要点**：
  1. 构成要件：①转让人无权处分；②受让人受让时为善意（不知情＋无重大过失）；③以合理的价格转让（排除赠与等无偿取得）；④动产已交付、不动产已登记。
  2. 标的物：仅限占有委托物；遗失物、盗赃物等占有脱离物原则上不适用善意取得（遗失物权利人有权自知道或应当知道受让人之日起2年内请求返还，第312条）。
  3. 交付方式：现实交付、简易交付、指示交付均可；占有改定不构成善意取得。
  4. 法律效果：受让人原始取得所有权，原权利人只能向无权处分人主张侵权赔偿或不当得利；善意取得他物权（质权、抵押权）参照适用，其中质权善意取得不要求支付合理对价。
- **命题角度**：几乎每年必考（分值约5分）。多与无权处分、遗失物、动产质权结合考查；判断"善意"的时间点为受让时（登记/交付完成时）。

### 2.3 担保物权总论与担保制度司法解释【高频】

- **核心法条**：《民法典》第386—393条、第406、416条；担保制度解释第1—17条、第37—54条。
- **可背诵要点**：
  1. 担保合同从属性：担保合同是主债权债务合同的从合同，主合同无效则担保合同无效（第388条），但担保人对合同无效存在过错仍可能承担责任（担保制度解释第17条）。
  2. 担保范围：主债权及其利息、违约金、损害赔偿金、保管担保财产和实现担保物权的费用（第389条）。
  3. 物保与人保并存（第392条）：有约定按约定；无约定或约定不明时，债务人自己提供物保的，债权人应先就物保受偿；第三人提供物保与人保并存的，债权人可选择行使，担保人之间依约定或依担保制度解释第13条（同一合同书签章可推定相互分担）追偿。
  4. 共同担保追偿规则（担保制度解释第13条）：原则上担保人之间不能相互追偿；但①有约定相互追偿及份额，②约定承担连带共同担保，③未约定但在同一份合同书上签章的，可依约或按比例分担。
  5. 抵押财产转让（第406条）：抵押人可转让抵押财产，抵押权具有追及效力；约定禁止或限制转让但未登记的，转让合同有效、物权可变动（受让人明知约定的除外）——担保制度解释第43条细化。
  6. 物上代位权（第390条、担保制度解释第42条）：担保财产毁损、灭失或被征收的，担保物权人就保险金、赔偿金、补偿金优先受偿。
- **命题角度**：共同担保人之间能否追偿、追偿份额（历年真题热点）；借新还旧中的担保责任；公司对外担保效力；担保合同无效时的责任承担。

### 2.4 抵押权（一般抵押、最高额抵押、超级优先权）【高频】

- **核心法条**：《民法典》第394—424条，重点为第402—406、416条；担保制度解释第44—57条。
- **可背诵要点**：
  1. 不动产抵押权自登记时设立（第402条）；动产抵押权自抵押合同生效时设立，未经登记不得对抗善意第三人（第403条）；浮动抵押（第396条）与最高额抵押（第420条）。
  2. 超级优先权（第416条）：动产抵押担保的主债权是抵押物价款，标的物交付后10日内办理抵押登记的，该抵押权人优先于抵押物买受人的其他担保物权人受偿，但留置权人除外。担保制度解释第57条扩张适用于浮动抵押后再购新动产、融资租赁等情形。
  3. 抵押权与租赁权关系：先租后抵（已转移占有）适用买卖不破租赁；先抵后租的，已登记的抵押权优先，实现抵押权不影响租赁合同效力但可涤除。
  4. 抵押权期间（担保制度解释第44条）：主债权诉讼时效期间届满后，抵押权人主张行使抵押权的，法院不予支持。
  5. 房地一体原则（第397条）：建筑物与占用范围内的建设用地使用权一并抵押；抵押后新增建筑物不属于抵押财产。
  6. 动产抵押权竞合顺位：登记在先优先；均未登记的按债权比例清偿；留置权＞登记的抵押权/质权（第456条）；价款优先权优先于在先登记的浮动抵押。
- **命题角度**：超级优先权与留置权的排序、10日宽限期的计算；一物多押时的受偿顺序；最高额抵押的债权确定情形（第423条）。

### 2.5 质权与留置权【中频】

- **核心法条**：《民法典》第425—462条；担保制度解释第55—60、62条。
- **可背诵要点**：
  1. 动产质权：交付生效（第429条），占有改定不能设立质权；转质规则（第434条）——承诺转质与原质权并存，责任转质仅在原质权范围内优先受偿。
  2. 权利质权（第440条）：有权利凭证的自交付时设立；无权利凭证的自登记时设立；汇票出质背书记载"质押"（担保制度解释第58条）；应收账款质权自办理出质登记时设立（第445条），应收账款债务人确认后不得以债权不存在抗辩（担保制度解释第61条）。
  3. 留置权（第447、448条）：债权人合法占有债务人的动产＋债权与该动产属于同一法律关系（企业间留置除外）＋债务已届清偿期。留置权效力优先于抵押权和质权（第456条）。
  4. 商事留置（第448条但书）：企业之间留置不以同一法律关系为要件，但不适用于非企业持续经营债权（担保制度解释第62条）。
- **命题角度**：转质效力；仓单质权与仓储物担保的竞合顺位（担保制度解释第59条）；留置权成立要件的辨析。

### 2.6 共有【中频】

- **核心法条**：《民法典》第297—310条。
- **可背诵要点**：
  1. 按份共有与共同共有的区分：共有人对共有物份额有明确约定的为按份共有，否则推定为共同共有（家庭关系、夫妻财产）。
  2. 处分规则（第301条）：处分共有不动产/动产、对共有物作重大修缮、变更性质或用途的，须经占份额2/3以上的按份共有人或全体共同共有人同意（另有约定除外）。
  3. 优先购买权（第305、306条）：按份共有人转让份额时，其他共有人在同等条件下有优先购买权；须在合理期间内行使（15日），通知应载明份额与价格。
  4. 共有物分割（第303、304条）：共有人可随时请求分割（另有约定除外），共同共有原则上只有在共有基础丧失或重大理由时才可分割。
- **命题角度**：按份共有人份额转让中优先购买权的行使规则与冲突处理；共有物管理费用的分担；与物权变动结合考查。

## 三、合同编

### 3.1 合同效力与合同编通则司法解释【高频】

- **核心法条**：《民法典》第502—509条；合同编通则解释第1—19条。
- **可背诵要点**：
  1. 合同生效的一般规则与批准生效合同（第502条）：依法须办理批准手续的合同，未批准不影响合同中履行报批义务条款的效力，未履行报批义务的承担违约责任（合同编通则解释第12条）。
  2. 强制性规定与公序良俗（第153条）：违反法律、行政法规的强制性规定的合同无效，但该强制性规定不导致合同无效的除外（管理性强制性规定）；违反公序良俗无效。合同编通则解释第16条确立"强制性规定并不当然导致无效"的审查思路。
  3. 格式条款（第496—498条）：提供方负有提示说明义务，未履行义务致对方未注意与其有重大利害关系的条款，对方可主张该条款不成为合同内容；不合理免除或减轻自身责任、加重对方责任、排除对方主要权利的条款无效。
  4. 无权处分合同有效（第597条），不影响物权变动的判断。
- **命题角度**：合同编通则解释为2024年以来命题热点——报批义务条款效力、格式条款的提示说明义务（电子合同弹窗）、强制性规定的类型化判断。

### 3.2 合同履行中的抗辩权与合同保全【高频】

- **核心法条**：《民法典》第525—527条（同时履行、先履行、不安抗辩权）、第535—542条（代位权、撤销权）；合同编通则解释第33—46条。
- **可背诵要点**：
  1. 三大抗辩权：同时履行抗辩权、先履行抗辩权、不安抗辩权（后履行方有丧失或可能丧失履行能力情形时，先履行方可中止履行并通知对方，对方提供担保或恢复履行能力的应恢复履行，否则可解除）。
  2. 代位权（第535条）：债务人怠于行使到期债权（含从权利）影响债权人到期债权实现的，债权人可以自己名义代位行使，但专属于债务人自身的债权除外；行使范围以债权人债权为限，必要费用由债务人负担；代位权诉讼胜诉后，由债务人直接向债权人履行（合同编通则解释第33—35条）。
  3. 撤销权（第538—541条）：无偿处分（放弃债权/债权担保、无偿转让财产、恶意延长履行期限）与有偿低价转让（明显不合理低价/高价，相对人知道或应当知道）两类；撤销权行使期限为知道或应当知道撤销事由之日起1年，行为发生之日起5年（除斥期间）。
- **命题角度**：代位权与撤销权的主客观要件差异；撤销权的除斥期间；与担保制度（撤销担保行为）结合考查。

### 3.3 违约责任与合同解除【高频】

- **核心法条**：《民法典》第563、565、577、580、584、585条；合同编通则解释第59—68条。
- **可背诵要点**：
  1. 违约形态：预期违约（明示/默示，第578条）、实际违约（迟延履行、不完全履行）、根本违约。
  2. 法定解除（第563条）：①不可抗力致合同目的不能实现；②预期违约；③迟延履行主要债务经催告后在合理期限内仍不履行；④迟延履行或其他违约行为致合同目的不能实现；⑤其他。合同解除不以催告为前置（第563条第2款新增，不定期继续性合同可随时解除但应合理期限前通知）。
  3. 继续履行限制（第580条）：法律上或事实上不能履行、不适于强制履行或履行费用过高、合理期限内未请求履行的，不能强制继续履行，可请求解除合同并主张违约责任。
  4. 损害赔偿：完全赔偿原则＋可预见规则（第584条）；违约金调整规则（第585条）——约定违约金过分高于损失（超过30%）的可请求减少；定金与违约金择一适用（第588条）。
  5. 违约精神损害：因违约损害对方人格权造成严重精神损害的，可请求精神损害赔偿（第996条）。
- **命题角度**：极为重要。解除权行使方式（通知解除/诉讼解除，第565条）；违约金、定金、损失赔偿的计算；双方违约与情势变更（第533条，不能撤销只能变更或解除）。

### 3.4 买卖合同【高频】

- **核心法条**：《民法典》第595—647条，重点为第604—611条（风险负担）、第641—643条（所有权保留）。
- **可背诵要点**：
  1. 风险负担规则（第604条）：交付前由出卖人承担，交付后由买受人承担（交付主义）。在途货物买卖风险自合同成立时转移（第606条）；约定交付地点不明且标的物需运输的，货交第一承运人后风险转移（第607条）；因买受人原因迟延受领的，自违约之日起风险转移（第608条）。风险负担不影响违约责任的追究（第610条）。
  2. 孳息归属与风险负担同步（第630条）。
  3. 分期付款买卖（第634条）：买受人未支付到期价款达到全部价款的1/5的，出卖人可要求一次性支付全部价款或解除合同。
  4. 所有权保留（第641条）：标的物所有权保留不影响风险转移；出卖人取回权与买受人回赎权；对抗善意第三人以登记为要件。
  5. 质量异议期间（第620—623条）：约定的检验期间不得过短；未约定检验期间的，及时检验并在合理期间内通知，最长自收到之日起2年（有质量保证期的除外）。
- **命题角度**：风险负担与交付主义（占有改定、货交承运人特殊规则）；一物数卖与风险负担结合；所有权保留中的取回权行使条件。

### 3.5 借款合同（民间借贷）【高频】

- **核心法条**：《民法典》第667—680条；民间借贷司法解释（2020年修订）。
- **可背诵要点**：
  1. 民间借贷利率：以合同成立时1年期贷款市场报价利率（LPR）4倍为上限（2020年修订后废除了24%/36%两线三区规则）；逾期利率、违约金等费用总计不得超过该上限。
  2. 利息不得预先扣除（第670条）：预先扣除的按实际借款数额计算。
  3. 自然人之间借款合同为实践合同（自实际提供借款时成立，第679条）；未约定利息视为不支付利息（第680条）；利息约定不明的，自然人之间视为无息。
  4. 借新还旧：担保制度解释第16条——借新还旧时旧贷担保人原则上不承担责任，新贷担保人知道或应当知道的除外。
- **命题角度**：利率上限计算（LPR 4倍）；"砍头息"的认定；自然人借贷的实践性特征；法定代表人以公司名义借款的担保效力。

### 3.6 租赁合同（房屋租赁为重中之重）【高频】

- **核心法条**：《民法典》第703—734条；城镇房屋租赁合同解释。
- **可背诵要点**：
  1. 租赁期限不得超过20年，超过部分无效；6个月以上的应当采用书面形式，未采用书面形式且无法确定期限的视为不定期租赁（第707条），当事人可随时解除但出租人应合理期限前通知。
  2. 买卖不破租赁（第725条）：租赁物在承租人按约占有期间发生所有权变动的，租赁合同继续有效；但出租前已设立抵押权（未告知或已登记）或因查封导致所有权变动的除外。
  3. 房屋承租人优先购买权（第726—728条）：须同等条件，15日内未表示购买视为放弃；房屋共有人、近亲属（配偶、父母、子女、兄弟姐妹、祖父母、外祖父母、孙子女、外孙子女）买卖时不得主张；侵害优先购买权仅可主张赔偿，不能主张买卖合同无效。
  4. 转租（第716—718条）：经同意转租的，原租赁合同继续有效；未经同意转租的，出租人可解除合同，但知道或应当知道6个月内未提异议的视为同意。
  5. 租赁物维修义务由出租人承担；租赁物危及承租人安全健康的，承租人可随时解除（第731条）。
  6. 共同居住人继续承租权（第732条）：承租人死亡后，与其生前共同居住的人或共同经营人可以按原合同继续租赁。
- **命题角度**：买卖不破租赁与抵押权实现的顺位冲突；优先购买权的行使限制；非法转租中6个月默示同意规则；不定期租赁的随时解除权。

### 3.7 建设工程合同【中频】

- **核心法条**：《民法典》第788—808条；建设工程施工合同解释（一）。
- **可背诵要点**：
  1. 建设工程价款优先受偿权（第807条）：承包人可就建设工程折价或拍卖价款优先受偿，优先于抵押权和其他债权；行使期限为自发包人应付款之日起18个月；消费者购房人的物权期待权＞建设工程价款优先受偿权＞不动产抵押权。
  2. 违法转包、分包合同无效，但工程质量合格的可参照合同约定折价补偿（背靠背条款、实际施工人规则——实际施工人可以发包人为被告主张权利，发包人在欠付工程款范围内担责）。
  3. 建设工程合同无效的情形：无资质/超越资质、借用资质挂靠、必须招标而未招标、违法分包转包。
  4. 竣工日期与竣工验收：验收合格之日；未验收擅自使用的，自转移占有之日起视为竣工验收合格。
- **命题角度**：价款优先受偿权的顺位与行使期限（18个月起算）；实际施工人突破合同相对性；工程价款结算以备案合同为准。

### 3.8 保证合同【高频】

- **核心法条**：《民法典》第681—702条；担保制度解释第25—36条。
- **可背诵要点**：
  1. 保证方式推定（第686条）：当事人对保证方式没有约定或约定不明的，按一般保证处理（民法典重大修改，改变了原担保法"推定为连带责任保证"的规则）。
  2. 一般保证的先诉抗辩权（第687条）及例外（债务人下落不明、已进入破产程序等6种情形）；连带责任保证无先诉抗辩权。
  3. 保证期间（第692、693条）：有约定按约定，约定不明或没有约定的为主债务履行期限届满之日起6个月；保证期间届满，债权人未主张权利的，保证责任消灭。
  4. 保证人追偿权与法定代位权（第700条）；债权人转让债权须通知保证人，否则对保证人不发生效力（第696条）；债务转移未经保证人书面同意，保证人不再承担保证责任（第697条）；主债务加入不影响保证责任（第697条第2款）。
  5. 借新还旧：担保制度解释第16条明确旧贷担保人免责、新贷担保人知情的担责规则。
- **命题角度**：保证方式推定的判断（"不能履行时""代偿"等表述的解释）；保证期间6个月的计算与保证诉讼时效的衔接；公司担保（法定代表人越权担保的效力，担保制度解释第7条）。

## 四、人格权编【中频】

- **核心法条**：《民法典》第990—1039条，重点为第994、995、997、1010、1019、1024、1032、1033条。
- **可背诵要点**：
  1. 人格权类型与专属性（第990、992条）：人格权不得放弃、转让或继承；自然人人格权保护具有开放性，法人、非法人组织仅享名称权、名誉权、荣誉权（封闭列举）。
  2. 人格权请求权（第995、997条）：停止侵害、排除妨碍、消除危险、消除影响、恢复名誉、赔礼道歉请求权不适用诉讼时效；人格权侵害禁令制度（第997条）是新增亮点。
  3. 死者人格利益保护（第994条）：死者近亲属（配偶、子女、父母，无的近亲属）可请求行为人承担民事责任。
  4. 肖像权（第1018—1023条）：未经同意不得制作、使用、公开他人肖像（"以营利为目的"要件被删除）；声音参照肖像权保护（第1023条）。
  5. 名誉权（第1024条）：以侮辱、诽谤等方式侵害；新闻报道与舆论监督的合理核实义务（第1025、1026条）——捏造歪曲事实、未尽核实义务等除外。
  6. 隐私权（第1032、1033条）：隐私＝私人生活安宁＋私密空间、私密活动、私密信息；明确列举刺探、侵扰、泄露、公开等侵害方式（电话短信骚扰、偷拍偷录、公开私密信息等）。
  7. 个人信息保护（第1034—1038条）：处理个人信息遵循合法、正当、必要原则；敏感个人信息（生物识别、医疗健康、行踪等）须单独同意。
  8. 性骚扰（第1010条）：机关、企业、学校等单位负有防止和制止义务。
- **命题角度**：肖像权与名誉权竞合（配图配文错误使用）；隐私权与个人信息的边界；违约精神损害赔偿（第996条）与侵权精神损害赔偿（第1183条）的适用。

## 五、婚姻家庭编

### 5.1 结婚与离婚制度【高频】

- **核心法条**：《民法典》第1046—1091条；婚姻家庭编解释（一）、解释（二）。
- **可背诵要点**：
  1. 无效婚姻与可撤销婚姻（第1051—1053条）：重婚、有禁止结婚的亲属关系、未到法定婚龄的无效；胁迫结婚的可在胁迫终止之日起1年内请求撤销；隐瞒重大疾病的，另一方可在知道或应当知道之日起1年内请求撤销（第1053条）。
  2. 夫妻忠实义务与过错离婚：准予离婚的法定情形（第1079条）——重婚或与他人同居、家庭暴力或虐待遗弃、赌博吸毒屡教不改、感情不和分居满2年、其他；判决不准离婚后又分居满1年，再次起诉应准予离婚。
  3. 冷静期制度（第1077条）：协议离婚申请后30日内任何一方可撤回；届满后30日内双方须亲自领取离婚证。
  4. 离婚救济：家务劳动补偿（第1088条）、离婚经济帮助（第1090条）、离婚损害赔偿（第1091条，无过错方有权请求）；一方挥霍、转移、隐匿夫妻共同财产的，离婚时可少分或不分（第1092条）。
  5. 彩礼返还：婚姻家庭编解释（二）第5条——未办理结婚登记、或虽登记但未共同生活、或婚前给付致给付方生活困难的（离婚时），可请求返还。
  6. 抢夺、藏匿未成年子女：解释（二）第12—14条——另一方可申请人身安全保护令或人格权侵害禁令；离婚诉讼中抢夺藏匿子女一方原则上不宜直接抚养子女。
- **命题角度**：可撤销婚姻的1年除斥期间；离婚损害赔偿与过错方"少分不分"的竞合；彩礼返还规则的适用（结合2026年实务热点）。

### 5.2 夫妻共同财产与共同债务【高频】

- **核心法条**：《民法典》第1062—1064、1087条；婚姻家庭编解释（一）、解释（二）。
- **可背诵要点**：
  1. 夫妻共同财产（第1062条）：工资奖金劳务报酬、生产经营投资收益、知识产权收益、继承或受赠财产（遗嘱或赠与合同确定只归一方的除外）、其他共同财产。
  2. 夫妻个人财产（第1063条）：婚前财产、人身损害赔偿或补偿、遗嘱或赠与确定只归一方的财产、专用生活用品、其他。
  3. 夫妻共同债务（第1064条）：共债共签＋事后追认；为家庭日常生活需要所负债务；超出日常需要但用于共同生活、共同生产经营的（债权人负举证责任）。
  4. 父母出资购房（解释（二）第8条）：一方父母全额出资且无明确约定的，离婚分割时房屋可判归出资人子女一方，综合考量共同生活、孕育子女、离婚过错等因素确定补偿；双方父母出资的按出资来源及比例为基础处理。
  5. 直播打赏（解释（二）第6条）：用夫妻共同财产打赏明显超出家庭一般消费水平、严重损害共同财产利益的，可认定为"挥霍"，另一方可在婚内请求分割或离婚时请求少分不分。
  6. 婚内分割共同财产（第1066条）：一方隐匿转移变卖毁损挥霍共同财产或伪造债务，或一方负有法定扶养义务人患重大疾病而另一方不同意支付医疗费的，可在婚内请求分割。
- **命题角度**：近年命题热点——父母出资购房的性质认定与补偿规则；共同债务的举证责任分配（债权人举证"用于共同生活"）；打赏、赠与第三人（婚外赠与无效，解释（二）第7条）的效力。

## 六、继承编

### 6.1 法定继承与代位继承【高频】

- **核心法条**：《民法典》第1122—1132条；继承编解释（一）。
- **可背诵要点**：
  1. 继承顺位（第1127条）：第一顺序——配偶、子女、父母；第二顺序——兄弟姐妹、祖父母、外祖父母。子女包括婚生子女、非婚生子女、养子女和有扶养关系的继子女；遗产由第一顺序继承，第二顺序仅在无第一顺序时继承。
  2. 代位继承（第1128条）：被继承人的子女先于被继承人死亡的，由子女的直系晚辈血亲代位继承；被继承人的兄弟姐妹先于被继承人死亡的，由兄弟姐妹的子女代位继承（民法典扩大代位继承范围）。代位继承人只能继承其父母有权继承的份额。
  3. 转继承：继承开始后、遗产分割前继承人死亡，其应继份额转由该继承人的继承人继承（第1152条）。
  4. 继承权丧失（第1125条）：故意杀害被继承人、为争夺遗产杀害其他继承人、遗弃或虐待情节严重、伪造篡改隐匿销毁遗嘱情节严重、以欺诈胁迫手段迫使或妨害设立变更撤回遗嘱情节严重的；但有宽恕制度（第3—5项情形经被继承人宽恕或事后表示原谅的恢复）。
  5. 胎儿预留份（第1155条）：遗产分割时应为胎儿保留继承份额，娩出时死体的按法定继承办理。
  6. 遗产酌给请求权（第1131条）：继承人以外的依靠被继承人扶养的人或对被继承人扶养较多的人，可分给适当遗产。
- **命题角度**：继子女/养子女的认定（收养须登记，未登记不成立养子女身份）；代位继承与转继承的区分；胎儿份额的处理；丧失继承权与宽恕。

### 6.2 遗嘱继承与遗赠【高频】

- **核心法条**：《民法典》第1133—1144条；继承编解释（一）第24—29条。
- **可背诵要点**：
  1. 遗嘱形式（第1134—1139条）：自书遗嘱（亲笔书写、签名、注明年月日）、代书遗嘱、打印遗嘱（新增，每页签名注日期）、录音录像遗嘱、口头遗嘱（危急情况，须两个以上见证人，危急消除后能立书面遗嘱则口头遗嘱无效）、公证遗嘱。
  2. 数份遗嘱冲突（第1142条）：立有数份内容相抵触的遗嘱，以最后的遗嘱为准（民法典废除"公证遗嘱效力优先"规则）。
  3. 见证人限制（第1140条）：无/限制民事行为能力人、继承人受遗赠人、与继承人受遗赠人有利害关系的人不得作为见证人；利害关系人包括其债权人、债务人、共同经营的合伙人（继承编解释（一）第24条）。
  4. 特留份（第1141条）：遗嘱应为缺乏劳动能力又没有生活来源的继承人保留必要份额，未保留的遗产处理时先留必要份额（继承编解释（一）第25条）。
  5. 无效遗嘱（第1143条）：无/限制民事行为能力人所立、受欺诈胁迫所立、伪造的、被篡改的（篡改内容无效）。
  6. 遗赠扶养协议优先（第1123条、继承编解释（一）第3条）：有协议按协议办理，协议与遗嘱抵触的按协议处理。
  7. 遗嘱与继承权丧失（继承编解释（一）第8条）：继承人实施第1125条第1款第1、2项行为的，即使被指定为遗嘱继承人也确认丧失继承权。
- **命题角度**：遗嘱形式要件瑕疵（签名、日期、见证人资格）的认定（高频）；打印遗嘱、录像遗嘱的合法性判断；口头遗嘱效力随危急情形消除而消灭；数份遗嘱效力冲突的解决。

### 6.3 遗产的分配【中频】

- **核心法条**：《民法典》第1130、1132、1144、1153条；继承编解释（一）第4条。
- **可背诵要点**：
  1. 遗产范围（第1122条）：自然人死亡时遗留的个人合法财产；夫妻共同财产先分割一半归配偶，剩余为遗产（第1153条）；遗产中应先清偿税款和债务，但以遗产实际价值为限（限定继承，第1161条）。
  2. 分配原则（第1130条）：同一顺序一般均等；对生活困难缺乏劳动能力的照顾；尽了主要扶养义务或共同生活的可以多分；不尽扶养义务的应当不分或少分。
  3. 遗嘱继承人依遗嘱取得遗产后，仍有权依法定继承取得遗嘱未处分的遗产（继承编解释（一）第4条）。
  4. 附义务遗嘱（第1144条）：无正当理由不履行义务的，经请求可取消其接受附义务部分遗产的权利。
  5. 遗产分割的时间与溯及：继承自被继承人死亡时开始（第1121条）；分割前遗产由继承人共同共有。
- **命题角度**：继承人与债权人关系（遗产债务清偿顺序：税款与债务的顺位、限定继承）；遗嘱未处分部分与法定继承的衔接；遗赠扶养协议的优先效力。

## 七、侵权责任编

### 7.1 归责原则【高频】

- **核心法条**：《民法典》第1164—1187条。
- **可背诵要点**：
  1. 过错责任（第1165条）：一般侵权，谁主张谁举证；过错推定（第1165条第2款）举证责任倒置。
  2. 无过错责任（第1166条）：法定情形，行为与损害有因果关系即担责，如监护人责任（第1188条）、用人单位责任（第1191条）、产品责任、饲养动物责任、高度危险责任、环境污染责任。
  3. 公平分担损失（第1186条）：仅限法律明文规定的情形（如第1190条暂时丧失意识无过错、见义勇为受益补偿、高空抛物补偿）。
  4. 免责与减责事由（第1173—1177条）：受害人过错、受害人故意、第三人原因、不可抗力、正当防卫、紧急避险、自甘风险（第1176条，文体活动）、自助行为（第1177条）。
  5. 多数人侵权（第1168—1172条）：共同侵权连带责任；共同危险行为（不能确定具体侵权人的，行为人承担连带责任）；无意思联络的数人侵权——足以造成全部损害的连带，按份（难以确定责任大小的平均）。
- **命题角度**：归责原则的准确归类是侵权题的第一步；过错推定与无过错责任的法定情形列表记忆；自甘风险与体育活动的免责适用。

### 7.2 特殊侵权责任【高频】

- **核心法条**：《民法典》第1191—1258条。
- **可背诵要点**：
  1. 用人单位责任（第1191条）：工作人员执行工作任务致害，由用人单位承担无过错责任，可向故意或重大过失的工作人员追偿；劳务派遣中由用工单位担责，派遣单位有过错的承担相应责任。
  2. 个人劳务责任（第1192条）：接受劳务一方担责，可向故意或重大过失的提供劳务一方追偿；提供劳务一方因劳务受伤的，按双方过错分担。
  3. 产品责任（第1202—1207条）：生产者、销售者对缺陷产品致害承担无过错责任；被侵权人可选择向生产者或销售者索赔（不真正连带）；惩罚性赔偿——明知缺陷仍生产销售致人死亡或健康严重损害，可主张价款2倍以下惩罚性赔偿。
  4. 机动车交通事故责任：机动车与行人、非机动车之间适用无过错责任（机动车一方无过错的承担不超过10%责任）；买卖交付但未登记的机动车发生事故，由受让人担责；使用人担责情形（租赁、借用——所有人有过错的担相应责任）；盗抢车辆由盗抢人担责。2026年新司法解释（道路交通事故损害赔偿解释（二））明确乘车人开车门致损等规则，虽未入大纲但属实务热点。
  5. 医疗损害责任（第1218—1228条）：医疗损害一般过错责任（患者举证）；推定医疗机构有过错的三种情形（第1222条：违反诊疗规范、隐匿或拒绝提供病历资料、伪造篡改销毁病历）；因药品、消毒产品、医疗器械缺陷致害的，患者可向医疗机构或生产者索赔。
  6. 饲养动物责任（第1245—1251条）：饲养动物致害无过错责任；被侵权人故意或重大过失的可以不担或减轻（禁止饲养的烈性犬等危险动物无免责事由，第1247条）；动物园动物过错推定；遗弃逃逸动物期间致害由原饲养人管理人担责。
  7. 高空抛物坠物（第1254条）：能查明侵权人的由侵权人担责；难以确定的，由可能加害的建筑物使用人给予补偿（证明自己不是侵权人的除外），补偿后有权向侵权人追偿；物业未采取必要安保措施的担相应责任；公安机关应依法及时调查（公安查明义务，区别于旧法）。
  8. 物件损害责任（第1252—1258条）：建筑物等倒塌——建设单位与施工单位连带（无过错），因其他责任人原因的可追偿；脱落坠落、堆放物、林木折断、地面施工、窨井等致害适用过错推定。
  9. 网络侵权责任（第1194—1197条）：网络用户、平台过错责任；"通知—删除—反通知—恢复"规则；平台知道或应当知道侵权未采取措施的承担连带责任。
- **命题角度**：各类特殊侵权归责原则的列表比对记忆；机动车责任主体认定（出租出借、挂靠、盗抢、买卖未过户）；高空抛物中"可能加害的建筑物使用人"补偿责任的要件与追偿；医疗过错推定的三种情形。

## 八、2026年备考提示

1. **分值分布**：民法客观题约占45—50分，主观题（民商法综合案例）约55分，与刑法并列第一梯队。"得民刑者得法考"。
2. **重者恒重**：可撤销民事法律行为（考查20次）、共同担保（16次）、民事法律关系识别（15次）、遗嘱继承（10次）为统计上的最高频考点；物权变动、善意取得、担保物权、违约责任、房屋租赁每年必考。
3. **司法解释热点**：担保制度解释（共同担保追偿、禁止转让抵押财产约定、未登记动产抵押效力、价款优先权扩张）、合同编通则解释（报批义务、格式条款、代位权撤销权细化）、婚姻家庭编解释（二）（父母出资购房、直播打赏、抢夺藏匿子女、彩礼返还）须重点研读。
4. **新规动向**：2026年道路交通事故损害赔偿解释（二）明确开车门致损、车辆所有人与使用人责任等规则，为实务热点，建议作拓展了解。
5. **复习方法**：先搭体系（总则—物权—合同—人格权—婚姻家庭—继承—侵权），再抓高频，以题带点；主观题训练"结论先行、要件齐备、法条定位"的答题规范。
