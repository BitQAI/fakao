# 《公司法》新旧对照表（2018年修正版 vs 2023年修订版）

> 编制说明：本对照表以《中华人民共和国公司法》（2018年10月26日第四次修正，旧法，共13章218条）为对照基准，逐条梳理《中华人民共和国公司法》（2023年12月29日第十四届全国人民代表大会常务委员会第七次会议第二次修订，新法，共15章266条，2024年7月1日起施行）的主要修改内容。本表为法律学习与备考资料，仅供参考，具体适用以官方文本为准。

---

## 一、修订概况

| 项目 | 旧法（2018修正） | 新法（2023修订） |
| --- | --- | --- |
| 立法进程 | 1993年制定，历经1999、2004、2005（全面修订）、2013、2018年五次修改 | 2021年12月一审稿、2022年12月二审稿、2023年8月三审稿、2023年12月29日四审通过并公布，2024年7月1日施行 |
| 章节数 | 13章 | 15章 |
| 条文数 | 218条 | 266条 |
| 修改规模 | —— | 删除16个条文，新增和修改228个条文，其中实质性修改112个条文，系1993年立法以来规模最大的一次修订 |

新法修订的七条主线：**①完善公司资本制度（五年实缴、加速到期、失权制度）；②优化公司治理结构（审计委员会、职工董事、股东会董事会职权调整）；③加强股东权利保护（知情权扩张、异议股东回购、双重代表诉讼）；④强化控股股东、实际控制人和董监高责任（影子董事、事实董事）；⑤完善公司设立与退出制度（简易注销、强制注销、简易减资）；⑥完善国家出资公司特别规定；⑦完善公司债券制度（债券持有人会议、受托管理人）。**

## 三、重点条文逐条对照

### （一）总则与公司登记制度（新法第1—41条）

| 旧法条文 | 新法条文 | 主要变化点/说明 |
| --- | --- | --- |
| 第1条 立法目的 | 第1条 | 立法目的新增"完善中国特色现代企业制度""弘扬企业家精神"表述 |
| 第2条 公司定义 | 第2条 | 基本延续：本法所称公司指有限责任公司和股份有限公司 |
| 第3条 公司独立责任与股东有限责任 | 第3条、第4条 | 拆分为两条，明确股东以其认缴（认购）的出资（股份）为限承担责任；章程约束力范围延续 |
| 第8条 公司名称 | 第6条 | 新增**公司名称权**保护条款："公司应当有自己的名称。公司名称应当符合国家有关规定。公司的名称权受法律保护。" |
| 第13条 法定代表人（董事长、执行董事或经理担任） | 第10条 | **重大修改**：法定代表人由"代表公司执行事务的董事或者经理"担任，不再限定董事长/执行董事；可依据章程由任意一名执行董事担任（外部董事、独立董事除外） |
| —— | 第11条 | 新增：法定代表人以公司名义从事民事活动的法律后果由公司承受；章程或股东会对代表权限制不得对抗善意相对人 |
| 第12条 法定代表人变更登记 | 第12条 | 新增法定代表人辞任后公司应及时确定新的法定代表人并办理变更登记；辞任的董事、经理应同时辞任法定代表人 |
| 第15条 对外投资（不得成为连带责任出资人） | 第14条 | 修改：删去"不得成为对所投资企业的债务承担连带责任的出资人"的绝对禁止，改为"法律另有规定的除外"；新增第2款：**公司可以约定对所投资企业的债务承担连带责任**（合伙型对外投资合法化） |
| 第16条 对外担保决议程序 | 第15条 | 基本延续：为股东或实际控制人提供担保须经股东会决议，被担保股东回避表决 |
| 第20条第3款 人格否认（纵向） | 第23条 | **重大扩充**：新增第2款**横向人格否认**——股东利用其控制的两个以上公司实施滥用行为的，各公司对任一公司债务承担连带责任；新增第3款：只有一个股东的公司，股东不能证明公司财产独立于股东自己财产的，应当对公司债务承担连带责任（原一人公司第63条内容上移，适用范围扩及一人股份公司） |
| —— | 第19条、第20条 | 新增**社会责任条款**：公司从事经营活动应遵守法律法规、遵守社会公德、商业道德，诚实守信，接受政府和社会监督，承担社会责任 |
| —— | 第24条 | 新增：**股东会、董事会、监事会会议可以采用电子通信方式召开和表决**；章程另有规定除外 |
| 第22条 决议无效与可撤销（60日撤销权） | 第26条 | 修改：保留60日起算规则；**新增第2款**：未被通知参加股东会会议的股东，自知道或者应当知道决议作出之日起60日内可请求撤销，但自决议作出之日起**1年内**未行使的，撤销权消灭 |
| —— | 第27条 | **新增决议不成立制度**，明确四种情形：（1）未召开会议作出决议；（2）会议未对决议事项进行表决；（3）出席人数或所持表决权数未达法定或章程规定；（4）同意人数或表决权数未达法定或章程规定 |
| —— | 第28条第2款 | **新增**：决议被宣告无效、撤销或确认不成立的，公司根据该决议与**善意相对人**形成的民事法律关系不受影响（保护交易安全） |
| 第6条、第33条 登记与公示 | 第29—32条、第40条 | 整合为第二章"公司登记"：明确登记事项（名称、住所、注册资本、经营范围、法定代表人姓名、股东或发起人姓名或名称等）；**新增第40条**：公司应通过国家企业信用信息公示系统公示认缴实缴出资额、出资方式、出资日期、股权变更、行政许可等信息，且应确保真实、准确、完整 |
| —— | 第33条 | 新增：**电子营业执照**与纸质营业执照具有同等法律效力 |

### （二）有限责任公司设立与注册资本制度（新法第42—55条）——资本制度核心

| 旧法条文 | 新法条文 | 主要变化点/说明 |
| --- | --- | --- |
| 第24条 股东人数（2—50人） | 第42条 | 修改：股东人数上限50人不变，**取消下限**——"由一个以上五十个以下股东出资设立"，为一人公司提供统一基础 |
| —— | 第43条 | 新增**设立协议**制度：设立时的股东可以签订设立协议，明确各自在设立过程中的权利义务（尤其规范股权代持、对赌等安排） |
| 第25条 章程应载明事项 | 第46条 | 基本延续，增列股东姓名（名称）等内容 |
| 第26条 认缴制（无期限限制） | 第47条 | **最重大修改——注册资本限期实缴制**："全体股东认缴的出资额由股东按照公司章程的规定**自公司成立之日起五年内缴足**"；法律、行政法规以及国务院决定对实缴、最低限额、出资期限另有规定的除外。彻底终结"认缴无期限、注册资本虚高"的乱象 |
| 第27条 出资方式（货币、实物、知识产权、土地使用权等） | 第48条 | 修改：出资形式明确新增**股权、债权**两类可用货币估价并可依法转让的非货币财产；仍禁止劳务、信用、自然人姓名、商誉、特许经营权等出资 |
| 第28条 股东按期足额缴纳出资 | 第49条 | 修改：新增第3款——股东未按期足额缴纳出资的，除足额缴纳外，还应对**给公司造成的损失承担赔偿责任**（赔偿责任法定化） |
| 第30条 非货币出资不足，设立时其他股东连带责任 | 第50条 | 延续：设立时其他股东与瑕疵出资股东承担连带责任（新法进一步明确与第88条衔接） |
| —— | 第51条 | **新增董事催缴义务**：董事会应当对股东出资情况进行核查，发现未按期足额缴纳出资的，应当由公司向该股东发出**书面催缴书**；未及时履行核查催缴义务给公司造成损失的，负有责任的**董事应当承担赔偿责任** |
| —— | 第52条 | **新增股东失权制度**：股东未按期缴纳出资，经公司书面催缴并给予**不少于60日宽限期**仍不缴纳的，公司**经董事会决议**可向其发出书面**失权通知**，自通知发出之日起该股东**丧失其未缴纳出资的股权**；失权股权应依法转让、减资注销或由其他股东按比例缴纳；失权股东对失权前未按期缴纳出资给公司造成的损失仍应承担赔偿责任 |
| 第35条 禁止抽逃出资 | 第53条 | 修改：抽逃出资给公司造成损失的，**负有责任的董事、监事、高级管理人员**与该股东承担连带赔偿责任（追责对象扩展至董监高） |
| —— | 第54条 | **新增认缴出资加速到期制度**："公司不能清偿到期债务的，公司或者**已到期债权的债权人**有权要求已认缴出资但未届出资期限的股东**提前缴纳出资**。"不再要求"破产/清算前提"或九民纪要式的"具备破产原因"，门槛大幅降低（司法实务对"入库规则"仍有争议，详见2025年司法解释征求意见稿第24条） |
| —— | 第44条、第45条 | 新增：设立时股东为设立公司从事民事活动的责任承担规则；设立登记前置审批的90日登记期限 |

### （三）有限责任公司组织机构（新法第56—83条）

| 旧法条文 | 新法条文 | 主要变化点/说明 |
| --- | --- | --- |
| 第32条 股东名册 | 第56条 | 基本延续，明确记载事项与记载效力的对抗要件 |
| 第33条 股东知情权（查阅章程、会议记录、财务会计报告，查阅会计账簿） | 第57条 | **重大扩张**：（1）查阅复制范围新增**股东名册、会计凭证**；（2）查阅范围扩展至**全资子公司**的相关材料；（3）股东查阅会计账簿、会计凭证可以**委托会计师事务所、律师事务所等中介机构**进行；（4）保密义务明确 |
| 第57—64条 一人有限责任公司特别规定（自然人只能设一个一人公司、一人公司不能投资设立一人公司、强制审计、财产独立举证责任倒置等） | 第58条等 | **专节删除，一人公司限制全面取消**：（1）允许一个自然人设立**多个**只有一个股东的公司；（2）允许其设立的公司再投资设立一人公司；（3）一人有限责任公司、一人股份有限公司统一适用"只有一个股东的公司"规则；（4）原第63条举证责任倒置内容并入第23条第3款，适用范围扩大 |
| 第37条 股东会职权（含"决定公司的经营方针和投资计划"） | 第59条 | 修改：**删除"决定公司的经营方针和投资计划""审议批准公司的年度财务预算方案、决算方案"**两项职权（经营自主权回归董事会），职权清单整体简化；股东会可授权董事会对发行公司债券作出决议 |
| 第42条 股东按出资比例行使表决权 | 第65条 | 延续：章程另有规定的除外 |
| 第43条 决议通过比例（修改章程等须三分之二以上表决权） | 第66条 | 修改：**首次明确普通决议的通过比例**——"股东会的议事方式和表决程序，除本法有规定的外，由公司章程规定。股东会作出决议，应当经代表**过半数**表决权的股东通过"；重大事项仍须三分之二以上 |
| 第44条 董事会成员3—13人 | 第68条 | 修改：董事会成员为**三人以上**（取消上限）；职工人数**300人以上**且无职工监事的有限公司，董事会中**应当有职工代表**（原为国有独资公司、两个以上国有主体投资公司要求）；新增第2款：审计委员会制度预留 |
| 第46条 董事会职权 | 第67条 | 修改：删除"制订公司的年度财务预算方案、决算方案"等，与股东会职权调整联动 |
| —— | 第69条 | **新增审计委员会制度（有限公司）**：可以按照章程规定在董事会中设置**由董事组成的审计委员会，行使监事会职权，不设监事会或者监事** |
| 第45条 董事任期（每届不得超过3年） | 第70条 | 延续任期3年；**新增董事辞任规则**：董事辞任应书面通知公司，自通知到达公司之日生效；董事辞任导致董事会成员低于法定人数的，在改选出的董事就任前原董事仍应履行职务 |
| —— | 第71条 | **新增董事无因解任与赔偿**：股东会可以决议解任董事，决议作出之日解任生效；**无正当理由在任期届满前解任董事的，该董事可以请求公司予以赔偿** |
| 第49条 经理职权（法定列举八项） | 第74条 | 修改：删除法定职权列举，改为"经理对董事会负责，**根据公司章程的规定或者董事会的授权**行使职权"（职权章定化、灵活化） |
| 第50条 执行董事（可代行董事会职权） | 第75条 | 修改：**规模较小或者股东人数较少的有限责任公司，可以不设董事会，设一名董事**，行使本法规定的董事会职权（"执行董事"称谓取消） |
| 第51条 监事会不少于3人 | 第76条 | 修改：监事会成员3人以上不变；**职工代表比例不得低于三分之一**的要求明确；规模较小或股东人数较少的公司可不设监事会、设一名监事 |

## 四、增加条文与删除条文说明

### （一）主要新增条文（新法首创或首度入法）

1. **公司登记专章（第29—41条）**：登记事项、登记公示效力、电子营业执照、信息公示义务（原散落规定系统化）。
2. **横向人格否认（第23条第2款）**：关联公司人格混同的连带责任，明确司法实践中"揭开公司面纱"的横向适用。
3. **决议不成立制度（第27条）**：四类情形入法，与无效、可撤销并列形成决议效力三分法。
4. **出资制度四件套（第51、52、54条）**：董事催缴义务、股东失权、加速到期（连同第47条五年实缴构成完整的资本充实机制）。
5. **未届期股权转让责任（第88条第1款）**：受让人主责+转让人补充责任。
6. **审计委员会制度（第69、121、176条）**：公司治理"单层制"试验，覆盖有限公司、股份公司、国有独资公司。
7. **类别股（第144条）、无面额股（第142条）、授权资本制（第152条）**：股份制度三大创新，回应科创企业融资需求。
8. **简易注销（第240条）、强制注销（第241条）、简易合并（第219条）、简易减资（第225条）**：公司生命周期"进出"双向简化。
9. **董监高责任体系（第180条第3款、第191、192、193条）**：事实董事、董事对第三人责任、影子董事连带责任、董事责任保险。
10. **财务资助禁止（第163条）、交叉持股禁止（第141条）**：上市公司"股份回购式收购"的规制。
11. **债券持有人会议与受托管理人（第204—207条）**。
12. **利润分配时限（第212条）、资本公积金补亏（第214条第2款）**。
13. **双重股东代表诉讼（第189条第4款）**：股东可对全资子公司董监高提起诉讼。
14. **设立协议（第43条）、电子化会议（第24条）、公司社会责任（第19、20条）**。

### （二）主要删除/废止内容

1. **删除"一人有限责任公司的特别规定"专节及第57—64条**：一人公司设立多家限制、强制年度审计、营业执照载明"自然人独资/法人独资"等全部废止；但第63条财产独立举证责任倒置规则被吸收进第23条第3款。
2. **删除股权转让"其他股东过半数同意"规则**（旧法第71条第2款）：有限公司股权对外转让由"同意制"改为"通知制"。
3. **删除经理法定职权列举**（旧法第49条、第113条）：经理职权回归章程自治。
4. **删除股东会"决定经营方针和投资计划"等职权**（旧法第37条）。
5. **删除无记名股票制度**（旧法第125条）。
6. **删除"资本公积金不得用于弥补亏损"的绝对禁止**（旧法第168条）。
7. **删除一人公司不得再设一人公司等限制性规则**（旧法第58条第2款）。
8. 旧法16个条文整体删除（多为上述制度调整后失去存在基础的条文）。

## 五、过渡期安排（"3+5"安排）

新法第266条授权国务院制定过渡办法，国务院于2024年7月1日公布《国务院关于实施〈中华人民共和国公司法〉注册资本登记管理制度的规定》（国务院令第784号，自公布之日起施行），核心安排如下：

| 公司类型 | 过渡期安排 | 最晚实缴节点 |
| --- | --- | --- |
| 存量有限责任公司（2024年6月30日前设立） | **3年过渡期**（2024年7月1日至2027年6月30日）：剩余认缴出资期限自2027年7月1日起**超过5年**的，应在2027年6月30日前将剩余出资期限**调整至5年内**并记载于公司章程；剩余期限不足5年或已缴足的**无需调整** | 调整后自2027年7月1日起不超过5年，**最晚2032年6月30日**（即"3年过渡期＋5年实缴期"＝8年） |
| 存量股份有限公司 | 发起人应当在**2027年6月30日前**按照认购的股份**全额缴纳股款**（无五年缓冲） | 2027年6月30日 |
| 新设有限责任公司 | 自公司成立之日起**5年内**缴足认缴出资（新法第47条） | 成立之日起5年 |
| 新设股份有限公司 | 发起人在**公司成立前**全额缴纳股款（新法第98条）；公开发行募集股款在登记时缴足 | 成立前 |
| 增资 | 有限公司新增注册资本自**增资决议之日起5年内**缴足；股份公司增资应在**股东全额缴足股款后**办理变更登记 | —— |

补充要点：

1. **例外情形**：公司生产经营涉及**国家利益或者重大公共利益**，经国务院有关主管部门或省级人民政府提出意见，国务院市场监督管理部门可以同意其**按原出资期限出资**。
2. **出资异常规制**：出资期限超过**30年**或出资额超过**10亿元**等明显异常情形的，登记机关可结合经营范围、经营状况、股东出资能力、主营项目、资产规模等进行研判，认定违背真实性、合理性原则的，可以依法要求其**及时调整**。
3. **信息公示义务**：公司调整出资额、出资方式、出资期限或发起人认购股份数的，应自相关信息产生之日起**20个工作日内**通过国家企业信用信息公示系统向社会公示；未按期调整的，登记机关责令改正，逾期未改正的在公示系统**特别标注并公示**（"另册管理"，规定第7条）。
4. **过渡期简化减资**：符合"无未结清债务或债务明显低于实缴资本＋全体股东承诺在原有认缴出资额范围内对减资前债务承担连带责任＋全体董事承诺不损害公司债务履行能力和持续经营能力"条件的存量公司，可适用**公示20日**的简易减资程序（普通减资为45日公告），提高存量公司调整注册资本效率。
5. **监管方式**：登记机关以"双随机、一公开"方式对公示认缴、实缴信息进行监督检查，并根据信用风险状况实施分类监管。
