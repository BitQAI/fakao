# 商经知《高频考点》（2026年法考版）

> 本资料依据2026年法考最新考情编写。核心背景：**新《公司法》（2023年12月29日修订，2024年7月1日施行）** 是近三年法考商法命题的绝对重心，五年实缴制、股东失权、未届期股权转让责任、审计委员会、简易注销等新增制度均为"新增必考"；反垄断法（2022年修正）、著作权法（2020年修正）、专利法（2020年修正）、商标法（2019年修正）等均须以现行法为准。

## 二、公司法（本部分为核心，共16个考点）

### 考点1：公司设立与设立责任【高频】

- **核心法条**：《公司法》第28-30条（设立）、第44条（设立时股东责任）、第45条（设立时董事责任）
- **可背诵要点**：
  1. 公司设立可采用发起设立或募集设立；股份有限公司可一人发起设立；
  2. 有限公司全体股东认缴出资，**自公司成立之日起5年内缴足**（五年实缴制，第47条）；
  3. 设立时的股东未按期足额缴纳出资的，**其他设立时股东与该股东承担连带责任**（第50条）；
  4. 设立中公司以自己名义或发起人名义订立合同：公司成立的，原则上由公司承继合同权利义务，发起人为自己利益订立的除外；公司未成立的，由全体发起人承担连带责任（第44条）。
- **命题角度**：判断合同责任归属（发起人vs公司）；区分"设立时股东"与"后加入股东"的责任差异；五年实缴期限的计算起点（营业执照成立之日）。

### 考点2：资本制度——认缴与五年实缴制【高频·新增必考】

- **核心法条**：《公司法》第47条、第54条、第228条；《国务院关于实施〈公司法〉注册资本登记管理制度的规定》
- **可背诵要点**：
  1. 有限公司：认缴出资**5年内缴足**；股份有限公司：发起人全额缴纳股款（发起设立）；
  2. 存量公司过渡期："3+5"规则——2024年7月1日前设立的公司，剩余认缴期限超过5年的，应在**2027年6月30日前**调整章程，最迟实缴不晚于**2032年6月30日**；
  3. **加速到期**：公司不能清偿到期债务的，公司或已到期债权的债权人有权要求已认缴但未届出资期限的股东**提前缴纳出资**（第54条，2024年新增）；
  4. 出资方式：货币、实物、知识产权、土地使用权、股权、债权等可用货币估价并依法转让的非货币财产（第48条）；
  5. 非货币出资须评估作价；虚假出资、抽逃出资的，责令改正并处罚款（5万元以上20万元以下）。
- **命题角度**：加速到期的触发条件（不能清偿到期债务即可，不以破产为前提）；债权人与公司请求权的行使主体；存量公司过渡期时间节点；非货币出资适格性判断。

### 考点3：股东出资责任（瑕疵出资与抽逃出资）【高频】

- **核心法条**：《公司法》第49-53条、第88条；《公司法解释（三）》第13-14条
- **可背诵要点**：
  1. 未按期足额出资：股东对公司承担补足责任，对已按期足额缴纳出资的股东承担违约责任（第49条）；
  2. **失权制度**（第52条）：宽限期**60日**，届满仍未缴纳的，**董事会可决议**发出失权通知，自通知发出之日起股东丧失其未缴纳出资的股权；失权股权应依法转让或减资注销，6个月内未处理的由其他股东按比例缴纳；
  3. 抽逃出资的股东返还本息，协助抽逃的董事、高管、实际控制人与股东承担**连带责任**（第53条）；
  4. 债权人可请求未履行出资义务的股东在未出资本息范围内对公司不能清偿的债务承担补充赔偿责任（解释三第13条）；
  5. 股东出资瑕疵不影响股东资格，但公司可根据章程或股东会决议对其利润分配请求权、新股优先认购权等权利作出合理限制。
- **命题角度**：失权程序的完整步骤与时间（催缴→60日宽限→董事会决议→失权通知→处置）；抽逃出资的认定（制作虚假财务会计报表虚增利润分配、虚构债权债务转出出资等）；瑕疵出资股东的权利限制。

### 考点4：未届出资期限股权转让的责任承担【高频·新增必考】

- **核心法条**：《公司法》第88条
- **可背诵要点**：
  1. **未届出资期限**的股权转让：受让人按期足额缴纳；受让人未按期足额缴纳出资的，**转让人对受让人未按期缴纳的出资承担补充责任**（防止以转让股权逃避出资义务）；
  2. 已届出资期限的瑕疵股权转让：受让人知道或应当知道瑕疵的，**与转让人承担连带责任**；受让人"**不知道且不应当知道**"方可免责（举证责任在受让人一方）；
  3. 多次转让的：由最后一位转让人先承担补充责任，不能承担的依次向前手追及；
  4. 出资期限届至后受让人未缴纳的，公司可请求转让人与受让人承担责任。
- **命题角度**：主客观题均高发——转让人是否仍承担责任；"不知道且不应当知道"的举证分配；连环转让情形下的责任顺位（由近及远）。

### 考点5：股东资格认定与股权代持【高频】

- **核心法条**：《公司法》第32条、第56条、第86条；《公司法解释（三）》第24-26条
- **可背诵要点**：
  1. 股东名册是股东向公司主张权利的**内部依据**；登记机关的登记具有**对抗第三人的公示效力**；
  2. **受让人自记载于股东名册时起可以向公司主张行使股东权利**（第86条，新增，解决股权变动时点争议）；
  3. 股权代持：实际出资人（隐名股东）与名义股东（显名股东）的合同效力原则上有效；隐名股东要求显名须经公司**其他股东半数以上同意**；
  4. 名义股东处分股权，第三人善意取得的，实际出资人只能向名义股东索赔；
  5. 股权让与担保、继承：自然人股东死亡，合法继承人可继承股东资格（章程另有规定的除外）。
- **命题角度**：股权转让合同生效、股东名册变更、工商变更三时点分别产生何种效力；隐名股东显名化条件；善意第三人保护。

### 考点6：股东知情权【高频·新增修改】

- **核心法条**：《公司法》第57条、第110条；《公司法解释（四）》第7-12条
- **可背诵要点**：
  1. 有限公司股东可**查阅、复制**：章程、股东名册（新增）、股东会决议、董事会决议、监事会决议、财务会计报告；可**查阅**：会计账簿、**会计凭证（新增）**；
  2. 股份公司：**连续180日以上单独或合计持股3%以上**的股东可查阅会计账簿、会计凭证（章程可降低比例）；查阅范围可**延伸至全资子公司**（新增）；
  3. 股东可**委托会计师事务所、律师事务所等中介机构**协助查阅（新增，中介机构应遵守保密义务）；
  4. 前置程序：书面请求+说明目的，公司15日内答复；公司以"不正当目的"拒绝的应承担证明责任（同业竞争、向他人通报等构成不正当目的）；
  5. 知情权属于股东固有权利，章程不得实质剥夺。
- **命题角度**：查阅与复制范围的精确区分（会计账簿只能查不能复制）；股份公司股东行权门槛；委托中介机构行权是否可复制；起诉时的股东资格要求。

### 考点7：利润分配请求权【高频】

- **核心法条**：《公司法》第210-212条；《公司法解释（四）》第14-15条
- **可背诵要点**：
  1. 分配顺序：弥补亏损→提取**法定公积金（税后利润10%，累计达注册资本50%以上可不再提取）**→提取任意公积金→按实缴出资比例分配（章程另有约定除外）；
  2. 公司不分配利润的，应**在6个月内完成利润分配**；股东会决议分配但公司拒不执行的，股东可诉请支付；
  3. 无分配决议时的例外：**大股东滥用股东权利导致公司不分配利润、损害其他股东利益的**，股东可诉请强制分配（滥用情形：转移利润、私分公司利润、隐瞒利润等）；
  4. 公司连续5年盈利且符合分配条件却**连续5年不向股东分配利润**的，异议股东可请求公司**按合理价格收购其股权**（异议股东回购请求权的第一种法定情形）。
- **命题角度**：公积金提取比例的精确数字；无决议强制分配之诉的构成要件；与异议股东回购请求权（5年不分红）的联动考查。

### 考点8：异议股东股权回购请求权【高频·新增修改】

- **核心法条**：《公司法》第89条、第161-162条、第219条
- **可背诵要点**：
  1. 有限公司三种法定情形（第89条）：（1）**连续5年盈利不分配利润**；（2）**合并、分立、转让主要财产**；（3）章程规定的**营业期限届满或解散事由出现，股东会决议修改章程使公司存续**；
  2. 异议股东须对决议投**反对票**，自决议通过之日起**60日内**协商，协商不成**90日内**起诉（60/90日期间为除斥期间）；
  3. **新增（第89条第3款）**：控股股东滥用股东权利、严重损害公司或其他股东利益的，其他股东可请求公司按合理价格收购其股权（无需决议、无需投反对票）；
  4. **新增（第161条）**：非上市股份公司股东在三种法定情形下享有同有限公司一致的回购请求权；上市公司仅限**合并、分立**情形（第162条，公开市场例外）；
  5. **简易合并**（第219条）：公司与持股**90%以上**的公司合并，无需被合并公司股东会决议，但异议股东仍享有回购请求权；
  6. 公司回购的股权/股份应**6个月内**转让或注销。
- **命题角度**：各类型公司回购情形的"由繁至简"对比表；除斥期间计算；控股股东滥权回购权的新增适用；简易合并触发条件。

### 考点9：股东会、董事会职权与决议效力【高频·新增修改】

- **核心法条**：《公司法》第59条、第67条、第25-27条；《公司法解释（四）》第1-6条
- **可背诵要点**：
  1. 股东会职权删除了"决定经营方针和投资计划""审议批准年度财务预算方案、决算方案"两项，公司经营决策权向**董事会中心主义**转移；股东会可**授权董事会**发行公司债券；
  2. 决议**不成立**（解释四第5条）：未召开会议、未表决、出席人数不足、表决权不足、表决未达比例；
  3. 决议**无效**（第25条）：内容违反法律、行政法规的强制性规定（自始无效、不适用除斥期间）；
  4. 决议**可撤销**（第26条）：内容违反章程，或召集程序、表决方式违法或违反章程且**未被裁量驳回**；股东应自决议作出之日起**60日**内请求撤销（除斥期间）；轻微瑕疵不影响决议实质内容的，法院可裁量驳回；
  5. 股东会、董事会决议被确认无效、撤销或不存在，与善意相对人形成的**民事法律关系不受影响**（第28条，内外有别）。
- **命题角度**：三种效力状态的区分（成立vs生效vs可撤销）；60日除斥期间；裁量驳回制度；决议无效不影响善意相对人。

### 考点10：法定代表人制度【高频·新增修改】

- **核心法条**：《公司法》第10-11条
- **可背诵要点**：
  1. 法定代表人由**代表公司执行公司事务的董事或者经理**担任（第10条，扩大选任范围，删去"董事长/执行董事"限定）；
  2. 担任法定代表人的董事或经理**辞任的，视为同时辞去法定代表人**；法定代表人辞任的，公司应在其辞任之日起**30日内**确定新的法定代表人；
  3. 法定代表人以公司名义从事的民事活动，其法律后果由公司承受；章程或股东会、董事会对法定代表人的职权限制，**不得对抗善意相对人**（第11条）；
  4. 法定代表人因执行职务造成他人损害的，由公司承担侵权责任，公司可向有过错的法定代表人追偿。
- **命题角度**：辞任与登记的联动（辞任即辞去代表权，公司30日内补选）；越权担保/越权代表的效力（善意相对人保护）；法定代表人侵权责任的承担主体。

### 考点11：董监高义务——忠实勤勉与赔偿责任【高频】

- **核心法条**：《公司法》第180-187条、第53条
- **可背诵要点**：
  1. 忠实义务：**采取措施避免自身利益与公司利益冲突**，不得利用职权牟取不正当利益（第180条第1款）；具体禁止行为：挪用资金、职务侵占、擅自借贷或担保、自我交易（关联交易须经决议+回避表决）、篡夺公司商业机会、竞业禁止（第181-184条）；
  2. 勤勉义务：执行职务应当为公司的最大利益**尽到管理者通常应有的合理注意**（第180条第2款，新增"合理注意"标准）；
  3. 关联交易：董事、监事、高管及其近亲属、关联企业与公司交易，应向董事会或股东会**报告并决议**；章程可对关联交易作出规定（第182条）；
  4. **董事对股东出资负有催缴义务**（第51条），未履行催缴义务给公司造成损失的，承担赔偿责任；
  5. 董事、监事、高管执行职务违反忠实勤勉义务给公司造成损失的，承担赔偿责任（第188条）；**董事任期届满前辞任、无正当理由解任的赔偿责任**（第70-71条）；
  6. 股东代表诉讼（第189条）：有限公司股东无门槛，股份公司股东须**连续180日单独或合计持股1%以上**；书面请求监事会/董事会，30日内未起诉的股东可自行起诉；**双重代表诉讼**（新增）：股东可对全资子公司董监高侵害子公司利益的行为提起代表诉讼。
- **命题角度**：自我交易的程序要求（报告+决议+回避）；竞业禁止与篡夺商业机会的边界；董事催缴出资义务与失权制度的衔接；股东代表诉讼的前置程序与豁免（紧急情形）；双重代表诉讼中前置请求对象为子公司监事会/董事会。

### 考点12：一人公司【中频·立法变化】

- **核心法条**：《公司法》第23条、第92条；新法删除原"一人有限责任公司的特别规定"专节
- **可背诵要点**：
  1. 新法**允许设立一人股份有限公司**（第92条：一个发起人可发起设立股份公司）；
  2. 一人公司股东与公司财产**混同**的（不能证明公司财产独立于股东自己财产的），股东对公司债务承担**连带责任**（举证责任倒置，第23条第3款）；
  3. **横向人格否认**（第23条第2款，新增）：股东利用其控制的两个以上公司实施逃避债务行为的，各公司对任一公司的债务承担**连带责任**；
  4. 人格否认适用于有限公司与股份公司；滥用行为包括：财产混同、业务混同、人员混同、资金转移等。
- **命题角度**：一人公司举证责任倒置规则；横向否认的适用主体（兄弟公司间互负连带）；与破产法上的关联企业实质合并的对比。

### 考点13：股权转让与优先购买权【高频·新增修改】

- **核心法条**：《公司法》第84-86条；《公司法解释（四）》第16-22条
- **可背诵要点**：
  1. **取消"经其他股东过半数同意"程序**（新法删去原第71条同意权），股东对外转让股权仅需**书面通知**其他股东（载明数量、价格、支付方式和期限等"同等条件"要素）；
  2. 其他股东自接到通知之日起**30日内**未答复的，视为**放弃优先购买权**；
  3. 两个以上股东主张行使优先购买权的，**协商确定**各自的购买比例；协商不成的，**按照转让时各自的出资比例行使**；
  4. 优先购买权被侵害的救济：股东可请求**按照同等条件购买**该股权，但**30日内**（通知后）不主张的、或非因自身原因无法行使的除外；转让合同效力不因侵害优先购买权而当然无效（解释四第21条）；
  5. 股权转让后，公司应**变更股东名册**并向登记机关办理变更登记；受让人自**记载于股东名册时起**主张行使股东权利。
- **命题角度**：新程序（通知+30日优先权）与旧程序（过半数同意）的对比题；同等条件的要素；优先购买权受侵害的救济路径；名册记载=对内效力、登记=对外效力。

### 考点14：公司合并、分立与减资【高频】

- **核心法条**：《公司法》第218-225条
- **可背诵要点**：
  1. 合并形式：吸收合并（A+B=A）与新设合并（A+B=C）；公司合并应**自作出决议之日起10日内通知债权人，并于30日内在报纸上或国家企业信用信息公示系统公告**；
  2. 债权人自接到通知之日起**30日内**、未接到通知的自公告之日起**45日内**，可以要求公司清偿债务或**提供相应担保**；
  3. 合并各方的债权债务由合并后存续的公司或新设的公司**承继**（法定概括承继，无需债权人同意）；
  4. **简易合并**（第219条）：与持股90%以上的公司合并，被合并公司可免于股东会决议；公司合并支付价款不超过本公司**净资产10%**的，可免于召开股东会（章程另有规定除外）；
  5. 分立：公司分立前的债务由分立后的公司**承担连带责任**，与债权人另有约定的除外；
  6. 减资：**通知+公告（45日）**；实质减资（返还出资）须履行债权人保护程序；违法减资的，股东应退还其收到的资金，负有责任的董事、监事、高管承担赔偿责任（第226条，新增）。
- **命题角度**：债权人保护程序期间（30/45日）；合并后债务承继的无因性；简易合并条件；违法减资责任主体。

### 考点15：解散、清算与简易注销【高频·新增修改】

- **核心法条**：《公司法》第229-241条
- **可背诵要点**：
  1. 司法解散（第231条）：公司经营管理发生**严重困难**（股东会僵局、董事会僵局、经营困难且继续存续会使股东利益受重大损失），持有公司**10%以上表决权**的股东可请求法院解散公司（以"其他途径不能解决"为前提，可通过协商、转让股权、减资等替代）；
  2. 清算义务人：**董事为公司清算义务人**（第232条，删去"股东"，为新增修改），应在解散事由出现之日起**15日内**成立清算组；董事怠于履行清算义务致公司财产贬损的承担赔偿责任；
  3. 清算程序：清算组10日内通知债权人、**60日内在报纸或公示系统公告**，债权人**30日内/45日内**申报债权；清算期间公司存续但不得开展与清算无关的经营活动；
  4. 清算中发现资不抵债的，应**申请破产清算**（清算程序转为破产程序）；
  5. **简易注销**（第240条）：存续期间**未产生债务**或已清偿全部债务的，经全体股东承诺，可通过国家企业信用信息公示系统公告**20日**，公告期满无异议的，可申请注销登记（无需清算）；
  6. 公司经注销登记后终止；股东对注销前的债务承诺不实的，对未清偿债务承担相应责任。
- **命题角度**：司法解散的构成要件（"严重困难+其他途径不能解决"）；清算义务人的身份变化（董事而非股东）；简易注销的适用条件与股东承诺责任；清算转破产的衔接。

### 考点16：公司人格否认与股东滥用权利【高频】

- **核心法条**：《公司法》第21条、第23条
- **可背诵要点**：
  1. 公司股东滥用公司法人独立地位和股东有限责任，逃避债务，严重损害公司债权人利益的，应当对公司债务承担**连带责任**（第23条第1款）；
  2. 人格否认适用情形：**人格混同**（财产混同为主要标准）、**过度支配与控制**、**资本显著不足**（九民纪要第10-12条）；
  3. 纵向否认：股东→公司；**横向否认**（第23条第2款）：股东利用其控制的两个以上公司逃避债务的，各公司对任一公司债务承担连带责任；
  4. 一人公司**举证责任倒置**：股东不能证明公司财产独立于自己财产的，承担连带责任；
  5. 人格否认**不是全盘否定法人人格**，仅个案否认、裁判生效后该公司对他人仍独立担责。
- **命题角度**：人格混同的认定因素（财产混同/人员混同/业务混同）；横向否认的适用；举证责任分配；个案否认的效力范围。

## 三、合伙企业法（共3个考点）

### 考点17：普通合伙企业的设立与合伙财产【中频】

- **核心法条**：《合伙企业法》第14条、第16条、第20-25条
- **可背诵要点**：
  1. 普通合伙：2个以上合伙人（自然人须完全民事行为能力），合伙人对合伙债务承担**无限连带责任**；
  2. 合伙企业的财产包括：合伙人出资、以合伙企业名义取得的收益和依法取得的其他财产；
  3. 合伙人向**合伙人以外的人**转让其在合伙企业的财产份额：须**经其他合伙人一致同意**（合伙协议另有约定的除外），同等条件下其他合伙人有**优先购买权**；
  4. 合伙人之间转让财产份额：通知即可；
  5. 有限合伙人向合伙人以外的人转让财产份额：**提前30日通知**其他合伙人即可（无需一致同意）。
- **命题角度**：普通合伙与有限合伙转让规则对比；合伙企业财产的性质（共同共有vs按份共有——共同共有）；表见合伙。

### 考点18：合伙事务执行与利润分配【中频】

- **核心法条**：《合伙企业法》第26-33条
- **可背诵要点**：
  1. 全体合伙人**共同执行**合伙事务，也可委托一个或数个合伙人执行；事务执行人对外代表合伙企业，其行为对合伙企业有效（内部限制不得对抗善意第三人）；
  2. 必须**全体合伙人一致同意**的事项：改变经营范围/名称/主要经营场所、处分不动产、转让或处分知识产权和其他财产权利、以合伙企业名义为他人提供担保、聘任合伙人以外的人担任经营管理人员等；
  3. 合伙人**不得自营或同他人合作经营与本企业相竞争的业务**（普通合伙人绝对竞业禁止）；不得同本合伙企业进行交易（但合伙协议另有约定或全体合伙人一致同意的除外）；
  4. 利润分配：**不得约定将全部利润分配给部分合伙人或由部分合伙人承担全部亏损**（禁止保底条款）；利润分配、亏损分担按合伙协议→协商→实缴出资比例→平均的顺位；
  5. 有限合伙人：可以自营或同他人合作经营与本有限合伙企业相竞争的业务（可约定排除），也可以与本企业交易（可约定排除）——**法定默许+约定排除**。
- **命题角度**：一致同意事项清单；普通/有限合伙人竞业与自我交易规则的对比；亏损不得由部分合伙人全部承担的强制性；表见执行合伙事务（第76条）。

### 考点19：退伙、入伙与合伙企业解散清算【高频】

- **核心法条**：《合伙企业法》第45-52条、第78-81条、第85-88条
- **可背诵要点**：
  1. 退伙类型：协议退伙、约定/法定事由退伙（45条：经全体同意/约定的退伙事由/发生难以继续参加合伙的事由/其他合伙人严重违反协议）、**当然退伙**（46条：死亡/丧失偿债能力/丧失民事行为能力（普通合伙人）/被除名/丧失合伙人资格）、**除名**（49条：未履行出资义务/故意或重大过失给企业造成损失/执行事务时有不正当行为/协议约定事由——经其他合伙人一致同意，除名决议应书面通知）；
  2. 退伙人责任：对**退伙前**发生的合伙债务承担无限连带责任；
  3. 入伙：新合伙人对**入伙前**的合伙债务承担无限连带责任（与退伙不同，入伙责任不能约定排除）；
  4. **有限合伙人**：丧失民事行为能力的，**其他合伙人不得因此要求其退伙**（第79条，区别于普通合伙人）；死亡/被宣告死亡的，其继承人可依法取得有限合伙人资格；退伙时仅以**取回的财产**为限承担责任（第81条）；
  5. 解散事由：合伙期限届满（不经营）/约定解散事由/全体解散决议/已不具备法定人数满30日/合伙协议约定的经营目的已实现或无法实现/依法被吊销执照、责令关闭、撤销/法律行政法规规定的其他原因；
  6. 清算：清算人由全体合伙人或经全体过半数同意指定的合伙人或第三人担任；**清算期间企业存续**但不得开展与清算无关的经营活动；清算结束办理注销登记。
- **命题角度**：当然退伙vs除名的区分；入伙人对入伙前债务的责任（无限连带、不可约定排除）；有限合伙人的特殊退伙规则；清算人确定规则（过半数）。

## 四、企业破产法（共5个考点）

### 考点20：破产原因与破产申请【高频】

- **核心法条**：《企业破产法》第2条、第7-8条；《破产法解释（一）》第1-4条
- **可背诵要点**：
  1. 破产原因（第2条）：不能清偿到期债务，且（1）资产不足以清偿全部债务，或（2）明显缺乏清偿能力；
  2. 债务人可申请**重整、和解或破产清算**；债权人只能申请**重整或破产清算**（不能申请和解）；出资额占注册资本**1/10以上**的出资人在**法院受理破产申请后、宣告破产前**可申请重整；依法负有清算责任的人应申请破产清算；
  3. 破产原因（债务人财产不足以清偿）的推定：明显丧失清偿能力可能的，可直接申请重整；
  4. 债权人申请破产的，债务人可在**收到法院通知之日起7日内**提出异议；
  5. 受理裁定：**5日内**通知、**25日内**通知已知债权人并公告；受理后**执行程序中止、保全解除**；对不受理裁定和驳回申请裁定可上诉（对其他裁定不可上诉）。
- **命题角度**：申请主体与程序类型对应关系（债权人不申请和解）；受理的法律效力（中止执行、解除保全、个别清偿无效）；7日异议期。

### 考点21：管理人制度【高频】

- **核心法条**：《企业破产法》第22-29条
- **可背诵要点**：
  1. 管理人由**人民法院指定**（债权人会议对报酬等有异议可申请更换）；**受理破产申请的同时指定管理人**；
  2. 管理人来源：有关部门、机构人员组成的清算组；律师事务所、会计师事务所、破产清算事务所等中介机构；具备执业资格的个人（简单案件）；
  3. 管理人职责：接管债务人财产、决定内部管理事务、决定待履行合同的解除或继续履行（自受理之日起**2个月内**未通知对方当事人或自收到催告之日起**30日内**未答复的，视为解除）、代表债务人参加诉讼、提议召开债权人会议等；
  4. 管理人报酬由人民法院确定；管理人应勤勉尽责、忠实执行职务，违反义务的由法院处罚、给债权人债务人第三人造成损失的承担赔偿责任；
  5. 管理人**不得自行辞去职务**（无正当理由）；债权人会议认为管理人不能胜任的，可申请法院更换。
- **命题角度**：管理人的指定主体与时间；待履行合同处理规则（2个月/30日）；管理人更换程序；不得自行辞职。

### 考点22：撤销权、无效行为与个别清偿【高频】

- **核心法条**：《企业破产法》第31-33条
- **可背诵要点**：
  1. **可撤销行为**（受理前**1年内**，由管理人请求法院撤销）：无偿转让财产；以明显不合理价格交易；对没有财产担保的债务提供财产担保；对未到期债务提前清偿；放弃债权；
  2. **个别清偿撤销**（受理前**6个月内**，债务人已具备破产原因仍对个别债权人清偿）：管理人可请求撤销；但**使债务人财产受益的除外**（维持基本生产经营所必需的水电费等）；
  3. **无效行为**（第33条，自始无效）：为逃避债务而隐匿、转移财产；虚构债务或承认不真实的债务；
  4. 撤销权行使主体是**管理人**（债权人个别或代位行使须以管理人怠于行使为前提，且受"个别清偿不能使债务人财产受益"等限制）；
  5. 破产撤销权与民法撤销权的区别：主体、期间（1年/6个月）、对象、法律后果均不同。
- **命题角度**：1年内5种行为+6个月内个别清偿的时间精确计算；"使债务人财产受益"的例外；隐匿转移财产为无效（不受期间限制）vs 无偿转让为可撤销（1年内）——两者区分。

### 考点23：取回权与抵销权【高频】

- **核心法条**：《企业破产法》第38-40条
- **可背诵要点**：
  1. **一般取回权**（第38条）：债务人占有他人财产，权利人可通过管理人取回（保管物、租赁物、寄托物、出质物等）；取回权基于所有权等物权，不依破产程序行使；原物毁损灭失的，取回权消灭，权利人可就**损失额申报债权**（按直接损失）；
  2. **出卖人取回权**（第39条，特殊取回权）：受理时出卖人已将标的物发运、债务人**尚未收到且未付清全部价款**的，出卖人可**取回在运途中的标的物**；管理人可以**支付全部价款**请求交付；
  3. 重整程序中取回权受限：重整期间权利人行使取回权应符合**事先约定的条件**（和解与清算程序不受此限）；
  4. **抵销权**（第40条）：破产受理前债权人对债务人负有的债务，可在破产清算前主张抵销（不受债务期限、种类限制）；
  5. **禁止抵销**情形：破产受理后取得他人对债务人的债权；债权人已知债务人不能清偿或破产申请的事实仍负担债务（法定原因或破产申请1年前的原因除外）；债务人的债务人已知破产事实仍取得债权（同上除外）；**股东的破产债权不得与欠缴出资抵销**。
- **命题角度**：出卖人取回权的三个要件（发运中、未收到、未付清）+管理人付款截断；取回权在重整/和解/清算三程序中的不同待遇；抵销权禁止情形的识别；股东欠缴出资不得抵销。

### 考点24：债权人会议、重整、和解与清算程序【高频】

- **核心法条**：《企业破产法》第59-68条（债权人会议）、第70-94条（重整）、第95-106条（和解）、第107-124条（清算）
- **可背诵要点**：
  1. 债权人会议决议规则：**出席会议的有表决权的债权人过半数通过，且其所代表的债权额占无财产担保债权总额的1/2以上**；
  2. 债权申报期限：自法院**发布受理公告之日起30日至3个月**；未申报的可在**破产财产最后分配前补充申报**（此前已分配的不补充分配，审查补充申报费用由补充申报人承担）；
  3. 职工债权（工资、医疗伤残补助抚恤费用、应划入职工个人账户的社保费、经济补偿金）**无需申报**，由管理人调查后列出清单公示；
  4. **重整期间**：担保权**暂停行使**；董事、监事、高管不得向第三人转让其持有的债务人股权（法院同意的除外）；债务人可在管理人监督下自行管理财产和营业事务；为继续营业的借款可设定担保；
  5. 重整计划草案：分组表决（担保债权组、职工债权组、税款债权组、普通债权组），**各组均通过**后由法院批准；部分组未通过的，**法院可强制批准**（符合清算价值保障、公平待遇等条件的"强裁"）；
  6. 和解：仅**债务人**可提出；和解协议由债权人会议**过半数通过且债权额占无担保债权总额2/3以上**；和解协议对全体和解债权人有效（有财产担保债权人不受影响）；和解不成功转破产清算；
  7. 清偿顺序：破产费用、共益债务（随时清偿，破产费用优先）→职工债权→税款与社保→普通破产债权（同一顺序按比例分配）。
- **命题角度**：债权人会议双重多数规则；重整/和解申请主体对比（和解仅债务人）；重整计划分组表决与强制批准；清偿顺位排序题；破产费用与共益债务的清偿顺序。

## 五、票据法（共3个考点）

### 考点25：票据特征与出票【中频】

- **核心法条**：《票据法》第4条、第8-9条、第14-15条、第17条、第19-26条
- **可背诵要点**：
  1. 票据三大特征：**文义性**（权利义务以票据记载为准）、**要式性**（格式与记载事项法定）、**无因性**（票据关系与基础关系相分离，票据债务人不得以基础关系对抗持票人——但直接当事人之间及无对价取得者除外）；
  2. 票据类型：汇票（银行/商业）、本票（仅银行本票）、支票；
  3. 绝对记载事项欠缺的票据**无效**（出票人签章、金额、付款人、收款人等）；金额、日期、收款人**不得更改**，更改的票据无效；
  4. 票据伪造、变造：伪造签章不影响其他真实签章的效力；变造前签章者对原记载负责、变造后签章者对变造后记载负责，不能辨认的前后按变造前；
  5. 票据权利时效（第17条）：持票人对出票人、承兑人——**2年**（支票出票人6个月）；对前手追索权——**6个月**；对前手的再追索权——**3个月**；追索权时效从被拒绝承兑或付款之日起算；
  6. **挂失止付**：票据丧失可挂失止付、公示催告、普通诉讼（失票人应在挂失止付后**3日内**申请公示催告或起诉）。
- **命题角度**：无因性原理及例外（直接当事人间、无对价取得）；绝对记载事项与更改规则；权利时效数字；挂失止付与公示催告衔接。

### 考点26：背书、承兑与保证【高频】

- **核心法条**：《票据法》第27-37条（背书）、第38-44条（承兑）、第45-52条（保证）
- **可背诵要点**：
  1. **背书**：背书须连续；背书人背书转让票据后即承担担保承兑和担保付款责任；**背书附条件无效**（条件视为不存在，背书有效）；背书人记载"不得转让"的，其后手再背书转让的，原背书人对后手的被背书人**不承担保证责任**；
  2. **期后背书**（第36条）：被拒绝承兑、被拒绝付款或超过付款提示期限的票据**不得背书转让**；背书转让的，背书人应承担**票据责任**（持票人可向背书人追索，但不得主张票据权利转让的完整效果）；
  3. 质押背书：以票据质押应作成质押背书，质权人享有票据权利但不得再次转让或质押；
  4. **承兑**：付款人承兑的，成为票据**主债务人**（到期无条件付款）；提示承兑期限：见票即付（无需承兑）、见票后定期付款（出票后1个月内提示）、定日付款或出票后定期付款（到期日前提示）；付款人自收到提示承兑之日起**3日内**承兑或拒绝；承兑附条件的，**视为拒绝承兑**；
  5. **保证**：保证人由票据债务人以外的人担任，未记载被保证人的，视为对**承兑人**（未经承兑的汇票为出票人）保证；保证不得附条件，附条件的**不影响保证责任**；保证人与被保证人对持票人承担**连带责任**；保证人对合法取得票据的持票人所享有的票据权利承担保证责任（被保证人债务因手续欠缺而消灭的除外）。
- **命题角度**：背书附条件vs承兑附条件vs保证附条件的效力差异（三个"附条件"对比——背书附条件无效、承兑附条件视为拒绝、保证附条件不影响保证）；"不得转让"记载的效力；期后背书的追索对象；保证人责任。

### 考点27：付款与追索权【高频】

- **核心法条**：《票据法》第53-60条（付款）、第61-72条（追索）
- **可背诵要点**：
  1. 付款提示期限：见票即付汇票——**出票日起1个月**；定日付款等——**到期日起10日**；本票——**出票日起2个月**；支票——**出票日起10日**；
  2. 付款人**善意付款**（审查背书连续、形式审查）后，票据债务消灭；恶意或重大过失付款的自行承担责任；
  3. **追索权**要件：到期被拒绝付款，或到期前被拒绝承兑、承兑人或付款人死亡/逃匿、被依法宣告破产或因违法被责令终止业务活动（期前追索）；须作成**拒绝证明**（退票理由书等）；
  4. 追索对象：出票人、背书人、承兑人、保证人（对持票人承担连带责任）；持票人可按任意顺序向任何前手追索（**选择追索**），也可同时向数人追索（**无限追索/跳跃追索）**；
  5. **追索金额**：被拒绝付款的票据金额+利息+取得拒绝证明的费用；再追索金额=已清偿金额+利息+发出通知的费用；
  6. **追索权丧失**：未按期提示承兑/提示付款的，丧失对**前手**的追索权（但不丧失对出票人、承兑人的权利——本票未按期提示丧失对出票人以外前手的追索权）；未按期通知的，仍可行使追索权，但应赔偿前手因此的损失（以票据金额为限）；
  7. 票据债务人的**抗辩切断**（第13条）：票据债务人不得以自己与出票人或持票人前手之间的抗辩事由对抗持票人，但持票人**明知存在抗辩事由而取得**的除外；**无对价取得**票据者不得享有优于前手的权利（善意且对价取得→抗辩切断）。
- **命题角度**：期前追索情形；未按期提示丧失追索权的范围（前手vs出票人/承兑人）；选择追索与再追索；抗辩切断的适用与例外；无对价取得（如赠与）的权利限制。

## 六、保险法（共4个考点）

### 考点28：保险利益原则【高频】

- **核心法条**：《保险法》第12条、第31条、第34条
- **可背诵要点**：
  1. 财产保险：**保险事故发生时**被保险人须对保险标的具有保险利益（否则不得请求赔偿）；人身保险：**订立合同时**投保人须对被保险人具有保险利益（否则合同无效）；
  2. 人身保险利益范围（第31条）：本人；配偶、子女、父母；与投保人有**抚养、赡养或者扶养关系**的家庭其他成员、近亲属；**与投保人有劳动关系的劳动者**（用人单位为劳动者投保）；
  3. 被保险人同意视为具有保险利益（如为朋友投保须经被保险人书面同意）；
  4. **以死亡为给付保险金条件**的合同，未经被保险人**书面同意并认可保险金额**的无效；但投保人对自己、对具有保险利益的近亲属（父母为其未成年子女投保）除外；此种合同不得**转让**、不得**质押**（第34条）；
  5. 保险金额不得超过保险价值，超过部分无效（超额保险）。
- **命题角度**：人身保险利益主体的判断（同学≠利益，赡养的伯父✓）；被保险人同意规则；以死亡为条件的合同的特殊规则（同意+金额认可、禁止转让质押）。

### 考点29：如实告知义务（最大诚信原则）【高频】

- **核心法条**：《保险法》第16条
- **可背诵要点**：
  1. 订立合同时投保人应如实告知；**询问告知主义**：保险人未询问的，投保人无需告知（"不问不答"）；
  2. **故意不告知**：保险人可解除合同、不赔不退（不退还保险费），并对解除前发生的保险事故不承担赔付责任；
  3. **重大过失不告知**（未告知事项对保险事故发生有**重大影响**的）：可解除合同、不赔但**退还保险费**；
  4. **2年不可抗辩条款**：保险人自知道解除事由之日起**30日内**不行使解除权消灭；自合同成立之日起**超过2年**的，保险人不得解除合同（发生保险事故应赔）；
  5. 保险人在合同订立时**已知**投保人未如实告知的，不得解除合同；
  6. 保险人在收到保险金给付请求后**30日内**核定赔付，作出核定后**10日内**赔付。
- **命题角度**：故意vs重大过失的法律后果对比（不赔不退vs不赔退费）；2年不可抗辩+30日除斥期；询问告知主义；格式条款（免责条款未提示说明不生效，第17条）。

### 考点30：受益人制度与人身保险特殊规则【高频】

- **核心法条**：《保险法》第18条、第39-43条、第44-45条
- **可背诵要点**：
  1. 受益人由被保险人或投保人指定（**投保人指定须经被保险人同意**）；投保人、被保险人可变更受益人（变更**须书面通知保险人**，否则不得对抗保险人）；
  2. **受益人丧失受益权**（第43条）：受益人**故意造成被保险人死亡、伤残、疾病**的，或故意杀害被保险人未遂的，**丧失受益权**——但投保人仍交保费或保险人有义务赔付的（如被保险人为无民事行为能力人且投保人为其父母时保险人仍赔付）；
  3. **受益人先于被保险人死亡、依法丧失受益权、放弃受益权且无其他受益人的**，保险金作为被保险人的**遗产**（第42条）；
  4. **自杀条款**（第44条）：以死亡为给付条件且合同成立或效力恢复之日起**2年内**自杀的，保险人不赔（但应退还保单现金价值；被保险人自杀时为无民事行为能力人的除外）；
  5. **故意犯罪条款**（第45条）：被保险人**故意犯罪或者抗拒依法采取的刑事强制措施导致其伤残或者死亡**的，保险人不承担给付保险金责任（投保人已交足2年以上保险费的，退还保单现金价值）；
  6. **人身保险禁止代位求偿**（第46条）：人身保险的被保险人因第三者行为发生死亡、伤残或疾病等保险事故的，保险人赔付后**不得**向第三者行使代位求偿权；
  7. 人身保险合同**不得用诉讼方式要求投保人支付保险费**（第38条）。
- **命题角度**：受益权丧失情形与"无其他受益人时保险金为遗产"的衔接；2年自杀免责；故意犯罪免责；人身险无代位求偿；指定/变更受益人的程序要求。

### 考点31：保险代位求偿权（财产保险）【高频】

- **核心法条**：《保险法》第60-62条
- **可背诵要点**：
  1. 代位求偿权：因第三者对保险标的损害造成保险事故的，保险人自**向被保险人赔偿保险金之日起**，在赔偿金额范围内**代位行使**被保险人对第三者请求赔偿的权利；
  2. 被保险人已从第三者取得赔偿的，保险人赔偿时应**扣减**相应金额（禁止双重受偿）；
  3. 保险人赔付前，被保险人**放弃**对第三者请求赔偿的权利的，保险人**不承担赔偿保险金的责任**；赔付后放弃的，放弃行为**无效**；
  4. 被保险人故意或重大过失致使保险人不能行使代位求偿权的，保险人可**扣减或要求返还**相应保险金；
  5. **不得代位行使的例外**（第62条）：除被保险人的家庭成员或组成人员**故意**造成保险事故外，保险人不得对被保险人的家庭成员或组成人员行使代位求偿权（"家庭成员故意造成事故时保险人可追偿"——易错点）；
  6. 代位求偿权以财产保险为限；人身保险无代位求偿（见考点30）。
- **命题角度**：代位权取得时点（赔付之日）；放弃追偿权在赔付前后的不同后果；家庭成员例外及故意情形；扣减规则。

## 七、证券法（共2个考点）

### 考点32：证券发行注册制与信息披露【中频】

- **核心法条**：《证券法》（2019年修订）第9条、第19条、第78-87条
- **可背诵要点**：
  1. **注册制**：公开发行证券实行注册制，国务院证券监督管理机构或国务院授权的部门注册；核准权回归市场，信息披露为核心；
  2. 公开发行的认定：向**不特定对象**发行；向特定对象发行累计超过**200人**；法律规定的其他行为；
  3. **信息披露义务**：发行人及控股股东、实际控制人、董监高等应真实、准确、完整披露信息；**发行文件中隐瞒重大事实或披露虚假信息的，发行人承担赔偿责任**，控股股东、实际控制人、董监高与保荐人、承销商等**过错推定连带责任**（能证明自己没有过错的除外）；
  4. 重大事件应**及时**披露（临时报告）：公司经营方针和经营范围重大变化、重大投资与重大合同、主要资产抵押出售报废一次超过该资产30%、重大债务违约、重大诉讼仲裁、股权结构重大变化等；
  5. 内幕信息范围：重大事件+公司分配股利或增资计划+股权结构重大变化+债务担保重大变更+营业用主要资产抵押出售报废一次超过30%+董监高行为可能承担重大赔偿责任+上市公司收购方案等。
- **命题角度**：公开发行认定标准（不特定/200人）；虚假陈述责任主体与举证责任分配（过错推定）；内幕信息范围判断（转让专利权不属于内幕信息）。

### 考点33：内幕交易与投资者保护【中频】

- **核心法条**：《证券法》第50-53条、第88-95条
- **可背诵要点**：
  1. 内幕信息知情人：发行人及其董监高、持股**5%以上**的股东及其董监高、实际控制人、收购人、证券监管机构及中介机构人员等；
  2. 禁止内幕交易：知情人在内幕信息公开前**不得买卖**公司证券、**不得泄露**、**不得建议他人买卖**；
  3. 短线交易归入权：持股5%以上股东及董监高在**6个月内**买入后又卖出或卖出后又买入的，收益归公司所有；
  4. 操纵市场：禁止连续交易、约定交易、自买自卖（对倒）、蛊惑交易、抢帽子交易等操纵证券价格的行为；
  5. **投资者保护专章**（2019年新增）：普通投资者与证券公司纠纷的**强制调解**（普通投资者提出调解请求的，证券公司**不得拒绝**）；**证券代表人诉讼**——特别代表人诉讼采用"**默示加入、明示退出**"（投保机构受50名以上投资者委托可提起，胜诉赔偿对未退出的投资者均有约束力）；
  6. 证券虚假陈述等民事赔偿实行**优先赔付**：违法者的罚款罚金优先用于赔偿投资者损失。
- **命题角度**：内幕人员范围；6个月短线交易归入权；强制调解不得拒绝；"默示加入、明示退出"特别代表人诉讼机制；罚没款优先赔付。

## 八、反垄断法（共3个考点）

### 考点34：垄断协议（横向、纵向、轴幅）【高频】

- **核心法条**：《反垄断法》（2022年修正）第16-22条
- **可背诵要点**：
  1. **横向垄断协议**（具有竞争关系的经营者之间，第17条）：固定或变更商品价格；限制商品的生产数量或销售数量；分割销售市场或原材料采购市场；限制购买新技术、新设备或限制开发新技术、新产品；联合抵制交易；国务院反垄断执法机构认定的其他垄断协议；
  2. **纵向垄断协议**（第18条）：固定向第三人转售商品的价格；限定向第三人转售商品的最低价格（**转售价格维持RPM**）；经营者能证明**不具有排除、限制竞争效果**的可不予禁止；
  3. **安全港制度**（新增）：纵向垄断协议中，经营者能证明其市场份额**低于15%**且符合其他条件的，不禁止（安全港仅适用于纵向协议）；
  4. **轴幅协议**（第19条，新增）：经营者**不得组织其他经营者达成垄断协议或为其提供实质性帮助**（平台、行业协会等组织者承担责任）；
  5. 垄断协议豁免（第20条）：改进技术、提高质量、统一规格标准、中小企业、经济不景气救济、外贸等情形；
  6. 责任：没收违法所得+处上一年度销售额**1%-10%**罚款；尚未实施的处300万元以下罚款；上年度无销售额的处500万元以下罚款；情节特别严重的可处2-5倍罚款；对个人（法定代表人、主要负责人、直接责任人员）处100万元以下罚款（新增）。
- **命题角度**：横向vs纵向的识别（竞争关系经营者间=横向）；固定转售价格=纵向垄断协议；安全港15%；轴幅协议的组织者责任；罚款幅度数字。

### 考点35：滥用市场支配地位【高频】

- **核心法条**：《反垄断法》第22-24条
- **可背诵要点**：
  1. 市场支配地位：经营者在相关市场内具有能够**控制商品价格、数量或其他交易条件**，或**阻碍、影响其他经营者进入相关市场**的能力；
  2. 滥用行为：以不公平高价销售或以不公平低价购买；低于成本销售（掠夺性定价）；拒绝交易；限定交易（限定相对人只能与其或指定经营者交易）；搭售或附加不合理交易条件；对条件相同的交易相对人实行**差别待遇**；
  3. **推定规则**（第24条）：1个经营者份额**1/2**；2个经营者合计**2/3**；3个经营者合计**3/4**——但有经营者份额不足**1/10**的不推定；被推定者可举证反驳；
  4. 认定因素：市场份额与竞争状况、控制销售市场或采购市场的能力、财力和技术条件、交易依赖程度、市场进入难易程度等；
  5. 独占经营者和专利、专营专卖企业：对经营者行为依法监管，不得滥用地位排除限制竞争。
- **命题角度**：滥用行为类型识别（拒绝交易/限定交易/搭售/差别待遇）；推定份额数字（1/2、2/3、3/4及1/10例外）；低于成本销售的正当理由（季节性、清仓、新产品推广）。

### 考点36：经营者集中审查【中频】

- **核心法条**：《反垄断法》第25-38条；《经营者集中审查规定》
- **可背诵要点**：
  1. 经营者集中情形：经营者合并；取得股权或资产取得控制权；合同等方式取得控制权或能施加决定性影响；
  2. **事先申报**：达到国务院规定申报标准的，**实施前**申报，未申报不得实施集中（"抢跑"违法）；
  3. **免予申报**（第27条）：一个经营者拥有其他每个经营者**50%以上**有表决权的股份或资产的；每个经营者50%以上股份或资产被同一未参与集中的经营者拥有的；
  4. 审查程序：**初步审查30日**→决定是否进一步审查；进一步审查**90日**（可延长最长**60日**）；逾期未决定视为批准；
  5. 审查结果：禁止集中；不予禁止；**附条件批准**（剥离资产、开放网络等行为性/结构性救济）；经营者能证明集中对竞争的有利影响明显大于不利影响或符合社会公共利益的，可不予禁止；
  6. 违法实施集中：责令停止、限期处分股份或资产、限期转让营业，并处上一年度销售额**10%以下**罚款。
- **命题角度**：三类集中情形；免于申报的50%规则；审查期限（30/90/60日）；附条件批准的救济措施类型。

## 九、反不正当竞争法（共3个考点）

### 考点37：商业混淆与虚假宣传【高频】

- **核心法条**：《反不正当竞争法》（2019年修正）第6条、第8条
- **可背诵要点**：
  1. **商业混淆**（第6条）：擅自使用与他人**有一定影响的**商品名称、包装、装潢相同或近似的标识；擅自使用他人有一定影响的企业名称、社会组织名称、姓名；擅自使用有一定影响的**域名主体部分、网站名称、网页**等；其他足以引人误认为是他人商品或与他人存在特定联系的混淆行为；
  2. 混淆的构成：擅自使用+有一定影响+足以引人误认（混淆可能性），不要求实际混淆；
  3. **虚假宣传**（第8条）：经营者不得对商品的性能、功能、质量、销售状况、用户评价、曾获荣誉等作**虚假或引人误解的商业宣传**，欺骗、误导消费者；**不得帮助他人进行虚假宣传**（组织虚假交易、虚假好评等，刷单炒信入法）；
  4. 虚假宣传vs虚假广告：构成虚假广告的由《广告法》规制，但虚假宣传的一般条款可并行适用；
  5. 混淆行为与商标侵权竞合时：既可依反不正当竞争法，也可依商标法主张（不得双重受偿）。
- **命题角度**：混淆行为四类情形；"有一定影响"要件；刷单炒信、虚假好评归入帮助虚假宣传；与商标权保护的竞合处理。

### 考点38：侵犯商业秘密【高频】

- **核心法条**：《反不正当竞争法》第9条、第17条、第32条
- **可背诵要点**：
  1. 商业秘密三要件：**秘密性**（不为公众所知悉）、**价值性**（具有商业价值）、**保密措施**（权利人采取相应保密措施）；
  2. 侵犯商业秘密行为：以盗窃、贿赂、欺诈、胁迫、电子侵入或其他不正当手段获取；披露、使用或允许他人使用以前述手段获取的商业秘密；违反保密义务或权利人有关保守秘密的要求，披露、使用或允许他人使用；**教唆、引诱、帮助他人**违反义务获取披露使用；
  3. **第三人责任**：第三人明知或应知商业秘密来源违法，仍获取、披露、使用的，视为侵犯商业秘密；
  4. **举证责任**（第32条，2020年修正后有利于权利人）：权利人提供初步证据+合理表明商业秘密被侵犯，**由涉嫌侵权人证明**其不存在侵犯商业秘密的行为；权利人提供初步证据证明已对所主张的商业秘密采取保密措施且合理表明商业秘密被侵犯，涉嫌侵权人应证明其不存在侵犯商业秘密的行为；
  5. 赔偿：实际损失→侵权获利→法院酌定（上限**500万元**，恶意侵权情节严重的可**1-5倍**惩罚性赔偿）；
  6. **员工跳槽**：员工违反保密义务（竞业限制协议）或与原单位约定泄露商业秘密，构成侵权；但员工以自己掌握的知识技能合法再就业不当然侵权。
- **命题角度**：三要件判断（未采取保密措施的不构成商业秘密）；第三人善恶意；举证责任转移；惩罚性赔偿适用条件；与竞业限制、劳动法的交叉。

### 考点39：商业诋毁与互联网专条【中频】

- **核心法条**：《反不正当竞争法》第10-12条
- **可背诵要点**：
  1. **商业诋毁**（第11条）：编造、传播虚假信息或误导性信息，损害竞争对手的**商业信誉、商品声誉**——主体须为经营者（有竞争关系），且捏造/传播虚假误导性信息+造成商誉损害后果；
  2. 商业诋毁vs虚假宣传：诋毁针对竞争对手（贬低他人），虚假宣传针对自己（抬高自己），二者常同时发生；
  3. **互联网专条**（第12条，2017年新增）：经营者不得利用技术手段，通过影响用户选择或其他方式，实施下列妨碍、破坏其他经营者合法提供的网络产品或服务正常运行的行为：强制跳转（未经同意插入链接强制目标跳转）；误导、欺骗、强迫用户修改、关闭、卸载其他经营者的网络产品或服务；恶意不兼容（恶意对其他经营者合法提供的网络产品服务实施不兼容）；其他妨碍破坏行为；
  4. 互联网专条规制"流量劫持""屏蔽广告""数据爬取（不当方式）"等新型行为，但须以"正当竞争"为边界，技术中立的正当行为不构成。
- **命题角度**：诋毁主体的竞争关系要件；互联网专条四类行为识别；与反垄断法、消费者权益保护法在互联网场景下的竞合。

## 十、消费者权益保护法（共2个考点）

### 考点40：消费者权利与经营者义务【高频】

- **核心法条**：《消费者权益保护法》（2013年修正）第7-29条
- **可背诵要点**：
  1. 消费者**9项权利**：安全权、知情权、自主选择权、公平交易权、依法求偿权、结社权、受教育权、受尊重权（人格尊严、民族风俗习惯）、监督权；
  2. 经营者义务：真实信息提供、明码标价、出具凭证单据、质量保证、三包义务（修理、更换、退货，"7日内性能故障可退货"）、**缺陷产品召回**（第19条：发现商品或服务存在缺陷危及人身财产安全的，应立即采取停止销售、警示、召回等措施，并承担消费者因商品被召回支出的必要费用）；
  3. **7日无理由退货**（第25条）：网络、电视、电话、邮购等方式销售的商品，消费者有权自收到商品之日起**7日内退货**，无需说明理由；**例外**：消费者定作、鲜活易腐、在线下载或拆封的音像制品计算机软件等数字化商品、交付的报纸期刊，以及**不宜退货的其他商品经消费者在购买时确认**的；
  4. **耐用消费品举证责任倒置**（第23条第3款）：机动车、计算机、电视机、电冰箱、空调器、洗衣机等耐用商品或装饰装修等服务，自接受商品或服务之日起**6个月内**发现瑕疵发生争议的，**由经营者承担瑕疵举证责任**；
  5. 格式条款：经营者不得以格式条款、通知、声明、店堂告示等方式作出排除或限制消费者权利、减轻或免除经营者责任、加重消费者责任等**不公平、不合理规定**，否则无效；
  6. **网络交易平台责任**（第44条）：平台明知或应知销售者利用平台侵害消费者合法权益，**未采取必要措施的，承担连带责任**；平台作出更有利于消费者的承诺的，应履行（先行赔付）。
- **命题角度**：7日无理由退货的例外情形清单；6个月举证责任倒置；格式条款无效；平台连带责任条件；召回费用承担。

### 考点41：惩罚性赔偿【高频】

- **核心法条**：《消费者权益保护法》第55条；《食品安全法》第148条；最高法食品药品惩罚性赔偿司法解释（2024年）
- **可背诵要点**：
  1. **欺诈三倍赔偿**（第55条第1款）：经营者提供商品或服务有欺诈行为的，按消费者要求**增加赔偿其受到的损失，增加赔偿的金额为消费者购买商品的价款或接受服务的费用的3倍；不足500元的为500元**（保底500元）；
  2. **缺陷侵权二倍赔偿**（第55条第2款）：经营者**明知**商品或服务存在缺陷，仍向消费者提供，造成消费者或其他受害人**死亡或健康严重损害**的，受害人有权要求所受损失**2倍以下**的惩罚性赔偿；
  3. **食品安全惩罚性赔偿**（食安法第148条第2款）：生产不符合食品安全标准的食品或经营明知不符合食品安全标准的食品，消费者除赔偿损失外，可要求**支付价款10倍或损失3倍**的赔偿金；**增加赔偿的金额不足1000元的为1000元**（保底1000元）；
  4. 食品"知假买假"：为**个人或家庭生活消费需要**购买的，可主张惩罚性赔偿；2024年司法解释明确"消费者"认定以生活消费为目的，职业打假人牟利性购买（明显超出合理生活消费需要、以索赔牟利为主要目的）的，人民法院可以不予支持；
  5. 首负责任制：食品生产与经营者收到赔偿请求的先行赔付，不得推诿（生产者赔偿后向经营者追偿）。
- **命题角度**：三倍vs十倍vs二倍三种惩罚性赔偿的区分适用（价款3倍保底500元vs价款10倍或损失3倍保底1000元vs损失2倍）；欺诈构成（故意隐瞒真实情况）；食安法148条"明知"要件；知假买假的最新裁判规则。

## 十一、食品安全法与产品质量法（共2个考点）

### 考点42：食品安全法重点【中频】

- **核心法条**：《食品安全法》（2021年修正）第34条、第148条
- **可背诵要点**：
  1. 禁止生产经营的食品：用非食品原料生产的食品、添加食品添加剂以外的化学物质、致病性微生物/农药残留/兽药残留/重金属等污染物质含量超标、超过保质期、无标签的预包装食品、添加药品等；
  2. 食品安全标准：**强制性标准**，分国家标准、地方标准（无国家标准的）和企业标准（严于国标/地标的）；
  3. **惩罚性赔偿**（第148条，见考点41）：价款10倍或损失3倍，保底1000元；
  4. 网络食品交易第三方平台：对入网食品经营者进行**实名登记+审查许可证**；未审查造成损害的，与食品经营者承担**连带责任**（区别于消法平台的"明知应知"标准）；
  5. 食品安全事故处置：责任主体为食品生产经营者，实行**首负责任制**；食品安全监管部门依法履职。
- **命题角度**：禁止生产经营食品类型判断；平台连带责任（食安法"未审查即连带"vs消法"明知应知"）；10倍赔偿适用条件（不符合食品安全标准+不以造成损害为前提——消费者可主张价款10倍赔偿不以实际损害为要件，但赔偿请求须以"不符合食品安全标准"为前提）。

### 考点43：产品质量法重点【中频】

- **核心法条**：《产品质量法》第41-46条
- **可背诵要点**：
  1. 产品缺陷：产品存在**危及人身、财产安全的不合理的危险**，或不符合保障人体健康和人身财产安全的国家标准、行业标准；
  2. **生产者严格责任**：因产品存在缺陷造成人身、缺陷产品以外其他财产损害的，生产者应承担赔偿责任，**不问过错**（无过错责任）；
  3. 生产者**免责事由**（第41条）：未将产品投入流通；投入流通时缺陷尚不存在；投入流通时科学技术水平尚不能发现缺陷的存在（发展风险抗辩）；
  4. **销售者过错责任**：因销售者过错（如进货检验不严、仓储不当）使产品存在缺陷造成损害的，销售者赔偿；销售者**不能指明缺陷产品的生产者也不能指明供货者的，承担赔偿责任**；
  5. **追偿**：生产者赔偿后有权向有过错的销售者追偿，反之亦然（最终责任者担责）；
  6. 诉讼时效：因产品缺陷造成损害要求赔偿的诉讼时效**2年**，自当事人知道或应当知道权益受损之日起算；请求权最长期限：**缺陷产品交付最初消费者之日起10年**（未超过明示安全使用期的除外）；
  7. 与消法的竞合：消费者购买产品受害的，既可依消法（含55条惩罚性赔偿）也可依产品质量法主张，择一适用（产品责任属侵权责任）。
- **命题角度**：生产者无过错责任vs销售者过错责任+不能指明时兜底；三免责事由；2年诉讼时效与10年除斥期间；"缺陷"与"瑕疵"区分（瑕疵指不符合质量标准，不当然危及安全）。

## 十二、劳动法（共2个考点）

### 考点44：劳动合同的订立与解除【高频】

- **核心法条**：《劳动合同法》第10条、第14条、第19-20条、第22-24条、第36-42条
- **可背诵要点**：
  1. 建立劳动关系应订立**书面劳动合同**；**用工之日起1个月内**订立；超过1个月不满1年未订立的，**每月支付2倍工资**；满1年未订立的，视为订立**无固定期限劳动合同**（第82条）；
  2. **无固定期限劳动合同**（第14条）：劳动者在该单位**连续工作满10年**；**连续订立2次固定期限劳动合同**且劳动者无过失情形，续订时劳动者提出或同意续订的（应订未订的视为无固定期限）；
  3. **试用期**（第19条）：合同期限3个月以上不满1年的≤1个月；1年以上不满3年的≤2个月；**3年以上及无固定期限≤6个月**；同一单位与同一劳动者**只能约定一次试用期**；以完成一定工作任务为期限或期限不满3个月的**不得约定**试用期；试用期工资≥本单位相同岗位最低档工资或合同约定工资的**80%**，且不低于当地最低工资标准；
  4. **违约金限制**：仅两种情形可约定违约金——**服务期**（单位提供专项培训费用）和**竞业限制**（高级管理人员、高级技术人员和其他负有保密义务的人员，期限不超过**2年**，单位按月支付经济补偿）；
  5. 用人单位解除劳动合同三种路径：
     - **过失性辞退**（第39条）：试用期不符合录用条件、严重违反规章制度、严重失职营私舞弊给单位造成重大损害、**兼职**对完成本单位工作造成严重影响或经提出拒不改正、以欺诈胁迫手段订立合同、被追究刑事责任——**无需预告、无需支付经济补偿**；
     - **非过失性辞退**（第40条）：患病或非因工负伤医疗期满不能从事原工作也不能另行安排工作、不能胜任工作经培训或调岗仍不能胜任、客观情况重大变化致合同无法履行经协商不能变更——须**提前30日书面通知或额外支付1个月工资（代通知金）+支付经济补偿**；
     - **经济性裁员**（第41条）：破产重整、生产经营严重困难、转产重大技术革新或经营方式调整经变更合同后仍需裁减人员等——裁减**20人以上或10%以上**须提前30日向工会或全体职工说明情况+听取意见+向劳动行政部门报告；**6个月内重新招用人员的应优先招用被裁减人员**；
  6. **不得解除**（第42条）：职业病危害作业未进行离岗前职业健康检查或疑似职业病诊断观察期间、患职业病或因工负伤被确认丧失或部分丧失劳动能力、患病或非因工负伤在**规定的医疗期内**、**女职工在孕期、产期、哺乳期**、在本单位连续工作满15年且距法定退休年龄不足5年等。
- **命题角度**：2倍工资与无固定期限的衔接；试用期期限/次数/工资比例数字；违约金法定情形；39条vs40条vs41条对比（有无补偿、有无预告）；42条禁止解除情形（与39条过失辞退可以解除不冲突）。

### 考点45：经济补偿金、赔偿金与劳动争议解决【高频】

- **核心法条**：《劳动合同法》第46-47条、第87条；《劳动争议调解仲裁法》第2条、第27条、第47条
- **可背诵要点**：
  1. **经济补偿金（N）**：用人单位应当支付的情形（第46条）：协商解除（单位提出）；非过失性辞退；经济性裁员；合同期满终止（单位不续订或降低条件续订）；单位破产、吊销执照、责令关闭、撤销或决定提前解散等终止；单位违法情形下劳动者被迫解除（第38条：未及时足额支付报酬、未依法缴纳社保、规章制度违法损害权益、强迫劳动、未支付加班费、低于最低工资等）；
  2. 补偿标准：**每满1年支付1个月工资**；6个月以上不满1年按1年计；不满6个月支付**半个月工资**（"1年1个月、半年半月"）；月工资为解除前**12个月平均工资**；月工资高于当地上年度职工月平均工资**3倍**的，按3倍封顶，且**年限不超过12年**；
  3. **赔偿金（2N）**：单位违法解除或终止合同，劳动者要求继续履行的应继续履行；不要求或不能继续履行的，单位按经济补偿标准的**2倍**支付赔偿金（第87条）；
  4. 赔偿金与经济补偿金**不能并存**（适用2N则不再适用N）；
  5. **劳动争议解决程序**：协商→调解（企业劳动争议调解委员会、基层人民调解组织等）→**仲裁前置**→诉讼；仲裁时效**1年**（自知道或应当知道权利被侵害之日起，劳动关系存续期间因拖欠劳动报酬发生争议的不受1年限制，但劳动关系终止的应自终止之日起1年内提出）；
  6. 一裁终局（小额争议）：追索劳动报酬、工伤医疗费、经济补偿或赔偿金，不超过当地月最低工资标准**12个月金额**的争议，以及执行国家劳动标准在工作时间、休息休假、社会保险方面发生的争议——裁决为**终局裁决**（劳动者不服可起诉；用人单位仅可申请撤销）；
  7. 劳务派遣：只能在**临时性、辅助性、替代性**岗位实施，用工数量不得超过用工总量**10%**；被派遣劳动者与**劳务派遣单位**建立劳动关系。
- **命题角度**：N/2N/代通知金（+1）的计算与适用情形对比；"被迫解除"（38条）情形清单；3倍封顶+12年封顶；仲裁前置与一裁终局；劳务派遣三性岗位。

## 十三、著作权法（共3个考点）

### 考点46：著作权客体与内容【高频】

- **核心法条**：《著作权法》（2020年修正）第3条、第5条、第10-11条、第16-19条
- **可背诵要点**：
  1. 作品类型（第3条，开放式列举）：文字、口述、音乐戏剧曲艺舞蹈杂技、美术建筑、摄影、视听、工程设计图产品设计图地图示意图、模型、计算机软件、符合作品特征的其他智力成果；
  2. **不受著作权法保护**（第5条）：法律、法规及官方正式译文；**时事新闻**（单纯事实消息）；历法、通用数表、通用表格和公式；以及依法禁止出版传播的作品（第4条）；
  3. **著作权内容**：
     - 人身权4项：**发表权**（决定作品是否公之于众，一次行使完毕）、**署名权**、**修改权**、**保护作品完整权**；
     - 财产权（13项）：复制、发行、出租、展览、表演、放映、广播、信息网络传播、摄制、改编、翻译、汇编以及应当由著作权人享有的其他权利；
  4. **保护期**：署名权、修改权、保护作品完整权**不受期限限制**；发表权和财产权：自然人作品——**作者终生+死亡后50年**（第50年12月31日截止）；法人或非法人组织作品、视听作品、职务作品——**发表后50年**（创作后50年内未发表的不再保护）；出版者版式设计10年、表演者/录音录像制作者50年、广播组织50年；
  5. 作者认定：创作作品的公民是作者；**视为作者**（推定）：由法人或非法人组织主持、代表其意志创作、由其承担责任的作品；
  6. **职务作品**：一般职务作品著作权归**作者**（单位2年内业务范围内优先使用）；**特殊职务作品**（主要利用单位物质技术条件创作并由单位承担责任的工程设计图、产品设计图、地图、计算机软件等）——作者享有**署名权**，其他著作权归**单位**；
  7. 委托作品：约定优先，无约定归**受托人**；影视作品著作权归**制作者**，编剧、导演、摄影、作词作曲等作者享有署名权。
- **命题角度**：不受保护对象的判断（时事新闻vs新闻评论——评论受保护）；人身权与财产权归属；特殊职务作品归属；委托作品无约定归受托人；保护期起点与终点计算。

### 考点47：合理使用与法定许可【高频】

- **核心法条**：《著作权法》第24-25条
- **可背诵要点**：
  1. **合理使用**（第24条，12种情形，**无需许可、无需付费、须指明作者与作品名称**）：个人学习研究欣赏使用；适当引用（为介绍评论说明）；为报道时事新闻不可避免再现；**课堂教学或科学研究**（翻译、改编、汇编并出版发行除外——"教学科研中的少量复制使用"）；国家机关执行公务合理使用；**图书馆、档案馆等为陈列或保存版本需要**复制本馆收藏作品；免费表演已发表作品（不向公众收费、不向表演者支付报酬）；对室外公共场所艺术作品以临摹绘画摄影录像方式使用；将中国公民法人作品以**汉文和少数民族语言文字**在国内出版发行；**以阅读障碍者能够感知的无障碍方式**提供（2020年新增）；对设置或陈列在室外公共场所的艺术作品进行临摹等；
  2. 合理使用判断标准：**不得影响作品正常使用、不得不合理损害著作权人合法权益**；
  3. **法定许可**（第25条，无需许可但须付费）：教科书编写出版使用他人作品（但不得侵害著作权人权益，作者事先声明不许使用的除外）；报刊转载摘编（作者声明不得转载的除外）；录音制作者使用他人已合法录制为录音制品的音乐作品制作录音制品；广播电台、电视台播放他人已发表的作品；
  4. 合理使用与法定许可的区别：前者免费（免许可+免付费），后者付费（免许可+须付费）。
- **命题角度**：12种合理使用情形识别（KTV播放、商场背景音乐、网上转载均非合理使用）；"免费表演"要件（不收费+不付酬+观众可免费入场）；教科书法定许可；无障碍格式版本；合理使用的三步检验法。

### 考点48：邻接权与著作权侵权【中频】

- **核心法条**：《著作权法》第29-45条、第52-54条
- **可背诵要点**：
  1. 邻接权四种：**表演者权**（许可他人现场直播、录音录像、复制发行、信息网络传播等；表演者人身权——表明表演者身份、保护表演形象不受歪曲）；**录音录像制作者权**（复制、发行、出租、信息网络传播——**出租权**是录音录像制作者特有）；**广播组织权**（转播、录制复制——**10年**）；**出版者权**（版式设计专有权——**10年**）；
  2. 表演者权归属：演员等表演者的权利保护期50年（表演发生后第50年12月31日）；职务表演（单位组织）的财产权归单位；
  3. **著作权侵权**（第52条）：未经许可发表、复制、发行、出租、表演、放映、广播、信息网络传播、剽窃抄袭（抄袭他人作品）、未经合作作者许可将合作作品当独作发表等；
  4. **赔偿**（第54条）：实际损失→侵权获利→**参照权利许可使用费**→**法定赔偿500元以上500万元以下**（2020年修改，上限从50万提高至500万）；**故意侵权且情节严重**的，可**1-5倍惩罚性赔偿**；举证妨碍规则（侵权人不提供账簿资料的，可参考权利人主张和证据确定）；
  5. 合理费用（律师费、公证费等）应计入赔偿数额；
  6. 网络服务提供者责任（第50-51条）：接到权利人**通知后未及时删除/断开链接**的，对扩大的损失与侵权人承担**连带责任**（通知-删除规则）；知道或应知侵权仍提供网络服务的连带责任。
- **命题角度**：表演者权vs录音录像制作者权vs广播组织权的内容与期限对比；出租权的归属（录音录像制作者）；法定赔偿上限500万与惩罚性赔偿；通知-删除规则下平台责任。

## 十四、专利法（共3个考点）

### 考点49：专利权客体与授予条件【高频】

- **核心法条**：《专利法》（2020年修正）第2条、第5条、第22-25条
- **可背诵要点**：
  1. 三类客体：**发明**（20年）、**实用新型**（10年）、**外观设计**（**15年**，2020年修改由10年延长至15年，自申请日起算）；
  2. **发明、实用新型三性**（第22条）：**新颖性**（不属于现有技术，也没有任何单位或个人在申请日以前就同样的发明或实用新型提出过申请并记载在申请日以后公布的专利申请文件中；宽限期——申请日前**6个月**内在中国政府主办或承认的国际展览会首次展出、在规定的学术会议或技术会议上首次发表、他人未经同意泄露的不丧失新颖性）；**创造性**（与现有技术相比有突出的实质性特点和显著进步）；**实用性**（能够制造或使用，并能产生积极效果）；
  3. 外观设计授权条件：**新颖性+创造性（与现有设计或现有设计特征组合有明显区别）+不得与他人在先取得的合法权利冲突**，且不得是**功能性**设计；
  4. **不授予专利权的对象**（第25条）：科学发现；智力活动的规则和方法；疾病的**诊断和治疗方法**（药品和医疗器械可授权）；动物和植物品种（生产方法可授权）；原子核变换方法及用该方法获得的物质；对平面印刷品的图案、色彩或二者的结合作出的**主要起标识作用的设计**；
  5. **其他排除**（第5条）：违反法律、社会公德或妨害公共利益的发明创造；依赖遗传资源完成但违反法律、行政法规获取或利用遗传资源的；
  6. 申请原则：先申请原则（同日申请的，先使用或先设计的先得）、单一性原则、优先权（发明/实用新型**12个月**、外观设计**6个月**内首次申请可享有外国优先权）。
- **命题角度**：三性概念与宽限期；不授权清单（发现、智力活动规则、诊断治疗方法、动植物品种、原子核方法）；外观设计保护期15年；先申请原则与同日申请处理。

### 考点50：职务发明与专利权归属【高频】

- **核心法条**：《专利法》第6条、第8条；《专利法实施细则》第12-13条
- **可背诵要点**：
  1. **职务发明创造**：执行本单位的任务（本职工作、履行本职工作以外的临时工作、退休/调动/离职后**1年内**作出的与原单位本职工作或分配任务有关的发明创造）或**主要利用本单位的物质技术条件**完成的发明创造；
  2. 职务发明申请专利的权利归**单位**（专利申请被批准后单位为专利权人）；发明人有**署名权**和获得**奖励报酬**的权利（职务发明奖励：发明专利**不低于4000元**、实用新型/外观设计**不低于1500元**，实施后每年或一次性给予报酬，2023年实施细则修改）；
  3. 非职务发明：申请权归**发明人或设计人**个人；单位可以与其约定署名、奖励等；
  4. **合作发明与委托发明**：有协议从协议，无协议的——合作完成的申请权归**合作各方共有**；委托完成的申请权归**完成发明创造的一方**（受托人），委托人可以在**免费实施**该专利的范围内使用；
  5. 共有人行使专利权：自行实施+普通许可无需全体同意；**转让、独占/排他许可、出质须经全体共有人同意**（另有约定除外）。
- **命题角度**：离职1年内职务发明的认定；主要利用单位物质条件的判断；委托发明无约定归受托人（委托人可免费实施）；共有专利的处分规则（转让需全体同意）。

### 考点51：专利侵权判定与抗辩【高频】

- **核心法条**：《专利法》第59条、第64-65条、第75条
- **可背诵要点**：
  1. 保护范围：发明或实用新型以**权利要求书**内容为准，说明书及附图可用于解释；外观设计以**图片或照片**所示产品为准；
  2. 侵权判定原则：**全面覆盖原则**（被控技术方案包含权利要求记载的全部技术特征）——相同侵权+**等同侵权**（以基本相同的手段、实现基本相同的功能、达到基本相同的效果，且本领域普通技术人员无需创造性劳动即可联想到，被禁止反悔原则限制）；
  3. **不视为侵犯专利权的情形**（第75条，法定抗辩）：权利用尽（专利产品售出后使用、许诺销售、销售、进口该产品）；先用权（在**专利申请日前**已制造相同产品、使用相同方法或已作好必要准备，并且仅在**原有范围**内继续制造、使用的）；临时过境（外国运输工具依条约或互惠原则过境中国）；专为**科学研究和实验**而使用（不构成侵权，区别于"生产经营目的"）；为提供行政审批所需信息（药品、医疗器械注册）而制造、使用、进口专利药品或医疗器械的（**Bolar例外**）；
  4. 诉讼中的程序性规则：专利侵权诉讼中，被告主张宣告专利权无效的，法院一般应**中止诉讼**（实用新型、外观设计须专利管理部门出具评价报告；发明专利不中止）；
  5. 赔偿（第71条）：实际损失→侵权获利→许可使用费合理倍数→**法定赔偿3万元以上500万元以下**（2020年修改，下限3万上限500万）；**故意侵权情节严重**可**1-5倍惩罚性赔偿**；举证妨碍规则；
  6. **药品专利链接制度**（2020年新增）：仿制药上市申请应与专利权人解决专利纠纷；**开放许可**（2020年新增）：专利权人自愿声明许可，开放许可期间专利年费减免。
- **命题角度**：等同侵权与全面覆盖原则；先用权抗辩的构成（申请日前+原有范围）；科研实验使用vs生产经营目的（科研目的也不得销售）；Bolar例外；法定赔偿额度；宣告无效与中止诉讼。

## 十五、商标法（共3个考点）

### 考点52：商标注册条件与禁用标志【高频】

- **核心法条**：《商标法》（2019年修正）第8-12条、第13条、第30-33条、第49条
- **可背诵要点**：
  1. 注册原则：**申请在先原则**（两个以上申请人同日申请的，**使用在先**者获得；均未使用的协商，协商不成**抽签决定**）；自愿注册原则（烟草制品等强制注册例外）；
  2. 注册条件：**显著性**（能区分商品来源）+可识别性；平面、立体、颜色组合、声音均可注册；
  3. **绝对禁用标志**（第10条，不得注册不得使用）：与我国国家名称、国旗、国徽、军旗等相同近似的；同外国国家名称、国旗相同近似或有害于其国家尊严的（经该国政府同意的除外）；同政府间国际组织名称旗帜徽记相同近似的（经该组织同意或不易误导公众的除外）；与表明实施控制、予以保证的官方标志、检验印记相同近似的（经授权的除外）；同"红十字""红新月"名称标志相同近似的；带有**民族歧视性**的；带有欺骗性（夸大宣传并带有欺骗性，容易使公众对商品质量特点或产地产生误认）；**有害于社会主义道德风尚或有其他不良影响的；县级以上行政区划的地名或公众知晓的外国地名**（地名具有其他含义或作为集体商标、证明商标组成部分的除外）；
  4. **相对不得注册**（第11-12条）：仅有本商品**通用名称、图形、型号**的；仅直接表示商品的**质量、主要原料、功能、用途、重量、数量**等缺乏显著特征的；其他缺乏显著特征的（经使用取得显著特征并便于识别的可作为商标注册）；**仅由商品自身性质产生的形状、为获得技术效果而需有的形状或使商品具有实质性价值的形状**的三维标志不得注册；
  5. 与他人在先权利冲突：不得与他人在先注册的商标相同近似（同一种或类似商品上）；**抢注**：不得以不正当手段抢先注册**他人已经使用并有一定影响**的商标；被代理人/被代表人的商标、地理标志等；
  6. **连续3年不使用**的注册商标，任何人可申请**撤销**（第49条，"撤三"制度）。
- **命题角度**：禁用标志识别（地名、国旗、红十字符号、欺骗性标志）；三维标志功能性不得注册；"撤三"制度；同日申请的处理顺序（使用在先→协商→抽签）。

### 考点53：商标侵权认定【高频】

- **核心法条**：《商标法》第57条、第63条；《商标侵权判断标准》（2020年）
- **可背诵要点**：
  1. **商标侵权情形**（第57条）：（1）未经许可，在**同一种商品上使用与其注册商标相同商标**（假冒，推定混淆）；（2）在同一种商品上使用近似商标，或在类似商品上使用相同或近似商标，**容易导致混淆**的；（3）销售侵犯注册商标专用权商品（销售者的"不知情+能证明合法来源"可免赔偿责任，但须停止销售——**合法来源抗辩**）；（4）伪造、擅自制造注册商标标识或销售；（5）未经商标注册人同意，**更换其注册商标并将该更换商标的商品又投入市场**（反向假冒）；（6）故意为侵犯他人商标权行为**提供便利条件**（仓储、运输、邮寄、印制、隐匿、经营场所、网络平台等）；（7）给他人注册商标专用权造成其他损害；
  2. 侵权判定以"**商标使用**"为前提，以相同/近似+相同/类似商品+混淆可能性为核心；**描述性使用、指示性使用（为说明商品特性而使用他人商标）不构成侵权**；
  3. **赔偿**（第63条）：实际损失→侵权获利→商标许可使用费的倍数→**法定赔偿500万元以下**；**恶意侵权且情节严重的可1-5倍惩罚性赔偿**；为制止侵权的合理开支计入赔偿；假冒注册商标构成犯罪的移送司法机关；
  4. 诉前禁令（行为保全）：商标注册人或利害关系人有证据证明他人正在或即将实施侵权，如不及时制止将使其合法权益受到难以弥补的损害的，可在起诉前向法院申请**责令停止有关行为**（保全）；
  5. 海关保护：商标权人可申请**海关扣留**侵权嫌疑货物。
- **命题角度**：假冒（同一种+相同商标，无需混淆证明）vs近似混淆侵权；合法来源抗辩要件（善意+来源合法）；反向假冒；描述性使用/指示性使用不侵权；赔偿额确定顺序与惩罚性赔偿。

### 考点54：驰名商标与商标权的期限、续展【高频】

- **核心法条**：《商标法》第13-14条、第39-40条；驰名商标司法解释
- **可背诵要点**：
  1. **驰名商标认定原则**：**个案认定、被动认定、按需认定**（仅在争议案件中应当事人请求认定，不作为广告宣传，不得在商品包装上标注"驰名商标"字样）；认定因素：相关公众知晓程度、持续使用时间、宣传工作的持续时间程度地理范围、作为驰名商标受保护的记录等；
  2. **跨类保护**（第13条）：就**相同或类似商品**申请注册的商标是复制、摹仿或翻译他人**未在中国注册的驰名商标**，容易导致混淆的，不予注册并禁止使用；就**不相同或不相类似商品**申请注册的是复制、摹仿或翻译他人**已在中国注册的驰名商标**，误导公众致使驰名商标注册人利益可能受到损害的，不予注册并禁止使用——**未注册驰名商标同类保护、已注册驰名商标跨类保护**；
  3. 驰名商标所有人对恶意注册可请求宣告无效**不受5年期间限制**（普通情形为自商标注册之日起**5年内**请求宣告无效，驰名商标+恶意注册的例外）；
  4. **有效期与续展**：注册商标有效期**10年**，自**核准注册之日**起算；期满前**12个月内**可办理续展，未能办理的有**6个月宽展期**；每次续展有效期**10年**，续展次数不限；
  5. 转让与许可：注册商标转让须双方共同申请、经核准并公告；商标使用许可（独占、排他、普通许可）应**备案**，未备案不得对抗善意第三人；受让人、被许可人应**保证使用该注册商标的商品质量**；
  6. 商标权**用尽**：注册商标专用权人售出的商品，他人再销售、使用不构成侵权（平行进口问题按司法实践处理）。
- **命题角度**：驰名商标"个案认定、被动认定、按需认定"；未注册驰名商标与已注册驰名商标保护范围的区别（同类vs跨类）；宣告无效的5年期间及驰名恶意例外；续展时间节点（期满前12个月+6个月宽展期）。

## 十六、2026年新增必考预测与复习建议

### 考点55：新法新增点清单（新增必考）【高频·提示性】

- **可背诵要点**（按部门法梳理）：
  1. **公司法（2024.7.1施行）**：五年实缴制与加速到期（第47、54条）；股东失权制度（第52条）；未届期股权转让补充责任（第88条）；横向人格否认（第23条第2款）；法定代表人选任范围扩大与辞任联动（第10条）；审计委员会替代监事会（第69条）；简易合并（第219条）；简易注销（第240条）；董事为清算义务人（第232条）；一人股份公司（第92条）；股东知情权扩展（第57条）；控股股东滥权时的回购请求权（第89条第3款）；非上市股份公司异议股东回购（第161条）；双重代表诉讼（第189条第4款）；董监高忠实勤勉义务精细化（第180条）；
  2. **反垄断法（2022.8.1施行）**：安全港制度（纵向协议15%）；轴幅协议与组织帮助者责任（第19条）；个人责任（法定代表人等100万元以下罚款）；公平竞争审查制度入法；
  3. **著作权法（2021.6.1施行）**：视听作品取代电影作品；合理使用新增无障碍格式条款；法定赔偿上限500万元；惩罚性赔偿（故意+情节严重，1-5倍）；表演者权、录音录像制作者权数字化；
  4. **专利法（2021.6.1施行）**：外观设计保护期延长至15年；局部外观设计；药品专利链接与早期解决机制；开放许可制度；惩罚性赔偿（1-5倍）与法定赔偿（3万-500万）；
  5. **商标法（2019.11.1施行）**：恶意抢注规制强化（不以使用为目的的恶意注册不予注册）；代理机构义务；惩罚性赔偿（恶意+情节严重，1-5倍）；
  6. **最高人民法院食品药品惩罚性赔偿司法解释（2024）**：生活消费需要+惩罚性赔偿的适用范围，"知假买假"裁判规则明确化；
  7. **《公司登记管理实施办法》（2025.2.10施行）**：注册资本登记管理细化，2027年6月30日前存量公司过渡期安排。
- **命题角度**：新法条文直接设题，特别注意"数字型考点"（5年、60日、6个月、1年、15%、500万元等）与"对比型考点"（新旧制度差异）。

### 考点56：商经知主观题备考要点【高频·提示性】

- **核心要点**：
  1. 主观题以**公司法+破产法**为主，常与民法（合同效力、担保、代位权）、民诉（举证责任）结合考查"民商结合"综合题；
  2. 高频主观题模型：公司设立→出资瑕疵/抽逃→股权转让→股东权利受损→决议效力→董监高责任→公司解散清算/破产——一条龙设问；
  3. 作答模板：结论先行→援引法条（条文序号）→要件分析→结论复述；涉及连带责任的须写明责任主体与范围（如"转让人在受让人未缴纳出资范围内承担补充责任"）；
  4. 破产法主观题重点：破产原因认定、管理人职责、撤销权期间与行为、抵销禁止、债权申报程序、清偿顺位。

## 十九、冲刺复习建议

1. **第一阶段（基础）**：公司法通读法条+司法解释（解释三、解释四），掌握新公司法全部新增制度；破产法重点突破撤销权/取回权/抵销权与三程序；知产三法以"要件清单+期限表"方式过一遍；
2. **第二阶段（强化）**：反复背诵本资料"可背诵要点"部分，配合真题检验——重点做近5年商经知真题，错题回归考点；注意数字型考点（见第十七节速记表）必须零失误；
3. **第三阶段（冲刺）**：只背高频与新增必考点；主观题至少手写3套商法综合题；考前默写"新公司法十大新增制度"清单。
