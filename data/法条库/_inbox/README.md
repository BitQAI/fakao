# 法条原文投递目录

官方站（flk.npc.gov.cn）的全文托管在内网 OSS，公网取不到，所以新增法条的
**正文**由人工投递到这里，再用脚本归一入库。

## 用法

1. 把法律原文存成 `.txt` 或 `.md`（docx/pdf 请先转纯文本），文件名用**法名**，
   例如 `中华人民共和国商标法.txt`。
2. 跑归一脚本：

   ```bash
   cd backend
   .venv/bin/python scripts/normalize_statutes.py --dry-run   # 先看结果
   .venv/bin/python scripts/normalize_statutes.py             # 写入 data/法条库/
   ```

3. 归一后的文件会落到 `data/法条库/<法名>.md`，格式与其他法条一致
   （文件头元信息 + `第X条　正文`），随后会自动被法条检索页与条目校验使用。

## 脚本会自动做的事

- 保留 `第X编 / 第X章 / 第X节` 标题行，构建目录结构
- 保留 `第X条` 正文，多段自动合并到同一条
- 统一成「第十条　正文」写法（阿拉伯数字条号转中文）
- 丢弃目录、页眉页脚、颁布说明等非条文行
- 校验条号递增，异常会在输出里列出来
- 从 `../_meta.json`（由 `scripts/fetch_statutes.py` 生成）取公布日／施行日／bbbs 写进文件头

## 注意

- 本目录内的**原始投递文件**已被 `.gitignore` 排除，只有归一后的 `.md` 会进仓库。
- 条号写法混乱、扫描件乱码严重的原文请先清洗；转换质量不达标的直接丢弃，不要将就入库。
