# 法考近5年命题趋势与1个月在职备考指南（客观题篇）

> 适用范围：备考目标仅为**客观题**（卷一+卷二，300分，180分过线），不涉及主观题。
> 整理日期：2026-08-12

---

## 一、结论先行

近5年（2021–2025）法考命题的主线是**从"背法条"转向"用法律"**，核心方向可以概括为三句话：**实务案例化、跨学科综合化、新法热点必考化**，同时理论法"政治化"（习近平法治思想）权重持续加大。客观题通过率整体走低（2024年约13%–14%，2025年整体约15%左右，且发证规模被控制）。

**在职备考1个月（仅客观题）：可行，但只适合有法律基础或二战考生。** 按每天3小时+周末加练算，全月有效学习时间约110–140小时，策略必须是"抓大放小、以题带学、放弃低性价比科目"。零基础裸奔通过概率很低，需要理性评估。

---

## 二、近5年命题方向（2021–2025）

| 趋势 | 具体表现 |
|---|---|
| 实务化 / 案例化 | 客观题基本脱离法条直接复述，全部依托生活化场景命题。如2025年考"网红直播带货虚假宣传"区分诈骗罪与虚假广告罪、"职场性骚扰"侵权责任与举证规则 |
| 综合化 / 跨学科 | 题目篇幅明显变长、人物关系复杂，一道题常融合民法+民诉、商法+民诉甚至刑民交叉，需要"立体化"拆解法律关系 |
| 热点化 / 新法必考 | "重者恒重"未变，但**新增、新修法律几乎必考**：2025年考了《民营经济促进法》、刑诉新规；2023年修订《公司法》（2024年施行）已成为商法绝对重点 |
| 去模板化 / 反押题 | 传统"必考"知识点比重下降，考纲内冷门内容反而成为命题点；单纯靠记忆背诵已难以应对客观题判断 |
| 政治化 | 2021年起理论法命题政治性明显加强，法治思想客观题稳定约10分，常结合时政热点而非单纯考法条 |
| 重者恒重 | 各科核心考点稳定：刑法抓财产犯罪、人身犯罪、犯罪构成；民法抓合同、侵权、物权；刑诉抓证据规则、强制措施；公司法抓新修条款 |

### 客观题结构与分值分布

- **客观题**：分卷一、卷二两场，各150分，共300分，**180分过线**。
  - 卷一：法治思想、法理学、宪法、中国法律史、国际法、司法制度和法律职业道德、刑法、刑事诉讼法、行政法与行政诉讼法
  - 卷二：民法、知识产权法、商法、经济法、环境资源法、劳动与社会保障法、国际私法、国际经济法、民事诉讼法

近年各科分值参考（客观题，历年略有浮动）：

| 科目 | 分值区间 | 备注 |
|---|---|---|
| 商经知 | 53–63 | 分值最高，公司法为核心 |
| 理论法 | 50–56 | 法治思想10、法理学15、宪法15、司法制度与职业道德10、法律史6 |
| 民法 | 44–54 | 理解型，案例大户 |
| 刑法 | 36–39 | 理解型，案例大户 |
| 刑诉法 | 32–35 | 程序法，重记忆 |
| 民诉法 | 24–34 | 程序法，重记忆 |
| 行政法 | 22–25 | 客观题性价比一般 |
| 三国法 | 15–19 | 短期突击有效 |

### 竞争环境数据（机构统计口径，官方以司法部公告为准）

- 报名人数：2020年约70.8万 → 2024年96万+ → 2025年约93万（首次下降）
- 通过率：2024年客观题通过率约13%–14%；2025年整体通过率约15%左右，预计客观题继续走低
- 发证规模：2024年非应届领证约12.7万 → 2025年约11.4万，政策方向为"提质减量"

## 三、1个月在职备考方案（仅客观题）

### 1. 总策略

**三选一抓重点，用真题反推考点，放弃完美主义。**

- 只做客观题，不碰主观题写作；
- 前3周按科目"过讲义+刷真题"，第4周全部用于机考模考和错题复盘；
- 每个科目先做近3年真题，把错题背后的考点反查回讲义，以题带学。

### 2. 科目优先级（按性价比）

| 优先级 | 科目 | 投入时间 | 方法 |
|---|---|---|---|
| 必抓（70%） | 民法、刑法、民诉、刑诉 | 每天核心时段 | 理解+刷题并重，刑法抓财产/人身犯罪与犯罪构成，民法抓合同、侵权、物权，程序法用"流程图+口诀"记忆 |
| 高性价比（20%） | 法治思想+宪法、公司法（新修）、三国法 | 早晚碎片时间 | 背诵型科目短期提分快；公司法逐条吃透新修条款；三国法集中刷高频考点 |
| 放弃/弱化（10%） | 法律史、知产细枝末节、冷门经济法、行政法低频考点 | 不主动投入 | 只靠刷题顺带覆盖，不再单独复习 |

### 3. 四周计划

| 周次 | 科目 | 目标 | 检验标准 |
|---|---|---|---|
| 第1周 | 刑法 + 民法 | 1.5倍速过背诵版讲义，完成对应章节真题 | 高频考点题正确率≥60% |
| 第2周 | 刑诉 + 民诉 + 行政法 | 流程图+口诀记程序，重点背证据规则、管辖、期限 | 程序题不再凭感觉选 |
| 第3周 | 商经知（公司法）+ 理论法 + 三国法 | 集中背诵，公司法新修逐条过 | 法治思想、宪法、三国法背诵题正确率≥70% |
| 第4周 | 全真模考 + 复盘 | 每2天一套机考模拟（卷一、卷二连做），错题归因 | 模考稳定≥180分 |

### 4. 每日时间模板（在职）

| 时段 | 时长 | 内容 |
|---|---|---|
| 通勤 | 40分钟 | 听法治思想/宪法音频，或背口诀 |
| 午休 | 20–30分钟 | 手机App刷20题，只刷错题对应考点 |
| 工作日晚上 | 2.5–3小时 | 1小时听课 + 1.5小时刷题 + 15分钟错题归因 |
| 周末 | 每天8–10小时 | 半天模考、半天专项补弱 |

### 5. 刷题方法

- **分科刷**：按科目和考点分类刷，避免东一榔头西一棒子；
- **错题归因**：分三类处理——知识型错误（没记牢→回归讲义）、技巧型错误（漏看关键信息→训练审题）、思维型错误（推理逻辑不对→看解析重建思路）；
- **每周复盘**：固定时间集中攻克本周错题对应考点；
- **限时训练**：单选1分钟内、多选/不定项1分半内，训练题感与速度。

### 6. 考场策略

- 目标180分，允许放弃20%左右的低性价比题，不必每题都死磕；
- 单选快速作答，把时间留给多选和不定项（多选题选错不得分，宁少勿滥）；
- 遇到题干很长的综合案例题，先提炼当事人和法律关系，再定位考点；
- 不空题：客观题不倒扣分，能排除一个选项就蒙一个。

## 四、2025年客观题真题与题目来源专题（以2025年信息为依据）

> 这一部分回答三个问题：**真题到底能不能拿到？题目从哪来？是改编还是直接引用？** 全部以2025年客观题的公开信息为证据。

### 1. 2025年客观题基本信息

- 考试时间：2025年9月13日、14日，分两批次机考（越牛新闻2025-09-13《2025年国家统一法律职业资格考试客观题考试开考》报道；9月18日司法部发布客观题成绩与合格分数线公告）；
- 卷面结构：客观题共两卷（卷一+卷二），各150分，总分300分，180分合格；两卷均为选择题（单选、多选、不定项），题型全部依托案例情境；
- 报考规模：约93万人报名（机构统计口径，官方以司法部公告为准）。

### 2. 真题能不能拿到：官方不公布，市场上只有"回忆版"

这是回答"来源"问题前必须先讲清楚的事实：

- 自2018年起，司法部通过历年考试公告明确**国家统一法律职业资格考试不公布试题及参考答案**（如《2019年国家统一法律职业资格考试公告》第六条第三项）；
- 依据是《国家司法考试保密工作规定》（司发通〔2008〕142号）第四条第三款：考试结束后未公布的试题试卷、标准答案、应试人员成绩等属于**工作秘密**，是否公开的批准决定权在司法部；
- 已有判例背书：2020年考生李某申请公开2019年法考真题及答案被司法部拒绝，起诉后北京三中院一审驳回、北京高院二审维持原判（澎湃新闻2020-11-11《法考答案不公布违法吗？一考生因此状告司法部，法院这样判》）；
- **结论：拿不到官方真题和标准答案。** 市面上所有"2025法考真题"均为233网校、厚大、瑞达、众合等机构或考生整理的**回忆版**，细节可能存在偏差，且没有官方答案可对照。

### 3. 2025年客观题考了什么（回忆版中可见的具体案例）

综合2025年考后公开的真题分析与回忆版：

| 科目 | 回忆版案例/考点 | 说明 |
|---|---|---|
| 刑法 | "网红直播带货虚假宣传"案，考查诈骗罪与虚假广告罪的界分 | 典型热点+实务化命题 |
| 刑法 | "王某、李某抢劫致人死亡"案，考查共同犯罪与转化型抢劫的共犯责任 | 经典刑法学理考点套真实案情 |
| 刑法 | 甲为索取赌债扣押乙并殴打致轻伤，考查非法拘禁罪与抢劫罪的定性 | 实务争议场景入题 |
| 民法/侵权 | "职场性骚扰"维权情景，考查侵权责任构成与举证规则 | 社会热点（职场权益）直接入题 |
| 新法 | 《民营经济促进法》、刑诉新规 | 印证"新增、新修法律几乎必考" |
| 人格权/网络 | 网络言论与名誉权，流传的回忆版解析中直接引用"最高法院第143号指导性案例"（北京兰世达光电科技有限公司、黄晓兰诉赵敏名誉权纠纷案） | 可见真题考点与最高法指导性案例存在对应 |

### 4. 题目来源：以"改编真实案件/热点事件"为主，直接引用极少（官方口径）

- **官方文件**：中办、国办《关于完善国家统一法律职业资格制度的意见》明确提出考试**"以案例题为主，大幅度提高案例题分值比重"**；
- **官方发布会表述**：法考新闻发布会上提及，命题时将"活生生"的案例**根据命题技术规范进行加工改造后使用**——即官方定位就是"改编"，而非照搬；
- **行业观察佐证**：法考机构（法考之家，今日头条2020-06-15）曾列举"高空坠狗""天降陨石""反杀防卫""卖药案""双胞胎替婚""小三原配争遗产"等媒体报道过的热点案件均为历届题源；
- **2025年延续同一逻辑**：考后机构分析（网易《2025法考真题出炉！命题"三化"趋势明显》）将命题特征概括为"实务化、综合化、热点化"，题目已基本脱离法条直接复述，全部依托生活化真实场景。

### 5. 比例判断：没有官方统计，只能给出行业共识

- 官方从不公布命题素材清单或比例，**任何"X%题目来自指导性案例/案例库"的说法都没有权威出处**；
- 可以确认的边界：客观题**几乎100%案例化命题**；题干素材以**改编**真实案件、指导性案例、入库案例、年度热点事件为主流；**直接照搬**判例全文或裁判文书的情况很少（命题会做人物、情节、考点的加工改造）；
- 从2025年可见考点看，与最高法指导性案例、人民法院案例库案例、年度热点案件存在**明显重合**（如网络言论名誉权对应指导案例143号、直播带货对应热点打假争议、民营经济对应《民营经济促进法》）；
- 备考含义：不要试图"背原题案例"押题，而要把核心考点（罪名构成要件、侵权责任要件、新修法条）练到能识别"换了马甲的题干"。

### 6. 若想直接获取这些案例资源（获取渠道）

| 资源 | 获取渠道 |
|---|---|
| 最高人民法院指导性案例 | 最高人民法院官网（court.gov.cn）"指导性案例"栏目，免费全文 |
| 人民法院案例库（入库案例） | 人民法院案例库官网（rmfyalk.court.gov.cn），2024年2月上线，免费注册检索 |
| 最高人民检察院指导性案例 | 最高人民检察院官网（spp.gov.cn）"指导性案例"栏目 |
| 刑事审判参考案例 | 法律出版社《刑事审判参考》丛书；最高法官网及中国法院网有部分内容 |
| 司法部（司法行政）案例库 | 中国法律服务网（12348.gov.cn）"司法行政（法律服务）案例库" |
| 年度热点案件 | 最高法"年度十大案件"、最高人民法院工作报告附件案例、最高检工作报告案例 |

> 注意：这些资源是**复习素材库**（用来学考点、练案例拆解），不是"押题库"——因为真题是改编而非照搬。

## 五、风险与说明

1. 以上趋势与数据来自公开资料交叉验证（网易号、搜狐号、中公法考等机构文章），其中报名人数、通过率为机构统计或预测，与司法部最终公告可能有出入；
2. "近5年命题方向"没有官方文件，属于行业共识性归纳；
3. 在职1个月过客观题的成功案例基本都出现在有基础/二战考生中；若零基础，更现实的做法是把这次当作"全真摸底"，同时按3–6个月周期规划系统备考；
4. 备考期间保证睡眠，宁可少刷题也不熬夜——客观题判断力比题量重要。
